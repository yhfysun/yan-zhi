# 会话置顶（星标）入口隐蔽，且无置顶分组

- **状态**：未解决（功能可用，但疑似「用户找不到」）
- **严重度**：low
- **发现日期**：2026-09-19

## 现象

用户反馈「会话列表没有星标功能」。实际排查发现**功能完整可用**，只是入口极隐蔽，
且缺少置顶分组，导致在长列表里几乎看不出效果。

## 现状核查（链路完整，无需重写）

| 环节 | 位置 | 状态 |
|---|---|---|
| UI 入口 | `packages/ui/src/components/chat/ChatSidebar.vue:155` 会话右键菜单「置顶/取消置顶」 | 有 |
| 状态切换 | `packages/ui/src/composables/chat/useChat.ts:2774` `togglePin()` | 有 |
| 持久化 | `packages/ui/src/stores/chat.ts:665` → `PATCH /conversations/:id` | 有 |
| 后端字段 | `apps/server/src/db.ts:115` `pinned INTEGER DEFAULT 0` | 有 |
| 排序 | `routes/conversations.ts:33` 与 `stores/chat.ts:574` 均 `ORDER BY pinned DESC, updated_at DESC` | 有 |
| 视觉标记 | `ChatSidebar.vue:53` 置顶项显示星形图标 + `.pinned` 样式 | 有 |

## 缺失项（真正要补的）

1. **没有独立的「置顶」分组**：置顶会话只是靠 `pinned DESC` 排到列表最前面，
   混在普通会话里，没有任何视觉分区，用户感知不到「这些是置顶的」。
2. **列表项内没有可直接点击的星标按钮**：只能右键 → 置顶，两步操作且需要先知道有右键菜单。
3. 置顶项的图标替换逻辑（`v-if="conv.pinned"` 用星标**替代**默认圆点图标）会让
   置顶项看起来像「换了个图标」而不是「被标记了」。

## 影响面

- 会话数量多时（实测 dev 库 11 条、打包版 7 条），用户难以把常用会话固定在顶部。
- 功能存在但不可发现 ≈ 功能不存在（用户就是这么反馈的）。

## 修复方向（待用户确认走哪条）

- **方案 1**：列表顶部增加「置顶」分组标题，置顶会话归入该组，与普通会话分隔。
- **方案 2**：会话项 hover 时在右侧显示星标按钮，点击即可切换（更符合直觉）。
- **方案 3**：两者都做（分组 + hover 星标）。

> 注意：用户对 UI 的一贯要求是**极简、不要多余图标与 tip 提示文字**（见项目约定），
> 因此方案 2 的星标**只在 hover 时出现**、默认不占位，比常驻图标更契合偏好。
