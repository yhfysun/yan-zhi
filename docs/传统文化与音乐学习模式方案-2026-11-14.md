## 二、产品定义

### 2.1 一句话

**传统文化**：从「天对地，雨对风」开始，把典籍原文摊开在一张宣纸阅读面上，**每个字都点得开、每句话都说明白**，最后自己能对出一句联；主线之外还有一座**典籍文库**——唐诗宋词元曲古文经籍，经典与冷门佳作同架陈列，分好类、搜得到、能诵读。
**音乐**：从「听一个音」开始，同一段旋律能在**五线谱 / 简谱 / 工尺谱 / 宫商角徵羽**四种记法间一键切换，点一下就响，拖一拖就能编出自己的曲子、填上自己的词。

### 2.2 两条零基础路线（都是「先能感知，再能认，再能写」）

**传统文化 · 四阶（每阶 8~12 课，首版共约 36 课）**

| 阶 | 名称 | 学什么 | 教材（全部公版） | 产出 |
| --- | --- | --- | --- | --- |
| 一 | 蒙学·对韵 | 一字对 → 二字对 → 三字对；字数、词性、平仄（仄起平收） | 《笠翁对韵》《声律启蒙》选段 | 能对出「山对海」 |
| 二 | 诗词歌赋 | 绝句 → 律诗 → 词 → 赋（选段）；句读、押韵、对仗、意象 | 唐诗三百首、宋词选、《千家诗》 | 能读懂一首没学过的绝句 |
| 三 | 四书 | 《论语》《孟子》选章 →《大学》《中庸》；章句、名物、句式 | 四书通行本 | 能逐字讲清一章 |
| 四 | 五经 | 《诗经》《尚书》《礼记》《周易》《春秋》选段（不做全本） | 五经通行本 | 能读懂一段带注原文 |

**典籍文库（主线之外的「图书馆」，用户拍板：要几千上万篇，不只一两百）**

| 维度 | 取值 |
| --- | --- |
| 规模 | 首批 **5 万+ 篇**，**各朝代均衡覆盖（先秦两汉魏晋南北朝唐五代宋元明清全有）、精品优先**（三级优先序 + 朝代配额见 §4.2b）+ 精读层 ~300 篇人工注解 |
| 体裁 | 经（四书五经）/ 诗（古体·近体·绝句·律诗）/ 词（小令·中调·长调）/ 曲 / 文（散文·骈文·赋）/ 蒙学 |
| 朝代 | 先秦 / 两汉 / 魏晋 / 南北朝 / 唐 / 五代 / 宋 / 元 / 明 / 清 |
| 主题 tag | 山水田园 / 边塞 / 咏史怀古 / 送别 / 思乡 / 爱情 / 哲理 / 节令 / 咏物 / 纪游 / 悯农 … |
| 丛书 | 唐诗三百首 / 宋词三百首 / 古文观止 / 诗经 / 楚辞 / 乐府诗集 / 花间集 / 千家诗 / 声律启蒙 / 笠翁对韵 / 四书 / 五经 |
| 热度 | `classic` 经典（教材/名句入选）/ `notable` **冷门佳作**（低热度但选本与评点收录，离线预生成名单）/ `normal` |
| 难度 | 蒙学 / 入门 / 进阶 / 深造 |

**音乐 · 五阶（首版共约 40 课）**

| 阶 | 名称 | 学什么 | 产出 |
| --- | --- | --- | --- |
| 一 | 听与拍 | 音高高低、长短、拍子、强弱 | 能跟着拍手打 4/4 |
| 二 | 识谱 | 五线谱（线间/谱号/时值/拍号）→ 简谱 → 工尺谱 → 五声名 | 看谱能点出音名 |
| 三 | 五声与调式 | 宫商角徵羽 = 1 2 3 5 6 = 上尺工六五；宫/商/角/徵/羽调式换调试听 | 听得出「宫调→羽调」的色彩变化 |
| 四 | 依谱写词 | 一字一音填词、字调与旋律走向、押韵 | 给一段旋律填上自己的词 |
| 五 | 积木编曲 | 小节网格 + 五声音高块、起承转合、重复与收束、移调 | 编出 8 小节小曲并试听 |

> **明确边界**：首版不做古琴减字谱的交互（只在「典籍/古谱」里做展示）、不做和声/多声部、不做升降号与复杂拍号、不做「按词牌格律填词」（只做依曲填词）、不做音频打分。

### 2.3 教学设计核心（决定成败的不是渲染）

1. **注解四层；精读层全部预写、不靠 LLM 现编**：`字面`（这个字在此处是什么意思）→ `白话`（整句怎么说）→ `背景`（典出/名物/制度，一句话）→ **`一句话说明白`**（给零基础的大白话收口）。生僻字带拼音，多音字标「此处读 X」；禁止裸用「互文见义」「宾语前置」等术语，必须出现时跟一句白话解释。文库层的 AI 注解只作辅助（见第 2 条），**不承担教学考核**。
2. **典籍必须真存在，且成规模（2026-11-14 扩量：典籍架 → 典籍文库）**：人工预写注解撑不起几千上万篇，所以内容分**三层**（详见 §4.2b）：
   - **精读层**（~300 篇）：手校通行本原文 + **人工预写四层注解**（`verified`），单测校验完整性，进判卷与考核；
   - **文库层**（首批 5 万+ 篇）：开源公版语料导入 SQLite——[chinese-poetry](https://github.com/chinese-poetry/chinese-poetry)（MIT 许可，含**全唐诗 4.9 万首**、宋词、元曲、古文、经部），可选维基文库（CC BY-SA，署名）补充；无预写注解，供分类浏览 / 检索 / 诵读；
   - **注解缓存层**：文库层篇目点字 → LLM 生成注解，落 `canon_gloss` 缓存，界面明标 **「AI 生成 · 供参考」**（`assisted`），不进判卷与考核。
   - ★ **硬约束（用户拍板强调）**：**精读层注解 100% 人工预写，禁止任何 LLM 生成/辅助填充精读层内容**——`assisted` 只允许出现在文库层缓存表，精读层内容包（TS 常量）里不允许出现 `assisted` 来源；测试断言钉死（精读层 gloss 全部人工字段、无 AI 标记），违反即测试红。
   - 原文一律公版，不引现代注本，规避版权；每篇带 `source` 标注底本与来源。
3. **注解深度三档**：初学（全注）/ 进阶（只注关键字）/ 原文（无注）。同一篇能从「扶着读」平滑过渡到「自己读」。
4. **对对子是规则可判的练习**：出句 → 填字位槽 → 实时校验三项（字数相等 / 词性相对 / 平仄相对，上联仄收下联平收）→ 交卷给**逐项判卷**（不是笼统对错）→ 对照「古人怎么对」。零基础先给候选字块选填，进阶才自拟。
5. **音乐把四种记法打通，而不是四个割裂模块**：同一份 `NoteEvent[]` 数据渲染五线谱 / 简谱 / 工尺谱 / 宫商角徵羽，一键切换、播放时四种记法同步高亮。这是本方案最核心的差异化。
6. **声音必须能听**：Web Audio 合成音（正弦 + 轻微三角波，ADSR 包络），点音符即响、整段播放音头跟随；无声环境降级为「看谱高亮」，不阻塞学习。

## 三、UI 交互设计（本方案重点）

### 3.0 两层结构契约

```
总览层 /learning（三栏，骨架不动）
  ├─ 顶栏：科目下拉（传统文化 / 音乐）· 进度 · streak
  ├─ 左栏：路线地图（按阶分组，筛选固定顶部 + 列表独立滚动）
  ├─ 中栏：本科目 Tab 工作区 → 课程列表 → 点课程
  └─ 右栏：典籍文库速览（传统文化）/ 我的曲子（音乐）· 今日复习
                    ↓ 点课程，进入
沉浸学习台（position:fixed 全屏覆盖，锁滚动）
  顶栏只四项：← 返回路线 | 典籍·篇章 / 曲目·课次 | 步骤 x/5 | ✕ 退出
  步骤条（紧凑，当前步高亮，可回看不可跳未解锁）
  阅读面（稳定最大宽度 ~720px，独立浅色表面）
  底部：上一步 / 下一步（移动端常驻）+ 极简工具条
```

### 3.1 传统文化沉浸台 · 「典籍精读台」

深色外层（`--cul-*` 私有变量，对齐 `--path-focus-*` 做法）+ **宣纸色阅读面** `#FFFDF8`，正文衬线大字、行距宽，适合长内容阅读。

**五步固定循环**：`诵读 → 逐字注 → 白话 → 章句脉络 → 自测/对句`，一次只显示一步。

- **诵读步**：原文按句切分，逐句高亮跟读；播放/暂停/单句循环三档；中文朗读 P0 走前端 `speechSynthesis`。
- **逐字注步（核心）**：
  - 原文中**可点字**带淡色下虚线；hover 显示一行简注（轻量预览），**点击打开右侧注解抽屉**。
  - 抽屉显示四层（字面 / 白话 / 背景 / 一句话说明白），**不用行内折叠**（遵守准则 §2）。
  - 抽屉顶部有「注解深度」极简三档切换；读过的字保持浅标记，方便回看。
- **白话步**：整篇 3 句「这一篇到底在说什么」+ 逐句左右对照（左原文、右白话），不做整页双语长表。
- **脉络步**：一屏一条结构线（如「提出 → 举例 → 收束」），每节点一句话，点节点回跳对应原句。
- **自测/对句步**：见下。

**对句台（独立步骤内的练习面）**

```
出句（大字，平仄标注可开关）      风　来　花　自　舞
                                  ─ 　─ 　─ 　丶 　丶   ← 平仄行
字位槽（按字数排列，逐格填）       [ ] [ ] [ ] [ ] [ ]
候选字块（零基础给词库，拖/点填入）  春  归  燕  共  语  山  对  海 …
提交 → 逐项判卷：✓ 字数 5=5   ✓ 词性 名/动相对   ✗ 平仄 第4字应仄
                 → 对照「古人怎么对」：《笠翁对韵》原句 + 一句为什么
```

- 三项判卷用纯函数 `judgeCouplet()`（平仄表 + 词性表内置），可单测；**错了不惩罚**，只给「换个字试试」。
- 交付前「再来一次 / 看范本 / 记到笔记」三个动作，不弹多余提示。

**典籍文库页（总览层一级 Tab，先逛图书馆，再进教室）**

传统文化科目 Tab 扩为两个：`零基础主线`（对句台是主线课第 5 步）+ `典籍文库`。

```
┌ 筛选固定顶部（不随列表滚动）──────────────────────────────┐
│ 🔍搜题目/作者/名句   体裁▾ 朝代▾ 主题▾ 丛书▾ 热度▾ 难度▾ │
└────────────────────────────────────────────────┘
┌ 列表独立滚动（分页 50/页 + 虚拟滚动，5 万条不卡）──┐ ┌右栏速览───────┐
│ [经典] 望月怀远 · 张九龄 · 唐 · 五言律诗          │ │ 首联原文      │
│ [冷门佳作] 蜀道后期 · 张说 · 唐 · 五绝            │ │ 主题 tag      │
│ [经典] 声律启蒙 · 一东 · 蒙学                     │ │ [精读] [诵读] │
└────────────────────────────────────────┘ └───────────┘
```

- 徽标：`经典` / `冷门佳作` / 无标；`verified` 篇目显示「精读」入口，其余「诵读」。
- 「每日一首 + 随机一首」入口放文库顶部，不打扰筛选。
- 点条目 → 同一个沉浸精读台：verified 篇目五步全开；文库层篇目「逐字注」步改为**点字问 AI 老师**（走陪练链路 + `canon_gloss` 缓存，就地浮层展开、明标「AI 生成 · 供参考」），主流程仍是步骤切换、不用行内折叠。
- 联动：读任何一首诗 → 「拿这首出对句题」→ 对句台以该诗名句为出句。

### 3.2 音乐沉浸台 · 「谱面工作台」

深色外层 + **纯白谱面**（独立阅读表面，与宣纸面同契约不同质感）。

**五步固定循环**：`听 → 认 → 写 → 奏 → 自查`。

- **记法切换条**（谱面上方，四个极简 Tab，当前高亮）：`五线谱 | 简谱 | 工尺谱 | 宫商角徵羽`。切换不改数据、只换渲染器；播放时四栏对照同步高亮。
- **谱面（ScoreCanvas，SVG 自绘）**：五条线 + 高音谱号 + 拍号 + 符头/符干/时值；音头随播放进度高亮；**点任意音符 → 播放该音**（Web Audio）。首版单声部、C 调、4/4、全/二分/四分音符。
- **四记法对照条**（谱面下方固定一行，纵向对齐同一音）：

  | 宫 | 商 | 角 | 徵 | 羽 |
  | --- | --- | --- | --- | --- |
  | 1 | 2 | 3 | 5 | 6 |
  | 上 | 尺 | 工 | 六 | 五 |
  | C | D | E | G | A |

  > 首版只用五声正音，不含「凡 / 乙」偏音；进阶课再引入并明确标注「偏音」。
- **音名块试奏条**：五个可点音名块（宫商角徵羽）+ 高低八度切换，点即响；「听音辨名」题在这里作答。
- **编曲格子（写/奏步）**：4 小节 × 5 音高的网格，拖音名块入格 → 立即试听 → 「调式」下拉一键换宫/羽调并试听差异；系统只给三条极简反馈（节奏是否齐 / 音域是否越界 / 是否有重复），不做打分。
- **依谱写词**：每个音符下方一个字格，填汉字后播放逐字高亮；字调提示（阴平阳平≈平、上去≈仄）只做**提示不做判分**，避免误导。
- **自查步**：3 题（听音选名 / 看谱点音 / 记法互译），交卷给逐题解析，对齐英语主线 `quickCheck` 体验。

### 3.3 交互规范（对齐既有偏好与准则）

- **极简**：无多余图标、无 tip 文案；工具条只留必要控件；筛选固定顶部、列表独立滚动（三栏各自滚动，不整页滚）。
- **hover 语义**：注解简注、音名块预览用 hover 展开（辅助说明），**主学习流程仍是步骤切换 + 抽屉**，不变成 click-to-switch 面板切换。

- **主题**：沉浸层私有变量不改全局 token；阅读面始终浅色高对比（AA），外层低饱和深色降干扰。
- **退出**：回到原路线位置、保留完成进度；进度写**独立 localStorage key**（`yz.learning.culture.completed.v1` / `yz.learning.music.completed.v1`），**绝不混用** `yz.learning.path.*` 或 `yz_security_progress_v1`。

**DB（db.ts 新增 3 表，照 7 表范式；canon 表 P0 建）**：

```sql
CREATE TABLE IF NOT EXISTS canon_work (
  id TEXT PRIMARY KEY,            -- 'source 前缀 + 原始 id'，幂等 upsert 锚点
  title TEXT NOT NULL, author TEXT, dynasty TEXT, genre TEXT,   -- 经/诗/词/曲/文/蒙学
  collection TEXT, tags TEXT,     -- 丛书与主题 tag（JSON 数组串）
  popularity TEXT,                -- classic | notable | normal
  difficulty TEXT, text TEXT NOT NULL, source TEXT NOT NULL,
  verified INTEGER NOT NULL DEFAULT 0, created_at INTEGER NOT NULL
);
CREATE TABLE IF NOT EXISTS canon_gloss (
  work_id TEXT NOT NULL, term TEXT NOT NULL, plain TEXT, context TEXT,
  in_one_line TEXT, pinyin TEXT, origin TEXT,   -- verified | assisted
  updated_at INTEGER NOT NULL, PRIMARY KEY (work_id, term)
);
CREATE VIRTUAL TABLE IF NOT EXISTS canon_fts USING fts5(
  title, author, text, content='canon_work', content_rowid='rowid'
);
```

- **FTS5 中文检索**：unicode61 默认按字切 token，中文短语查询（`"海上生明月"`）即可做**名句反查**，首版够用，不引 jieba。
- **体积账**：文库层 DB 约 60~100MB（含全唐诗 + 全宋词后）；**安装包只涨精选集 ~4-6MB**（首启后台导入 ~2250 篇 <2s）。断代大库语料 JSON 走在线内容包分批下载，复用 `tts-packs.ts` 镜像/代理下载与 `POST /books/import` 先例，落 `<dataDir>/canon-src/` 后导入。
- **冷门佳作圈定**：按「选本收录 + 评点语料」离线预生成 `notable` 名单存 tag，保证「冷门但优秀」筛得出来；不靠运行时热度。
- **导入**：`import-canon.mjs` 按**朝代配额 + 三级优先序**规整语料字段 → 按 `source` 前缀 id 批量 upsert（可重跑）；首启检测 `canon_work` 空则后台导精选集（~2250 篇，各朝代都有），不阻塞启动；断代大库每批入库即立即可检索。

### 4.4 音频与渲染（零新依赖）

- **音频**：`useScoreAudio.ts` 用 `AudioContext` + `OscillatorNode` + `GainNode`，ADSR 包络（attack 10ms / decay / sustain / release 120ms），正弦 + 轻微三角波叠加；播放整段时按 `beats × 60/BPM` 排程并回调高亮当前音头。自动播放策略照 `live-audio.ts:83` 在首次用户手势后 `ctx.resume()`。
- **B3 规避**：中文诵读 **P0 用前端 `speechSynthesis`（`zh-CN`）逐句朗读**，不改 `/api/learning/tts`；P1 再评估本地 sherpa 中文音色。音乐完全不走 TTS（合成音）。
- **谱面**：`score-render.ts` 纯函数把 `NoteEvent[]` 转成 SVG 图元数组（五线 y 坐标、符头 x、符干方向、时值旗/尾），`ScoreCanvas.vue` 只负责 `<svg>` 渲染与点击命中。首版不做连音线、装饰音、休止以外符号。
- **为什么不引 VexFlow/Tone.js**：项目纯 CSS + 原生 Web Audio 已有先例，引入会增打包体积与许可审查；且首版谱面范围（单声部/五声/4/4）自绘成本低于接入成本。

## 七、拍板结论（2026-11-14 22:14 全部确认，开始实施）

1. **文库节奏**：✅ 按 §4.2b 配额表执行——P0 精选集 ~2250 篇随包（各朝代都有），P1 断代大库分批（全唐诗 → 全宋词 → 汉魏六朝 → 明清）。
2. **AI 注解（assisted 层）**：✅ 接受——LLM 生成 + 缓存 + 明标「AI 生成 · 供参考」、不进考核。
3. **P0 范围**：✅ **先传统文化**（典籍文库 + 精读台 + 对句台），音乐放下一轮。
4. **接线方式**：✅ 采用 `subject-extensions.ts` 扩展表（改 3 个通用点、存量分支零改动）——按「效果与最小回归面」选定。
5. **音色**：✅ 以效果为准运行时自适应——诵读优先探测系统中文音色（`speechSynthesis`），有本地中文 TTS（P1）则优先；音乐用 Web Audio 合成音（零资源、即时可听），后续可换采样音色。
