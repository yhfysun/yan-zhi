# 学习内容手写并行协作看板（2026-11-23）

## 状态规则

只使用三种状态，禁止自造中间态：

| 状态 | 含义 |
|---|---|
| `未写入` | 输出文件尚不存在或仍是模板内容 |
| `正在处理` | 已登记负责人和唯一写入文件，允许开始编写 |
| `已完成` | 内容已合入主工作区，契约测试与类型检查通过 |

“正在处理”只能由主线程登记；“已完成”只能由主线程在集成并验证后勾选。子智能体不得自行把任务改成“已完成”。

## 防写乱规则

1. 一个任务只对应一个新增内容文件，文件路径写进任务行；同一文件同一时间只允许一个负责人。
2. 子智能体只编写自己的内容文件，不得修改 `catalog.ts`、`v2-curated/index.ts`、共享组件、测试和看板。
3. 子智能体不创建临时索引、不提交 Git、不清理其它文件。
4. 主线程一次只集成一个包：先补导出和去重挂接，再跑该包契约测试，最后标记“已完成”。
5. 若发现任务文件已有外部修改，暂停集成并由主线程核对，不覆盖现有内容。
6. 每个课程必须包含：前置知识、可观察目标、引导练习、独立练习、至少两个常见错误、真实来源和五步教案；每步正文不少于 100 字。
7. 主线程每次集成前后都检查状态列只能出现 `未写入`、`正在处理`、`已完成`；发现其它值立即停止集成。
