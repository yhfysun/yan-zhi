急停三件套

Esc 热键 立即冻结输入 · 时长上限 默认 5 分钟 · 步数上限 默认 300 步。
实时模式下每次循环都校验这三个闸门，任一触发即停并保留现场（截图 + 最后 N 步日志）供复查。
维度 回合制 · LLM 慢通道 实时 · 主进程循环
决策者 每一帧都由 LLM 决策（截图进模型 → 模型给出动作） 开局一次策略，之后主进程按 30Hz 执行；只在"卡住"时回问 LLM
单步延迟 约 1000–2000ms（一次 LLM 往返） 约 33ms（一次 sendInputEvent）
适用游戏 回合制、放置挂机、棋类、每日签到 动作、弹幕、跑酷等需要毫秒级反应的
token 成本 随步数线性增长（每步一张图） 基本恒定（只开局一次）
状态判断 模型读整张截图，泛化好、但慢且贵 canvas 像素采样（血条颜色 / 目标区域），毫秒级且免费
失败形态 点空、点错目标——可回读截图自查 像素条件写错会"空转"——靠日志与步数上限兜底
