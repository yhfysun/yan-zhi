# 言智 App 化重构原型 v3

## 打开方式

直接双击：

- `desktop.html`：桌面端全模式与菜单原型
- `mobile.html`：移动端全 Tab、店铺子页与底部抽屉

或启动静态服务：

```powershell
python -m http.server 4218 --directory docs/prototypes
```

桌面访问：

- http://127.0.0.1:4218/app-v3/desktop.html
- http://127.0.0.1:4218/app-v3/mobile.html

## 桌面覆盖

- 模式：办公、店铺运营、开发、运维、安全、工作流、自动化、剪辑、学习
- 每个模式内部提供 `AI / 人工` 工作方式切换，AI 继承当前模式上下文
- 不保留常驻模式栏；模式切换位于标题栏下拉和命令面板，桌面只保留一个可收起上下文栏
- 各模式使用独立布局原型：办公任务台、店铺运营台、开发 IDE、运维控制台、安全风险台、工作流画布、自动化运行台、剪辑时间线和学习课程桌面
- 开发、剪辑和店铺运营继承项目中心交互：左侧保留项目/文件上下文，中间保留主工作画布，检查器按需展开
- 开发 AI 方式保留项目文件树、代码编辑区、测试状态和 Git 插件；Git 支持独立变更/diff/提交面板
- 桌面上下文栏和检查器支持拖动调宽、双击收起，并可从标题栏或模式栏重新展开
- 1024px 窗口下，项目中心模式默认收起检查器；打开检查器时使用覆盖层，不压缩代码区、剪辑监看区或运营主台
- 店铺子页：总览、商品、订单、发货、库存、物流、操作日志、口径速查
- 店铺从 0 开店：平台、店铺类型、货源方式、连接方式、确认创建五步向导
- 学习：19 科科目切换、课程总览、独立图书馆与单步沉浸学习台
- AI 工作方式：完整消息流、发送框、智能体 / Skill / 模型 / 工具权限选择、附件与更多菜单
- AI 输入框菜单：智能体、Skill、模型、权限、文件、图片、浏览器页面、剪贴板、记忆、工作流
- 设置：通用、模型与平台、智能体、Skill 与工具、权限与审批、通知、快捷键
- 菜单：模式切换、命令面板、通知、账号、工作区右键、表格行右键、AI 变更单、剪贴板管理态、宠物半圆菜单、宠物任务面板、设置中心

顶部评审工具条可以直接切换模式和打开所有菜单；点击“清屏预览”可隐藏工具条。
在地址后添加 `review=0` 可直接以无评审工具条的应用窗口状态打开任意桌面页面；`inspector=1` 或 `inspector=0` 可指定检查器初始状态。

## 移动覆盖

- 主导航：工作、店铺、文件、我的
- 移动工作模式：日常办公、运维、安全、学习
- 店铺：总览、商品、订单、发货、库存、更多
- 抽屉：模式切换、店铺切换、筛选、商品详情、订单详情、发货、库存调整、AI 快速指令、通知、操作菜单
- 学习：顶栏 19 科科目切换、课程总览、独立图书馆与单步沉浸学习
- 图书馆：发现、书架、书源三区，不是学习页子 Tab

右侧评审面板可以直接打开每个页面和抽屉。390px 视口会自动隐藏评审面板，只显示真实手机界面。

开发、工作流、视频剪辑、RPA 不进入移动一级模式。它们只在任务通知中提供运行状态、测试结果和审批等只读入口。

学习沉浸层必须完全覆盖总览页和全局导航，不允许底层课程卡、继续学习卡或 TabBar 在上下露出。

## 说明

这是用于方向评审的高保真交互原型，不是业务代码实现。所有数据均为演示数据，不读取真实店铺、剪贴板或任务。
