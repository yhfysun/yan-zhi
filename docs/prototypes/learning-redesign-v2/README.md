# 学习模式全科目重构原型

日期：2026-11-16

## 入口

- `index.html`：方案索引、双端预览、19 科 × 8 类页面矩阵。
- `desktop.html`：桌面端可交互原型。
- `mobile.html`：移动端可交互原型。
- `library.html`：全科公共图书馆，跨科检索原文、注释、版本与出处。
- `coverage.html`：327 门课程的全页面直达清单，共 5,232 个桌面/移动链接。
- `../../学习模式全科目重构方案-2026-11-16.md`：正式方案文档。

## 覆盖

- 19 个科目：党史、政治、经济学、军事、历史、书法、记忆训练、思维训练、数学、物理、百家思想、英语、日语、软考、网络安全、传统文化、音乐、周易、占卜。
- 最新代码的 95 个课程与精读单元全部保留。
- 新方案首批登记 232 门课程。
- 每个科目 8 类页面：学科总览、课程地图、书籍研读、沉浸学习、实践、练习测评、复习巩固、AI 陪练。

## 交互

- 顶部“上一科 / 下一科”切换科目。
- 页面 Tab 切换八类页面。
- 学科总览或课程地图中点击课程可切换当前课程。
- 点击“进入学习台”打开全屏单步学习。
- 学习台内可切换步骤、看到进度、完成本课并进入复习。
- 练习页可选择选项并提交反馈。
- 移动端顶栏科目和课程均可打开 App 内浮层。

## 原型边界

原型用同一页面语法生成所有课程入口，验证布局、导航与交互覆盖。生产实现中，每门课程的内容、题目、来源和复习卡由各自内容包提供，不能用一个示例正文代替全部课程内容。

原型文件只服务设计与评审，不接入产品运行时，也未修改现有学习模式代码。
