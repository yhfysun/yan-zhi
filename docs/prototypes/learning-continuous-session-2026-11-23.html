扩容时，旧数据为什么要重新排？

当元素数量超过阈值，HashMap 会把数组容量翻倍，并重新计算旧元素在新数组中的落点。这个动作叫 rehash，它保证了容量变化后仍能快速定位。

先抓住 threshold

threshold = capacity × load factor。默认容量 16、负载因子 0.75，因此阈值为 12；插入第 13 个元素时触发扩容。

扩容后，元素的 hash 没有变，但用于定位的数组长度变了，所以旧元素需要重新分配位置。并不是“复制过去就完事”。

第 13 个元素插入前，准备扩容
→
容量 32 · rehash 后
旧元素在新数组里重新落位
本步要记住：扩容不是单纯增加空间；它同时改变了落点计算，所以必须 rehash。
