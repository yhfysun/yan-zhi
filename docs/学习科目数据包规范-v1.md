# 学习科目数据包规范 v1

状态：`1.0`

适用范围：Learning V2 内置导出包、用户自制课程、学校/团队共享课程、按科目裁剪安装包。

## 1. 设计目标

- 一个文件表达一个完整科目，可离线导入、导出、校验和分享。
- 第三方不需要修改言智源码，也能创建合法课程包。
- 导入时拒绝空壳课程、重复课程、非法分发状态和结构缺失内容。
- 同一包既是用户学习数据，也是安装包选择清单的内容来源。
- 用户笔记、学习进度、运行证据和个人数据永远不进入共享包。

## 2. 文件约定

- 扩展名：`.yzcourse.json`
- MIME：`application/json`
- 编码：UTF-8
- 单包上限：25 MB
- 文件名：`<subjectKey>.yzcourse.json`
- 包 ID：`learning.subject.<subjectKey>`

`subjectKey` 规则：

- 2 到 64 个字符
- 只允许小写字母、数字和短横线
- 必须以小写字母开头
- 创建后不可修改；显示名称可以修改

示例：`learning.subject.math`、`learning.subject.custom-first-aid`。

## 3. 顶层结构

```json
{
  "format": "yan-zhi.learning-subject-pack",
  "formatVersion": 1,
  "packageId": "learning.subject.custom-first-aid",
  "contentVersion": "1.0.0",
  "generatedAt": "2026-11-23T00:00:00.000Z",
  "distribution": "ondemand",
  "scope": "subject",
  "subject": {},
  "courses": [],
  "counts": {
    "courses": 1,
    "steps": 5,
    "quizQuestions": 4,
    "codeLabs": 0
  }
}
```

字段规则：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `format` | 是 | 固定为 `yan-zhi.learning-subject-pack` |
| `formatVersion` | 是 | v1 固定为数字 `1` |
| `packageId` | 是 | 必须与 `subject.key` 对应 |
| `contentVersion` | 是 | 分享者维护的语义版本，例如 `1.2.0` |
| `generatedAt` | 是 | 合法 ISO 时间 |
| `distribution` | 是 | `bundled` / `ondemand` / `excluded` |
| `scope` | 是 | v1 固定为 `subject` |
| `subject` | 是 | 科目元数据、轨道、书籍、实践台和教练配置 |
| `courses` | 是 | 完整课程数组，不能少于 1 门 |
| `counts` | 是 | 汇总值；导入器会重新计算并核对 |

`distribution` 语义：

- `bundled`：允许随安装包分发，必须进入 `selection.manifest.json`
- `ondemand`：不随安装包，可由用户导入后使用
- `excluded`：仅用于源码维护，禁止导出和导入

## 4. 科目元数据

`subject` 复用 `LearningV2SubjectView` 的公开字段，但不包含运行时课程引用数组：

- `key`、`name`、`short`
- `accent`、`tint`、`line`
- `current`
- `stats`
- `tracks`
- `lesson`
- `practice`
- `review`
- `coach`
- `book`
- `studio`

硬约束：

- `tracks` 中出现的每门课程都必须在 `courses` 中有同名课程。
- `courses` 中每门课程都必须登记到一条轨道。
- 第三方不得使用 `subject.current` 伪造用户进度；它只作为目录初始展示信息。
- `book` 和 `studio` 只描述课程内容；真实用户笔记、运行记录和健康信息不得写入。

## 5. 课程结构

每门课程：

```json
{
  "id": "custom-first-aid:0:0",
  "name": "现场安全与呼救",
  "trackName": "基础急救",
  "plan": {}
}
```

字段规则：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 是 | 包内唯一、稳定，不得复用给另一门课程 |
| `name` | 是 | 包内唯一课程名 |
| `trackName` | 是 | 必须存在于 `subject.tracks[].name` |
| `plan` | 是 | 完整 `LearningV2CoursePlan` |

`plan` 必填：

- `subjectKey`：必须等于 `subject.key`
- `courseName`：必须等于课程 `name`
- `trackName`
- `title`
- `prerequisite`
- `plainLanguageGoal`
- `guidedPractice`
- `independentPractice`
- `commonErrors`：至少 2 项
- `sourceRefs`：至少 1 项，优先给出来源 URL
- `qualityStatus`：`curated`、`generated` 或 `draft`
- `steps`：至少 1 步
- `expertNotes`
- `quiz`

共享课程的最低内容标准：

- 每步包含 `title` 和非空 `body`
- 正文不得只写“了解”“掌握”“记住”等不可验证口号
- 有操作技能的课程应提供 `example.code` 和 `example.output`
- 练习与实践必须能看到输入、步骤、产出和失败边界
- 第三方课程不得冒充“人工审校”；`qualityStatus` 必须如实标注

## 6. 题库与代码台

`quiz` 每题：

- `prompt`
- 至少 3 个不重复 `options`
- `answer` 为合法选项下标
- `explanation`
- `focus`

可选 `codeLab`：

- 必须声明支持语言和运行环境
- 起始代码不得隐藏标准答案
- `practice` 与 `apply` 都必须有验收检查
- 未实际验证的通用模板代码不得批量登记

## 7. 来源、许可与版权

- 每个课程至少提供一个 `sourceRefs`
- 第三方转载必须保留作者、作品、版本、链接和许可
- `excluded` 不得被改写成 `ondemand` 后公开分享
- 用户导入包只保存在本机，不上传到服务端或其他用户
- 禁止在包中放真实密钥、Cookie、身份证明、健康记录和个人笔记

## 8. 导入规则

导入顺序：

1. 检查 25 MB 上限
2. 解析 JSON
3. 检查格式、版本、ID、分发状态和结构
4. 重算 `counts` 并与声明值比较
5. 检查课程与轨道一一对应
6. 检查课程名和课程 ID 唯一
7. 通过后写入本机 IndexedDB
8. 注册到运行时并刷新科目目录

冲突策略：

- `coexist`：包 ID 或科目 key 加用户后缀，两版并存；默认策略
- `replace`：同科目 key 且 `contentVersion` 更高时覆盖用户包
- `disable`：保留文件但不注册

任何版本都不得静默覆盖内置内容。移除用户包后恢复内置版本。

## 9. 打包清单

安装包只读取一份 `selection.manifest.json`：

```json
{
  "format": "yan-zhi.learning-content-selection",
  "formatVersion": 1,
  "generatedAt": "2026-11-23T00:00:00.000Z",
  "entries": [
    {
      "subjectKey": "math",
      "subjectName": "数学",
      "packageId": "learning.subject.math",
      "contentVersion": "2026.11.23.1",
      "distribution": "bundled"
    }
  ]
}
```

打包命令：

```powershell
node scripts/package.cjs desktop:lite --content=math,physics
node scripts/package.cjs desktop:lite --content=all
node scripts/package.cjs desktop:lite --content=none
```

约束：

- `bundled` 可以进入安装包
- `ondemand` 必须排除在安装包外
- `excluded` 不生成数据文件
- 未安装科目显示“未安装”，不得生成空壳课

## 10. 命令

```powershell
pnpm learning:content:list
pnpm learning:content:init -- --key=custom-first-aid --name=基础急救 --file=tmp/content/custom-first-aid.yzcourse.json
pnpm learning:content:export -- --subjects=math --default=excluded --out=tmp/content
pnpm learning:content:verify -- --file=tmp/content/bundled/math.yzcourse.json
```

导出目录：

```text
tmp/content/
  selection.manifest.json
  bundled/
    math.yzcourse.json
  ondemand/
    physics.yzcourse.json
```

## 11. v1 兼容规则

- 读取方必须忽略未知的可选字段。
- 未知的顶层字段不影响导入。
- `formatVersion` 更高时拒绝导入，并提示升级应用。
- 删除字段、改变字段语义或新增必填字段必须发布新主版本。
- 后续支持 zip 时仍使用相同 `manifest.json` 和课程结构。

## 12. 校验入口

- JSON Schema：`docs/schemas/learning-subject-pack-v1.schema.json`
- 可导入示例：`docs/examples/custom-demo.yzcourse.json`
- TypeScript 契约：`packages/shared/src/learning/learning-content-pack.ts`
- 命令行校验：`pnpm learning:content:verify -- --file=<path>`
- 内容审计：`pnpm --filter @yan-zhi/server exec tsx ../../tools/audit-learning-courses.ts <课程名>`
