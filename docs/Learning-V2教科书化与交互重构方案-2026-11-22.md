## 1. 目标与非目标

**目标**

1. 教案与题库从 TS 源码中解放出来：可导入、可导出、可独立升级、可按课程包裁剪。
2. 学习路线重构为教科书结构：册/章/节/知识点四级编号，每章有小结与练习，每个知识点有笔记与随堂题。
3. 习题体系扩容：每知识点 3-5 题、每章 10-20 题、每册 1 套综合卷；引入错题库与间隔重复。
4. 交互从「8 个 tab + 多层二级 tab」收敛为「教材页 + 沉浸层 + 今日复习 + 独立图书馆」，一次只做一件事。
5. 保留 `docs/学习模式设计准则.md` 全部硬约束（沉浸层完全盖住总览、一次一步、移动 v1.1 骨架、图书馆独立入口、WCAG AA）。

**非目标**：本轮不改任何课程内容文案；不把第三方有版权资料转成内置教案；不接入新的付费 API；不动 `culture/` 等本轮范围外科目。

## 2. 改造一：教案数据化（内容包 + 导入导出 + 打包可控）

### 2.1 三层内容模型

| 层 | 位置 | 用途 | 谁可写 |
| --- | --- | --- | --- |
| 内置内容包 | `apps/server/assets/content/<packageId>/`（构建期从 `packages/shared/src/learning/**` 导出） | 随包分发的基础课程，按 manifest 白名单决定哪些进包 | 开发者（构建产物只读） |
| 用户内容包 | `%APPDATA%/yan-zhi/content/packages/<packageId>/` + IndexedDB 索引 | 用户导入的第三方/自制课程，覆盖同名包或并存 | 用户（导入/删除/禁用） |
| 服务端库（可选增强） | `data.db` 新增 `course_*` 表 | 跨端同步、全文检索、笔记与错题 | 应用（导入时写入） |

判据：**内容是数据，不是源码**。运行时只读 manifest 注册的内容包，不再直接 import 26 个 TS 常量文件作为唯一真相源。

### 2.2 统一内容包 `.yzcourse`

本质是一个 zip，结构固定：

```
manifest.json          # id/version/title/subject/distribution/license/deps/sha256
courses/<courseId>/
  course.md            # 封面：目标、先修、章节目录、来源
  chapters/01.md       # 章：导语、知识点列表、章末练习、小结
  knowledge/01-02.md   # 知识点：正文 + 笔记区（front-matter 带编号/前置/来源）
  exercises/*.json     # 题目：题型/难度/答案/解析/来源/id
  assets/*             # 图片/音频（相对路径引用）
notes/                 # 整理笔记（公开出处，不冒充引文）
export-manifest.json   # 导出时生成，记录版权与许可
```

- `distribution` 三态：`bundled`（打进安装包）/ `ondemand`（不在包内，运行时提示从内容市场或本地导入）/ `excluded`（只作源码维护、永不分发）。
- 单文件 md 也支持：front-matter 带 `id/title/chapter/knowledge/prerequisites/source`，导入器自动包成一个临时包。
- 校验：manifest 版本号 + 逐文件 sha256；导入失败逐条报「序号 / 名称 / 原因」，一条坏数据不回滚整包（复用书源导入的既有交互约定，`学习模式设计准则.md:150`）。

### 2.3 导入 / 导出

- 入口：总览页顶栏「内容管理」按钮（不是新 tab，是弹窗）；支持选择 `.yzcourse` / `.md` / `.json`，也支持粘贴 JSON。
- 冲突策略三选一：**并存（改 id）/ 覆盖（同 id 高版本）/ 禁用**（保留文件但不注册）。默认「并存」，避免误覆盖内置课程。
- 导出：按包 / 按科目 / 按章节导出；导出产物带 `export-manifest.json`（许可与来源），`excluded` 包和标注「仅授权范围内使用」的素材不导出。
- 导入后必须立刻可在教材目录看到，并能在「内容管理」里看到包版本、文件数、启用开关。

### 2.4 打包源头排除（回答「打包时不包含某些课程」）

现状：三份 `electron-builder.*.yml` 的 `files` 只收 `dist/**`，但 `extraResources` 把 `server/dist` 全量打进去（`apps/desktop/electron-builder.full.yml:29-181`），编译后的 1387 课内容全在包里，且 lite/mac 同构。

改造：

1. 新增 `content.manifest.json`（仓库根或 `apps/server/assets/content/`）：列全部课程包的 `id + distribution`，每包一个条目。
2. 构建脚本 `node apps/desktop/scripts/build-content.mjs --manifest content.manifest.json --out apps/server/assets/content`：只导出 `bundled` 包；`ondemand`/`excluded` 不生成产物。
3. 三份 yml 的 `extraResources` 只收该输出目录（其余 server/dist 照旧）；不得依赖 yml 里逐个手写课程路径——**白名单只有 manifest 一处实现**（避免同一语义多处实现）。
4. 运行时 `getLearningV2Catalog()` 合并「内置包注册 + 用户包注册」，按 `distribution` 与启用开关过滤；被排除的课程在目录里不出现，也不占全局课时编号。
5. 验收：`packaged` 构建后检查 asar/unpacked 目录不存在被排除包的 id 字符串；`dev` 环境下可临时开启全部包用于校对。

### 2.5 迁移路径（保证过程可回滚）

| 阶段 | 动作 | 退出条件 |
| --- | --- | --- |
| M1 | 写导出器：把现有 TS 教案/题目导出为 md + json 包（先编程 + 算法 + 22 科综合题） | 导出包数量、课时数、题数与源码测试断言一致 |
| M2 | 运行时加 content adapter：优先读 manifest 注册包，找不到时回退现有 TS 常量 | 全部既有测试通过（契约 / 挂载 / 构建） |
| M3 | 默认切到内容包；TS 常量仅作为导出器输入，逐步下架 | 22 科教材目录由内容包驱动；导入导出可用 |
| M4 | 删除运行时对 v2-curated 字面量的直接 import，源码仅保留生成器或归档 | 打包体积下降；被排除课程不再出现在产物 |

## 3. 改造二：教科书式学习路线与内容骨架

### 3.1 从「扁平列表」到「教材树」

```
科目（如 编程 / Java）
└─ 册（第一册：语言核心）
   └─ 第 3 章 集合与泛型
      ├─ 3.1 List 与 ArrayList        ← 知识点（有编号、有笔记、有随堂题）
      ├─ 3.2 HashMap 的哈希与扩容
      ├─ 3.3 泛型与类型擦除
      ├─ 本章小结（一张知识图 + 3 条易错）
      ├─ 章末练习（10-20 题，含 2 道手写题）
      └─ 章测（限时可选，默认不计时）
```

- **三级可见**：总览同时只展示「册 / 章 / 节」三层，知识点进入沉浸层后才展开（符合 UX 惯例的 ~3 visible levels + breadcrumb）。
- 全局课时编号保留，但显示格式改为「第 3 章 · 3.2 · 第 128 课时」。
- 章首页四问：本章学什么、学完能做什么、预计多久、下一节是什么（Coursera / MOOC 惯例）。
- 路线 = 教材目录顺序 + 显式先修图（`prerequisites: courseId[]`），主线按顺序推进；已掌握者提供「测一测跳过」（mastery challenge），不硬锁。
- 「继续学习」始终深链到具体章/知识点，不让用户回到目录重新找第 14 课。
- 术语表 / 索引 / 参考文献 / 附录进入教材页右侧抽屉，不占主导航。

### 3.2 每个知识点的固定六件套

1. **目标**（1-2 句可观察目标）
2. **正文**（教案：概念 → 机制 → 例子 → 边界；正文只写学科事实，不写「本步目标」等写作意图）
3. **笔记区**：来源笔记（公版古注逐字 + 篇目 / 整理笔记标注公开出处）+ 我的笔记（可编辑 md）
4. **例题**（至少 1 道带完整解析）
5. **随堂练习**（3-5 题，即时反馈且解释「为什么对/错」）
6. **常见错误**（≥2 条，来自既有契约要求）

章末汇总：本章笔记 + 错题 + 3 道题的「章末复习卡」，一键送入复习队列。

### 3.3 习题体系扩容

| 题型 | 适用范围 | 判分方式 |
| --- | --- | --- |
| 单选 / 多选 / 判断 / 填空 | 全部 22 科 | 自动 |
| 简答 / 手写（含书法/公式/算法推导） | 传统文化、易学、医学、编程、算法 | 自评对照 + 样例答案（不伪装自动判分） |
| 代码 / 填空骨架 / 输出预测 | 编程、算法（复用 4320 题参数化引擎） | 本机运行单测 + 标准输出比对 |
| 排序 / 连线 / 案例分诊 | 算法、医学、网络安全 | 自动 |
| 场景分析 / 授权实战验收 | 网安、架构、工程项目 | 清单式自评 |

- **题量目标**：每知识点 3-5 题；每章 10-20 题（含 2 道手写）；每册 1 套综合卷（30 题）。优先补齐 PF/H/PY/GO 114 门与其余 21 科；已有算法 4320 道参数化题可直接挂到对应知识点。
- 难度三档：识记 / 应用 / 迁移；默认先出识记题，答对再解锁应用题（不是硬门禁，可「看答案后继续」）。
- 提示 Economy：题目 → 提示 → 答案，三级递进；提示消耗少量进度但不会卡死（借鉴 Anki / MOOC 约定）。
- **错题库 + 间隔重复**：错题自动入队，简化 FSRS/SM-2（interval 1d → 3d → 7d → 16d → 35d，答错回退一档）；「今日复习」按到期队列生成，不按课程 all 题轮询。复用已有 `learning_lesson_progress` 表新增 `learning_review_card` 表（本地 IndexedDB 为真相源，服务端只备份）。
- 所有题目必须带 `source`（原创 / 公版 / 开放许可 / 官方外链）与 license，禁止无出处抓取题面。

## 4. 改造三：交互重构（去 tab，做教科书）

### 4.1 当前 → 目标映射（入口做减法）

| 现在的入口 | 去向 |
| --- | --- |
| overview / roadmap 两个 tab | 合并为一个「教材页」：左目录树 + 右章首页/节页 |
| lesson tab | 取消，改为从教材页点知识点进入页内放大的学习面板（视图切换，非弹窗） |
| studio tab | 取消一级入口，作为知识点的「实训」步骤存在 |
| practice tab | 取消一级入口，改为知识点随堂题 + 章末练习 + 章测 |
| review tab | 保留为一级「今日复习」（到期卡片 + 错题，一屏任务列表） |
| coach tab | 取消 tab，改为沉浸层内按需唤起的侧栏助手 |
| books tab | 从学习页移出，恢复顶栏独立「图书馆」入口（发现/书架/书源三区） |
| 各工作台内部 4/5/7 个二级 tab | 用教材树的「节」替代；保留必要模式切换为同一行 chips，不超过 4 个 |

**结果：一级入口从 8 个降到 3 个（教材 / 今日复习 / 我的）+ 顶栏 1 个独立图书馆。**「我的」收敛笔记、错题、进度、内容管理（导入导出/包开关）。

### 4.2 三个核心界面

1. **教材页（总览层）**：左栏为**可拖宽、可收起**的教材目录树（章带完成标记与进度 3/7），右栏为当前章首页/节页；顶部面包屑「科目 / 册 / 第 3 章 / 3.2」；「继续学习」唯一大卡直达上次知识点；阶段标题可折叠并显示序号。
2. **学习面板（页内放大，非弹窗）**：从教材页点知识点后，学习面板在**当前页面内容区内展开**，像浏览器最大化一样占满工作区；顶部应用导航保留，教材总览层从视图中撤出（同一时间只渲染一个视图），**不加 fixed 遮罩、不做 `inert + aria-hidden`、不弹独立窗**。标题栏保留四项（返回教材 / 课程名 / 步骤 x/n / 退出），另有「放大 / 还原」开关。正文定宽居中，一次只显示一个步骤，底部固定「上一步 / 记笔记 / 下一步」。
3. **今日复习页**：任务型列表（到期卡片数、连续天数、预计分钟），点开即进入单卡问答（先回忆 → 翻面 → 自评「记得/模糊/忘了」→ 自动排期）；错题可跳回原知识点。

### 4.2.1 面板尺寸与收起（本次评审新增，三处统一行为）

| 面板 | 位置 | 行为 |
| --- | --- | --- |
| 教材目录 | 教材页左栏 | 右边缘拖拽手柄调宽（34–340px）；点「收起」缩成 34px 窄轨（竖排「教材目录」），点窄轨展开 |
| 章节目录 | **学习面板内左侧** | 同上；显示当前册/章/节/知识点编号与完成标记，点击任意节点即跳到对应知识点（不退出学习面板），是当前进度的快速定位器 |
| 笔记抽屉 | 学习面板内右侧 | 左边缘拖拽手柄调宽（34–340px）；点「收起」缩成窄轨，点窄轨展开；默认收起，按需展开 |

统一实现口径（避免三处各写一套）：
- 抽一个通用可调整面板组件（如 `ResizablePane.vue`），props = `side`（left/right）、`min/max/default`、`storageKey`；三处只传参数。
- 拖拽用 Pointer Events + `setPointerCapture`；键盘用方向键调宽（无障碍）；拖拽时正文区最小宽度保护（低于阈值停止收缩）。
- 宽度与收起状态存本地偏好（key 形如 `yz.learning.pane.<name>`），重进恢复；切换科目/课程不重置。
- 移动端（≤900px）不提供拖拽：目录与笔记改为 bottom sheet（沿用准则第 5 条），学习面板仍替换总览视图而非浮层。

### 4.3 移动端
