### 自动验收的边界说明

- 补帧实测时长 1.833s（非 2.000s）是 `minterpolate` 尾帧取整所致，与仓库既有 e2e 容差一致；**未放宽断言**。
- 字幕 11 种只验「能被 libass 接受并出片、时长正确、画面可抽帧、入场帧互异」，**不替代观感**（方向/幅度/是否飞出画面需人工）。
- 抠像用合成「黑底白矩形」验证 **链路正确性**（蒙版识别前景、背景替换、音轨保留），**不代表真实人像抠像质量**（U2Netp 精度低，发丝/多人/快速运动未验）。

## 五、无法自动验证的原因（如实列出）

| 项 | 原因 |
|---|---|
| 表 B 全部 UI 交互 | 需要 Electron/浏览器界面：拖动、弹窗、滑杆、切点把手手感、角标与提示文案，headless 无法替代 |
| 剪口播端到端 | 需要 whisper 模型 + 真实口播素材；本轮未确认本机 whisper 模型就绪，且 ASR 是重 IO，不在自动验收里跑 |
| 录音 | 需要真实麦克风与权限弹窗，无法在测试进程内模拟授权/释放 |
| 11 种动画观感 | 自动验收只证明「能烧录/时长对/入场帧不同」，方向、幅度、是否飞出画面属主观观感，需人眼 |
| 智能竖屏真实效果 | 自动验收用合成人脸框验证纯函数；Haar 对侧脸/背影/遮挡的漏检率必须用真人素材 |
| 抠像真实质量 | 自动验收用「黑底白矩形」验证链路；U2Netp 对发丝、多人、快速运动的精度未验，也不代表换模型后的效果 |
| 补帧伪影/耗时 | 合成 testsrc2 只能验帧率与时长；拖影/果冻与 1080p 实际耗时需真实题材素材与计时 |
| 美颜主观强度 | 高频能量下降只能证明“柔化了”，肤色/多人小脸/与字幕叠加的观感需人眼 |
| 多机位真实对齐 | 自动验收用合成音频；真实双机位含音乐/噪声时的互相关失准与切点观感未验 |
| 模型下载 | 本轮未触发网络下载（避免联网与写用户数据目录）；镜像可用性/校验/许可展示需人工在应用内点一次 |
| 剪映草稿导出新动画 | shake/wipe/flip3d 有意不映射 `JY_TEXT_INTRO`，草稿打开后无入场动画属已知设计，不是缺陷 |

## 六、结论

- 自动验收 **13/13 通过，0 跳过，0 失败**；能力链路（ASS 动画、补帧滤镜与出片、美颜柔化、多机位对齐/编排/重建、竖屏窗口与轨迹、音效匹配、真实模型抠像合成）均有实测证据。
