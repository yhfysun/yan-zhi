## 说明

- petdex 的宠物页与下载包（`zip.zip`）**不携带许可字段**；提交时作者自选
  CC0 / CC BY / CC BY-SA / 非商用 / 保留所有权利，但该字段未公开在页面上。
  需要用作者账号登录后的 `/api/pets/<slug>` 才能看到（未登录返回 401）。
- 新增三只猫系形象仅使用 petdex 社区开源包，**没有复制第三方产品截图里的角色**。
- 若要对外分发：先补齐上表「作者 / 许可」两列；仍无法确认的包从 `catalog.json` 移除即可
  （`pet-assets.ts` 按 catalog 与文件是否存在降级，不会崩）。
