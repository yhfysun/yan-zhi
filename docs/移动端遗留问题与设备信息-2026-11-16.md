### 连接方法

1. **端口每次开关「无线调试」都会变**（30000-49999 随机）。已配对设备直接：
   ```
   adb connect <ip>:<当前端口>
   ```
   当前端口看手机「开发者选项 → 无线调试」页面，或电脑上扫描：
   ```bash
   python -c "..."  # 见下（并发扫描 30000-50000）
   ```
2. **息屏/锁屏后无线调试会停** → 连接被拒（积极拒绝/超时）属正常，亮屏后端口可能也变，重新扫。
3. **mdns 不可用**（Windows 上 `adb mdns services` 大概率为空），别指望自动发现。
4. **扫描脚本**（把 IP 换掉）：
   ```python
   import asyncio
   async def probe(port, sem, out):
       async with sem:
           try:
               r, w = await asyncio.wait_for(asyncio.open_connection('192.168.5.X', port), timeout=0.35)
               out.append(port); w.close()
           except Exception: pass
   async def main():
       sem = asyncio.Semaphore(1000); out = []
       await asyncio.gather(*[probe(p, sem, out) for p in range(30000, 50000)])
       print('open:', sorted(out))
   asyncio.run(main())
   ```
5. **新设备配对**：手机「无线调试 → 使用配对码配对设备」弹窗（**30 秒过期**）→
   `adb pair <ip>:<配对端口> <6位码>`（配对端口 ≠ 主端口，弹窗上写着）。
6. **★ 大坑：沙箱/工具环境里 `adb pair` 会 protocol fault** —— 必须在非沙箱（提权）环境执行。
   Git Bash 还会把 `/data/...` 转成本地路径，`adb push` 要加 `MSYS_NO_PATHCONV=1`。
7. 常用诊断命令（每条 shell 前都要 `adb connect` 先，daemon 会掉）：
   ```bash
   adb -s <ip:port> shell "netstat -tln | grep 3001"     # 内嵌后端是否监听
   adb -s <ip:port> shell "run-as com.yanzhi.mobile ls files/capawesome_nodejs/yan-zhi-data/logs/"
   adb -s <ip:port> shell "logcat -d --pid=$(adb -s <ip:port> shell pidof com.yanzhi.mobile)"
   # 后端日志同时落盘：yan-zhi-data/logs/server-YYYY-MM-DD.log（最可靠的证据源）
   ```
8. **CDP 直连 WebView**（读 pinia 内存态/页内 fetch，比截图猜快一百倍）：
   ```bash
   SOCK=$(adb -s <ip:port> shell "cat /proc/net/unix" | grep -o "webview_devtools_remote_[0-9]*" | head -1)
   adb -s <ip:port> forward tcp:15322 localabstract:$SOCK
   # 然后用仓库里现成的 tmp/cdp-eval.py "<js表达式>"
   ```
