# 内置数据「恢复默认」与「升级覆盖打包参数」—— 实施说明

> 状态：已实施
> 配套：`YZ_BUILTIN_OVERWRITE` 环境变量 + reset 接口 + 前端「恢复默认」按钮。

---

## 一、背景

内置 agent（默认助手 / pageAgent / dataAgent）与内置 skill 的提示词、工具挂载、文档，在安装时由 seed 初始化进库。用户后续可能手动改动它们。此前存在两个问题：

1. **无恢复入口**：用户改坏了内置提示词/文档后，只能重装或走升级迁移，无法一键还原默认。
2. **覆盖策略硬编码**：内置 pageAgent/dataAgent 的提示词在升级时被无条件 `force_sync` 覆盖，几个自动化 skill 的 body 也被无条件覆盖，用户自己的改动会在升级时丢失，且无法配置。

---

## 二、改动一：升级覆盖由打包参数控制

新增环境变量 **`YZ_BUILTIN_OVERWRITE`**，三档取值：

| 取值 | 行为 |
|---|---|
| `always`（默认） | 内置 agent/skill 定义以代码为准，启动时强制覆盖旧库（历史行为，向后兼容） |
| `never` | 永不覆盖用户对内置项的改动（用户改了保留） |
| `migrate` | 仅新增缺项 / 补空，不覆盖已存在的内置项（最保守） |

**传递链路（无需额外代码）**：
- Electron 主进程 `main.cjs` 启动内置后端时 `env: { ...process.env, ... }` 已透传。
- 因此在**打包时**（CI/构建脚本）注入 `YZ_BUILTIN_OVERWRITE=never`，或**运行时**（快捷方式/启动器）设置该变量，即可控制升级覆盖策略。

**接入点**（`apps/server/src/db.ts`）：
- `seedAgents` 的 `force_sync` 分支（pageAgent/dataAgent）
- `skill_web_task_automation` / `skill_jimeng_daily_checkin` / `skill_ontology_query` 三个内置 skill 的无条件覆盖分支

---

## 三、改动二：内置数据「恢复默认」

### 后端
- `apps/server/src/db.ts`：
  - `builtinSkillDefaults`（30+ 批量内置 skill）、`ONTOLOGY_QUERY_DESC/BODY` 提升为模块级导出常量（数据单一来源）。
  - 新增 `resetBuiltinAgent(id)` / `resetBuiltinSkill(id)` 导出函数，恢复 seed 默认值。
- 新增接口：
  - `POST /api/agents/:id/reset`（`apps/server/src/routes/agents.ts`）
  - `POST /api/skills/:id/reset`（`apps/server/src/routes/skills.ts`）

### 前端（双库同步）
- `packages/ui/src/stores/agent.ts` 新增 `resetAgent(id)`：恢复本地库的内置 agent 默认值（`DEFAULT_AGENT_DATA` / `PAGE_AGENT_DATA` / `DATA_AGENT_DATA`），并 try 调后端 `/agents/:id/reset` 同步 server 库。
- `packages/ui/src/components/AgentEditDialog.vue` 底部新增「恢复默认」按钮（仅内置/默认智能体显示，二次确认后恢复并回填表单）。

> 说明：本项目是「双库」架构——前端 UI 读本地库（桌面 yan-zhi.db / web Dexie），server seed 在 data.db。故恢复默认需双端兼顾，已同时落。

---

## 四、改动三：agent / skill 提示词同步优化

配合「list_models 选型 + call_agent 指定模型 + 浏览器降级」，双端（`apps/server/src/db.ts` + `packages/ui/src/stores/agent.ts`）同步：

1. **默认助手**新增【模型选型】块：任务需特定模型能力时先 `list_models` 查询，再 `call_agent` 传 `platformId`+`modelId`。
2. **pageAgent**「核心工作方式」补充：index 失效会自动降级（`autoRelocated`）；DOM 拿不到弹窗结构时用 `browser_screenshot(annotate=true)` 视觉兜底。
