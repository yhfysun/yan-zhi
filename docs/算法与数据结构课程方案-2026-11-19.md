# 算法与数据结构独立学科方案

## 1. 学科定位

“算法与数据结构”是 Learning V2 第 21 个独立学科，和“编程”同级，不走编程科目的课程卡，也不并入数学或软考。

编程科目保留必要的简单算法与数据结构：数组、哈希、栈队列、基础树图、复杂度、测试与递归。完整算法体系、题型族、竞赛专题和大量实战放到本学科，避免编程课被算法淹没，也避免算法课只讲竞赛。

核心目标不是让学生背模板，而是：

1. 能把题面故事讲清楚。
2. 能画出表、树、图或状态。
3. 能从小数据手算出方法。
4. 能写出可运行代码。
5. 能解释复杂度、反例和失效条件。
6. 能把同一方法迁移到新故事。

## 2. 易学优先原则

- 默认从入门题开始，难度按“入门 → 进阶 → 困难 → 竞赛”排序。
- 每讲先讲故事，不先甩术语。
- 每道题分七步：故事任务、画图猜法、填空骨架、代码实战、手算找坑、过关证明、换个故事。
- 每步只显示当前内容，不一次倾倒题目、答案、代码和复杂度。
- 提示要逐步出现；先给观察方向，再给伪代码，不给“抄完就结束”的完整答案。
- 竞赛题和高级结构放在后段，是扩展方向，不是入门门槛。

## 3. 故事化学习主线

| 阶段 | 故事场景 | 核心能力 |
| --- | --- | --- |
| A0 复杂度、正确性与测量 | 小店排班、库存和订单记录 | 估算工作量、画表、写不变量 |
| A1 线性结构、哈希与窗口 | 快递分拣站 | 排队、合并、最近一单、窗口移动 |
| A2 树、堆、排序与索引 | 图书馆排架和预约 | 搜索、有序性、优先级、范围查询 |
| A3 图论、搜索与最短路 | 地铁、道路和临时封路 | 换乘、依赖、最短路径和连通块 |
| A4 DP、贪心与回溯 | 旅行队、背包和路线选择 | 子问题、选择、状态和反例 |
| A5 高级结构与竞赛 | 竞赛教练的百宝箱 | 线段树、Fenwick、分块和离线 |
| A6 面试与题型变形 | 换装面试现场 | 识别同型题和假同型题 |
| A7 工程算法与性能 | 大促缓存、队列和分片 | 吞吐、延迟、内存与回滚 |

每个阶段 8 讲，共 64 个系统课程。

## 4. 系统课程结构

每讲固定 6 步：

1. **拆题意与输入规模**：把故事中的角色、对象、动作和目标找出来。
2. **手算、追踪与不变量**：只拿 8 个元素手算，记录状态变化和终止条件。
3. **从模型到可读实现**：先写伪代码，再写正式代码，保留索引和边界语义。
4. **题型族与迁移**：比较同型题、变体和不可用条件。
5. **复杂度、反例与优化**：用基线、profile、基准测试证明瓶颈。
6. **工程与竞赛验收**：加入真实资源约束、错误输入、在线更新和对拍。

每讲都有前置知识、可观察目标、跟做任务、完成检查、三个常见错误和官方来源。

## 5. 题库设计

### 5.1 规模

- 12 个核心题型族。
- 6 个生活/工程故事场景。
- 5 种数据与资源约束。
- 4 个难度等级。
- 3 种输出要求：最优值、方案恢复、方案计数。
- 总计 `12 × 6 × 5 × 4 × 3 = 4320` 道原创参数化变体。
- 其中 240 道标为精选题族，用于先建立模板和迁移感。

### 5.2 题型类型

| 类型 | 用途 |
| --- | --- |
| 热门题 | 面试和课程中最常见的模型 |
| 经典题 | 必须理解来源、证明和变体的基础题 |
| 竞赛题 | 时间限制、构造、对拍和高级结构 |
| 冷门模型 | 不常出现但能补全算法观的模型 |
| 工程算法 | 缓存、调度、检索、分片和真实资源预算 |

### 5.3 难度

- 入门：数据小、目标单一、先用手算或暴力。
- 进阶：需要选择结构、排序、哈希或简单 DP。
- 困难：多种条件组合、优化或恢复方案。
- 竞赛：大输入、在线更新、对拍和实现风险。

### 5.4 每道题都包含

- 故事场景和角色任务。
- 输入、输出、资源限制。
- 模型和相邻题型。
- 参考策略和三级提示。
- 伪代码骨架。
- 时间/空间目标。
- 三个易错边界。
- 一个换条件后的变体。
- 四点验收清单。
- 原创声明与同型平台使用建议。

不复制第三方原题全文，只提供第三方官方题库入口。

## 7. 交互与布局

- “系统课程 / 原理动画 / 题型实战 / 外部题库”四段切换。
- 题库支持关键词、阶段、题型和难度筛选。
- 桌面两列题卡，移动单列。
- 每页 24 道，避免一次渲染 4320 个 DOM 节点。
- 题目实战使用全屏单步工作台。
- 进入实战后底层应用 `inert + aria-hidden`，焦点只在当前步骤循环。
- Escape 或返回按钮退出，并恢复原来的题目列表和触发元素。
- 触控目标不小于 44px，320px 不得横向溢出。

### 7.1 原理动画

- 动画覆盖 10 个入口：冒泡排序、二分查找、链表反转、栈与队列、二叉树层序遍历、图 BFS、最大堆、哈希表、编辑距离与滑动窗口。
- 每个场景提供播放、暂停、上一帧、下一帧、进度拖动、0.5× / 1× / 1.5× / 2× 速度和重置。
- 每一帧同时显示当前操作、状态变化、叙述和循环不变量；下方固定展示该过程对应的代码与复杂度。
- 颜色只作辅助，当前、已完成、待访问等状态必须同时带文字标签；播放遵循 `prefers-reduced-motion`。
- 动画不是装饰：帧序必须真实反映指针、队列、访问集合、DP 表或窗口边界的变化。

### 7.2 应用内代码实战

- 单题第 4 步直接显示代码编辑器，不需要切到外部 IDE。
- JavaScript/Node.js 使用应用内置运行时，Python 优先使用安装包内置解释器，也可回退本机 Python。
- Java、C、C++ 只有在探测到完整 JDK/GCC/Clang 工具链时启用；缺环境时明确显示不可用原因。
- 支持代码草稿、stdin、运行、编译输出、stderr、退出码、耗时和超时状态。
- 代码草稿按“题目 + 语言”保存在 `yz.algorithms.code.v1`。
- 运行目录使用系统临时目录，源代码最多 128 KB、输入最多 64 KB、输出最多 64 KB，运行最长 6 秒。
- 代码以当前系统用户权限在本机运行，UI 必须显式提示只运行可信代码。
- 代码运行、环境探测和训练工程写入接口只接受本机回环请求；局域网远程访问不能调用这些接口。
- 这是本机学习运行器，不冒充在线判题：不会替学生伪造测试通过，也不执行第三方题库原题抓取。

## 8. 进度与练习记录

- 题目完成状态保存在本地 `yz.algorithms.problem-progress.v1`。
- 课程学习进度沿用 Learning V2 的 lesson-progress。
- 完成题目至少留下：代码、手算表、反例、复杂度、基准或迁移记录。
- 代码运行器已经接入；后续可继续增加强隔离判题沙箱、错题本和间隔复习。

## 9. 验收

- 21 个学科均可进入。
- 算法学科有 8 阶段、64 讲、4320 道变体。
- 原理动画覆盖 10 类核心结构/算法，且桌面和 320px 移动端均可完整操作。
- 每讲为 6 步完整教案，来源可追溯。
- 单题可直接写 Node/Python，并在探测到工具链时运行 Java/C/C++。
- 默认入门优先，热门、经典、冷门、竞赛和工程题型均可筛选。
- 1440、1024、430、390、375、320 无横向溢出。
- 全屏解题一次只显示一个步骤。
- Shared 内容契约、AlgorithmWorkbench 挂载测试、LearningV2 挂载测试和生产构建通过。
