# 本地模型网关

## 定位

言智本地模型网关把当前账号可用的模型、候选池和健康路由以 OpenAI 兼容接口开放给本机工具。
网关不读取外部应用的模型密钥，也不允许外部客户端指定任意供应商或平台。

默认只允许本机回环地址访问。确需远程访问时，必须显式设置
`YZ_GATEWAY_ALLOW_REMOTE=1`，并由部署方自行增加网络层访问控制。

## 接口

Base URL：

```text
http://127.0.0.1:<后端端口>/gateway/v1
```

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/health` | 网关存活检查，不需要密钥 |
| GET | `/models` | 当前密钥可用的模型列表 |
| POST | `/chat/completions` | OpenAI Chat Completions；支持流式、工具调用、JSON 输出 |
| POST | `/responses` | OpenAI Responses；支持流式与 function call output |
| POST | `/messages` | Anthropic Messages；支持流式与 tool_use/tool_result |
| POST | `/embeddings` | OpenAI Embeddings |

当前暂不支持图片输入；图片、视频生成仍应走言智原生工具。

## 鉴权

设置 → 服务与连接 → 本地网关创建客户密钥。明文 `yzg_...` 只在创建时返回一次，
数据库只保存 SHA-256 哈希。

```http
Authorization: Bearer yzg_xxx
```

密钥绑定创建者账号，可独立配置：

- 模型白名单：`*` 表示全部；`auto` 表示只允许自动路由；也可填写模型 ID。
- 每日 token 上限。
- 每日费用上限，单位人民币。
- 每分钟请求数上限。
- 启用状态和过期时间。

## 模型名

- `auto`：使用当前账号的全局候选池和健康优先/顺序优先策略选择模型。
- 模型的言智主键、API 模型名或别名：解析到当前账号可用的具体模型。

如果同名 API 模型存在于多个平台，网关按默认模型和创建时间选择最近的一条；
需要精确指定平台时，应使用言智模型主键。

## 调用示例

```bash
curl http://127.0.0.1:3001/gateway/v1/chat/completions \
  -H "Authorization: Bearer yzg_xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "auto",
    "messages": [{"role": "user", "content": "你好"}],
    "stream": false
  }'
```

```bash
export OPENAI_BASE_URL=http://127.0.0.1:3001/gateway/v1
export OPENAI_API_KEY=yzg_xxx
```

## 审计与限额

每次网关请求写入 `gateway_usage`，记录协议、请求模型、实际平台/模型、状态、token、
缓存 token、费用、估算标记、耗时和错误码。成功请求同时写入言智主费用账本，
来源为 `gateway`。

每日 token 达到上限时返回 HTTP 429；每日费用达到上限时返回 HTTP 402；
每分钟请求数超限时返回 HTTP 429 并带 `Retry-After: 60`。
