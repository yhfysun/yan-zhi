# UI 下一阶段任务描述（2026-11-02）

> 用途：直接作为新会话的任务说明。目标不是继续抠细节，而是把「桌面应用骨架」和「办公模式」补齐。
> 现状基线：聊天页视觉 A（760 阅读列 / 卡片 / 块级区分）、会话两行列表、侧栏标签三级降级、右上下文栏默认开、底部状态栏、任务按模式隔离，均已完成。

---

## 一、P0：一致性收尾（1–2 天，先做）

这几项是上一阶段留下的不一致，影响日常使用。

1. **归档 / 回收站按模式过滤**
   - 现状：主列表已按 `mode` 过滤，归档与回收站仍是跨模式。
   - 位置：`packages/ui/src/composables/chat/useChat.ts` 的 `loadLifecycleLists` 与 `archivedConversations / trashedConversations`。
   - 验收：开发模式打开归档，看不到办公模式会话。

2. **切换模式时当前会话的归属**
   - 现状：`currentConvId` 各模式共用，切到开发后聊天区可能还显示办公会话。
   - 目标：当前会话不属于新模式时，聊天区切到"新任务"空态（不串台），旧会话保留在列表外。
   - 位置：`stores/mode.ts` 的 `setMode` / `router` 的模式同步逻辑。

3. **状态栏模型名**
   - 现状：显示模型 id（如 `e8aa6005-…`）。
   - 目标：显示模型展示名或平台名，取不到则隐藏该项。
   - 位置：`packages/ui/src/components/AppStatusBar.vue`。

4. **未命名任务行**
   - 现状：新建后未命名的会话在侧栏是空行，只剩右侧计数/时间。
   - 目标：显示「未命名任务」占位，点开后再由首条消息自动命名。
   - 位置：`ChatSidebar.vue` 的 `conv.title` 渲染兜底。

5. **移动端与暗色回归**
   - 390 / 768 两档截图；`data-theme=dark` 下检查无白块、无不可读文字。

## 二、P1：桌面骨架（3–4 天）

目标：让所有页面共享同一副固定框架，而不是整页上下滚。

1. **统一页面骨架 PageFrame**
   - 结构：固定页头（标题 + 一句说明 + 右侧操作）→ 固定工具条（搜索 / 筛选）→ 内容区自滚。
   - 先落地 4 个高频页：`views/Models.vue`、`views/Agents.vue`、`views/ToolMarket.vue`、`views/Skills.vue`。
   - 验收：滚动时页头与工具条不动；1600 与 1280 两档都不出现双滚动条。

2. **管理页分栏**
   - 列表 + 右侧详情（可拖拽宽度），详情用容器而不是跳页。
   - 复用现有 `composables/useResizable.ts`。

3. **窗口与状态记忆**
   - 窗口尺寸/位置、上次所在模式、侧栏与右栏宽度、列表滚动位置。
   - 位置：`apps/desktop/main.cjs`（窗口）+ 各 `useResizable` 的 storage key。

4. **快捷键**
   - `Ctrl+K` 命令面板（已有 CommandPalette，补命令条目：切换模式、新建任务、打开设置、切换面板）。
   - `Ctrl+B` 折叠侧栏、`Ctrl+J` 切换右栏、`Ctrl+N` 新建任务。

## 三、P2：办公模式产品化（5–8 天）

1. **办公工作台骨架**
   - 左：文件树（工作目录）｜中：编辑器 / 预览｜右：AI 助手。
   - AI 模式 = 现在的聊天界面保持不变；人工模式 = 右栏收起，文件改动全部走本地操作。
   - 参考原型：`docs/mockup-desktop-frame-2026-10-31.html`。

2. **AI / 人工切换**
   - 入口：右栏头部 segmented + 底部状态栏同步显示当前模式。
   - 人工模式下不调用任何模型（发送入口隐藏或禁用）。

3. **办公三件套 CRUD**
   - 新建 docx / xlsx / pptx、重命名、复制、删除、导出。
   - 后端统一文件接口（python-docx / openpyxl / python-pptx），前端三套视图：文档 / 表格 / 演示。
   - AI 与人工共用同一套接口，AI 只是在上层发起操作。

---

## 四、P3：观感收尾（随批次做）

- Element Plus 组件统一：按钮、表格、空态、下拉、分页。
- 图标一致性：同类动作使用同一套图标（新建 / 更多 / 关闭 / 刷新）。
- 暗色皮肤逐页回归，禁止硬编码 `#fff` / `rgba(15,23,42,…)`。
- 动效统一：hover 120ms、面板展开 200ms、统一 `ease-out`。

---

## 五、验收与验证方式

- 类型检查：`cd packages/ui && npx vue-tsc --noEmit`（当前有 2 个既有的 ClipWorkbench 报错，勿误判为新引入）。
- 测试：`npm run test -- --no-file-parallelism`（并行模式有计时敏感误报）。
- 截图验收：1600 / 1280 / 390 三档 + 暗色；每次改动后至少截聊天页与一个管理页。
- 不重启用户正在跑任务的应用；渲染层改动走 HMR，后端改动另起 3101 + 独立 DATA_DIR 验证。

## 六、已知风险

- 多会话共用工作区：提交前 `git status` 核对自己的文件，避免把别人的在途改动带进提交。
- 预览服务器会抢占共享 Vite 依赖缓存：验证用独立 `cacheDir`，不要直接起第二个默认 vite。
- 模式隔离属于数据口径改动：改完要检查新建任务、置顶、空间计数、归档/回收站四条链路。
