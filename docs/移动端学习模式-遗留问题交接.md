## P0-1 科目切换残留英语内容（真机截图实锤）

- **现象**：从「软考」切到「网络安全」，中栏顶部是网安的 tab（安全路线/实操台），下面却渲染着英语主线内容（场景练习/自由开口按钮、零基础 track chips、「1. 字母名≠字母音」小节下拉、0/137 课进度）。
- **根因（已定位）**：`packages/ui/src/views/Learning.vue` `switchSubject()`（约 L383-441）分支优先级错误：
  ```ts
  if (key === '软考') { ... }
  else if (wasSoft) { tab.value = 'path'; }        // ← 从软考切网安时命中这里
  else if (key === '网络安全') { tab.value = 'security'; ... } // ← 永远轮不到
  ```
  切换方向「软考 → 网络安全」时 `wasSoft=true` 抢先把 tab 设为 `path`，网安分支不执行。
- **修法**：按**目标科目**先分流（switch on key），`wasSoft/wasSecurity` 只做旧科目状态清理（右栏宽度、securityFocusing 等），不要决定目标 tab。
- **验收**：任意科目两两互切（至少 软考↔网安、英语↔周易、网安↔英语），中栏永远是目标科目内容；补一条守卫测试断言 switchSubject 内「目标 key 分支先于 wasXxx 分支」。

## P0-2 原生 select 下拉丑（用户实报「下拉框什么玩意丑不拉几」）

- **修法建议**：抽一个通用 `LearningSelect.vue`（放在 `packages/ui/src/components/learning/`），照抄 SubjectPicker.vue 的 button + popover 模式（带 aria combobox/listbox、键盘导航、group 分组支持），替换上述五处。视觉对齐设计稿 mobile-learning-redesign.html：白底药丸、粗体、主题色边、caret。
- **注意**：吸顶层叠已定为「课程条 sticky top:6px（Learning.vue 左栏卡片）、小节/路径条 sticky top:64px（各工作台内）」，替换组件后保持这个关系；popover 用 absolute 定位（老 WebView 兼容，禁 :has()/fixed 新依赖）。
- **验收**：手机上点开是 App 内浮层（非系统弹窗），触摸目标 ≥44px，桌面端选择器外观零变化（组件内部按视口条件渲染）。

## P0-4 TTS 无声（代码已接好，真机验证被环境卡住）

- **链路**：前端 speak() → `nativeSpeak`（packages/ui/src/utils/nativeTts.ts）→ YzTts 插件（TtsPlugin.java）→ 系统 TextToSpeech → 失败兜底 **SherpaTts 内置引擎**（sherpa-onnx 1.10.35 AAR + piper en_US-amy-medium int8，APK 内 ~35MB assets）。
- **已修的坑**：sherpa 不能直接 `newFromAsset`——espeak-ng-data 目录内部用标准文件 IO，必须先递归拷 assets → filesDir 再按真实路径 `new OfflineTts(null, config)`（SherpaTts.java L63-120，copyAssets）。旧包就是死在这。
- **验证状态**：logcat 已确认插件加载、系统引擎 onInit status=-1（一加无 TTS 引擎）、兜底分支已编译；但「内置引擎初始化成功 + 实际出声」尚未在真机上完成验证（adb 无线连接极不稳定，CDP 探测被 adb daemon 反复重启打断）。
- **验证步骤（给 Codex）**：
  1. 装 APK：`adb connect 192.168.5.77:35531; adb -s 192.168.5.77:35531 install -r dist-release/android/0.1.1/app-debug.apk`（连接+执行必须同一条命令，adb daemon 每次调用重启）。
  2. 扩缓冲：`adb -s <dev> shell "logcat -G 4M; logcat -c"`。
  3. 触发：在手机上点任意朗读按钮（学习→英语→任一课→「跟着演示拼一遍」），或 CDP：`adb forward tcp:15322 localabstract:webview_devtools_remote_<pid>` + `python tmp/probe-cdp.py`（tmp/probe.js 已写好 YzTts.speak 直调；forward 必须与执行同命令）。
  4. 判读 logcat `YZTTS`：应依次出现「sherpa 模型拷贝 assets → filesDir」「sherpa 内置引擎就绪」「sherpa 合成完成」「内置引擎朗读完成」。若「初始化失败」→ 查 assets 是否打进 APK（`apply-native-sherpa.cjs` 日志 + `adb shell ls assets/sherpa-en`）。
  5. 若内置引擎出声但用户点某些按钮仍无声 → 那些按钮走**随包音频文件**（phonicsAudioSrc/blendAudio，不走 TTS），查音频资源在移动端是否可加载（file:// + absoluteMediaSrc 链路）。
- **设备**：一加 192.168.5.77:35531（无 TTS 引擎，tts_default_synth=null）；红米 K60 192.168.5.2:39781（自带小米引擎 com.xiaomi.mibrain.speech，但 MIUI 需开「USB 调试（安全设置）」才允许 adb 注入点击）。
- **验收**：一加无引擎也能出声；logcat 全链无静默失败。
