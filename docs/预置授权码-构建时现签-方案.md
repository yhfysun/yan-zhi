# 预置授权码：构建时现签方案

> 状态：方案（拍板 2026-10-03：方案 A——构建时现签，源码不再存码）
> 关联：`scripts/gen-license.mjs`（签发脚本，私钥 `scripts/license-private-key.pem` 不进 git）、`apps/server/src/license.ts`（`DEFAULT_LICENSE_BY_EDITION` 常量）

## 1. 背景

三档预置试用码**写死在 `license.ts` 源码里**，expireAt 全为 `2026-12-18T15:59:59Z`（90 天口径，2026-09-19 签）。两个问题：

1. **2026-12-18 后所有新安装包"开箱 90 天试用"直接失效**，且无任何告警。
2. `license-edition.test.ts` 的时长断言因此改为时间不变量（`expireAt − LICENSE_SIGNED_AT`）——只要不重签，测试永远红不了，但也永远提醒不了"快到期了"。

## 2. 方案：打包时现场签发

### 2.1 流程

```
electron-builder 打包
  → 前置步骤（scripts/prepare-server-runtime 或新增 scripts/pre-sign-license.mjs）：
      ① 检查 scripts/license-private-key.pem 存在
         缺失 → **明确报错中止打包**（与 python 运行时缺失同口径：不再静默降级）；
                逃生舱 YZ_SKIP_LICENSE_SIGN=1 显式声明跳过
      ② 逐档位调 gen-license.mjs --days 90 --edition lite|basic|pro
         （★ gen-license 补一个 --out 参数直接输出 JSON，避免解析 stdout）
      ③ 产物写入 <build>/resources/license/default-codes.json：
         { "signedAt": "2026-10-03T…", "lite": "…", "basic": "…", "pro": "…" }
  → 运行时：license.ts 启动时优先读 resources/license/default-codes.json
         文件缺失/解析失败 → 回退现有源码常量（向后兼容存量包）
```

### 2.2 改动点

| 改动 | 文件 |
|---|---|
| 签发脚本支持 `--out <file>` JSON 输出 | `scripts/gen-license.mjs` |
| 打包前置：现签 + 写 JSON + 缺私钥报错 | 新 `scripts/pre-sign-license.mjs`，接入 `electron-builder.{lite,full,mac}.yml` 的 beforePack/afterPack 钩子与 `prepare-server-runtime` |
| 运行时读取优先级：资源文件 > 源码常量 | `apps/server/src/license.ts`（新增 `loadBundledCodes()`，三档常量保留作回退） |
| payload 增加 `signedAt` 字段 | `gen-license.mjs` + `LicensePayload`（可选字段，存量码无此字段照常验签） |
| 测试改回动态口径 | `test/license-edition.test.ts`：`LICENSE_SIGNED_AT` 改读 `signedAt` 字段（文件里有就用，没有回退现常量） |
| 到期告警 | 服务端启动时若预置码剩余 < 14 天，console.warn + 设置页横幅（兜底：有人用旧流程打包时能看见） |

### 2.3 关键决策点

- **私钥只在签发机**：打包机必须有 `license-private-key.pem`（git 外分发，与现在签发授权码的要求一致）；CI 不打包商用包（只跑测试），不受影响。
- **存量包回退**：已发货的包读不到 JSON，走源码常量——2026-12-18 前发货的包行为不变。
- **测试不再时间敏感**：`signedAt` 进 payload 后，时长断言 = `expireAt − signedAt ≈ 90d`，与运行日期无关（回退路径仍用现 `LICENSE_SIGNED_AT` 常量）。

### 2.4 验收

1. `pnpm --filter @yan-zhi/desktop package`（有私钥）→ 包内 JSON 存在且三档 expireAt ≈ 打包日 + 90 天。
2. 删除私钥再打包 → 明确报错中止；`YZ_SKIP_LICENSE_SIGN=1` 跳过并打警告。
3. 服务端启动读 JSON 成功（日志打印 `预置码来源: 构建时签发 (signedAt=…)`）。
4. 全部 license 测试绿，且无任何对"今天"的依赖。
