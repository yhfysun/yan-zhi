## 2. 调研结论（对标了什么）

- **YiSphere 易道**（github.com/0xfnzero/YiSphere）：FastAPI + 单页聊天；核心是「**程序负责计算，LLM 负责表达**」——八字/农历/黄历/起卦由本地工具算好，结构化结果注入给模型，提示词禁止模型改写排盘结果。左侧多角色先生，右侧对话，支持自然语言输入（「农历 1988.3.24 男 占一卦」）。
- **8Char-H5**（github.com/axbug/8Char-Uni-App）：排盘结果分四屏——命主信息 / 基本命盘 / 专业细盘 / 在线批命；细盘含四柱、十神、藏干、纳音、星运、空亡、神煞、五行分布、大运流年、古籍参考。**结论：结果必须是结构化盘面，不是一段文字。**
- **chatgpt-tarot-divination**（975 star）：一个入口挂多种占法（塔罗、姓名五格、周公解梦、生辰八字、梅花易数）。**结论：占法矩阵 + 统一结果骨架。**
- **卜筮正宗 / 卜筮全书**：六爻按「**事类取用神**」断卦——用神取错全盘皆错；有《用神分类定例》《六亲发动断事歌诀》《诸占定位》整套体系。
- **黄历宜忌词库**（《钦定协纪辨方书》系 / 农民历 / 顺时）：事类是**固定文言词库**，分六大类，不是随机词。
- **cnlunar / lunar-python**：宜忌、建除十二神、值神、吉神凶煞、冲煞、彭祖百忌、纳音、二十八宿可结构化下发。

**可借鉴**：计算与解读分离；自然语言 / 事类入口；结构化盘面；多角色；事类词库驱动。
**不借鉴**：付费解锁、每日运势推送、大师真人、改运化解、真实布局建议。

## 3. 必须先拍板的定位红线

现有 `docs/周易课程方案-2026-11-15.md:477` 把「**起名改名、在线大师、真实风水布局建议、改运化解**」列为明确不做；T5/T6 讲义与陪练 system prompt 也钉死「不做个人化预测」。用户本轮点名的取名、测祸福、姻缘、前程、算命与这条红线正面冲突。

- ✅ **口径 A（推荐，默认按此做）｜古籍规则演示**：功能全做，但输出是「这门手艺按古法怎么算」——事类 → 用神/规则 → 古籍引文 + 出处 + 简化口径说明 + 「规则演示」标签。取名做成**姓名学五格剖象的规则演示**（演示给定字的笔画/五格怎么算，不替用户起名、不推荐名字）；姻缘/前程/搬家做成**事类取用神演示**；测祸福做成**古籍吉凶断语演示**。不生成「你该不该跳槽/搬家」这类个人结论。
- ⚠️ **口径 B｜真·预测服务**：要改产品定位、免责声明、T5/T6 讲义立场、陪练 system prompt 硬闸、以及现有测试里的「不做个人化预测」断言，属于另一条产品线，风险 high。

**只问这一个决策**，其余按 A 推进。

### 4.2 事类层（新增，是「算事情」的骨架）

统一 `divination-case` 词库：每个事类带 `id / 名称 / 白话 / 古籍用神 / 对应占法 / 出处`，全部纯数据放 `packages/shared/src/zhouyi/cases.ts`，前后端共用。

- **六爻用神分类**（《卜筮正宗·用神分类定例》《卜筮全书·六爻诸占定位》）：身命、婚姻、胎孕、功名/科举/仕宦、求财买卖、出行/行人、**家宅/移徙（搬家）**、疾病医药、词讼/盗贼、失物、坟墓/风水、天时耕作、六畜蚕桑。
- **黄历宜忌六大类**（《钦定协纪辨方书》系词库）：
  - 婚姻：嫁娶、纳采、问名、订盟、订婚、安床、合帐、冠笄
  - 营建：入宅、**移徙**、安香、安门、修造、动土、上梁、竖柱、掘井、破屋、补垣
  - 工商：开市、挂匾、立券、交易、纳财、开仓
  - 祭祀：祭祀、祈福、求嗣、开光、沐浴、斋醮、塑绘、普渡、造庙
  - 生活：出行、出火、理发、习艺、栽种、纳畜、会亲友、入学、求医
  - 丧葬：修坟、启攒、破土、安葬、立碑、谢土、除服、解除
  - **易错对**：动土（阳宅开工）≠ 破土（阴宅开工）、入宅（首次住进）≠ 移徙（搬家）——词库里必须写清
- **用户口语 → 事类映射**：姻缘→婚姻/嫁娶，前程→功名/仕宦/赴任，搬家→移徙/入宅，吉凶→建除十二神 + 黄道黑道值神，算事情→事类选择器。

### 4.3 吉凶与解卦层

- **解卦**：本卦/变卦/互卦、动爻、卦辞爻辞、彖/象/文言、世应、六亲、六神、纳甲干支、用神旺衰；每条断语标「逐字引文 / 大意转述 / 今按」+ 出处。
- **吉凶口径**：建除十二神（建除满平定执破危成收开闭）、黄道黑道十二值神、吉神宜趋 / 凶神宜忌、冲煞、彭祖百忌、纳音五行、二十八宿、六亲发动断事歌诀、六神吉凶诀。
- **硬闸**：所有断语只查 `ZHOUYI_RULE_TABLE` 白名单（现约 22 条 → 按事类扩到 80+ 条，逐条带书名·朝代·卷次·license），**绝不生成新预测文本**。

### 4.4 记录层（用户实报「都要保留、能看到」）

本轮已修「不丢 + 可见」，重构再补：

- 独立「演练记录中心」一级入口，跨所有占法/事类，按时间倒序、可筛选、可搜索。
- 每条记录保留**脱敏盘面快照**：占法、事类、方法标签、summary、seed、createdAt、断语（白名单）、图类型、关联课时；**永不存 input 与生辰**（`steps[].input` 含输入值，必须逐字段剥离后再落盘）。
- 支持「同 seed 重跑」复现、单条导出 JSON、批量导出、手动删除（二次确认）。
- 存储从 localStorage 升级为「本地优先 + 服务端 `divination_practice` 表可选同步」，保持离线可用。

## 5. 视觉与交互重构

现状：深色底 + 一张 720px 白卡片 + 8 个小方法块 + 3 个输入框 + 一个按钮 —— 像后台表单，没有「排盘」感。

- **入口页（总览层）**：顶部「我想问什么事」事类条（姻缘 / 前程 / 搬家 / 求财 / 出行 / 疾病 / 词讼 / 失物 / 择日 / 更多）；下方占法矩阵卡，每卡带**卦盘/九宫/四柱缩略 SVG**、出处、难度、关联课时；右侧「最近演练」与记录中心入口；筛选固定顶部、列表独立滚动。
- **输入**：跟随事类/占法切换，支持自然语言一句话解析（借鉴 YiSphere，但解析器本地纯函数，不交给模型编数据）；内部 P0/扩展 徽标换成用户能懂的「入门 / 进阶」。
- **结果（沉浸层）**：从「五步纯文本」升级为**排盘主视觉 + 规则逐步展开**：
  - 六爻：六爻纳甲盘（本卦/变卦并列、六亲六神、世应、动爻标记）
  - 四柱：四柱表（十神、藏干、纳音、五行分布）+ 大运流年条
  - 玄空：3×3 九宫飞星盘（山/向/运三星）
  - 八宅：八方大游年吉凶罗盘
  - 梅花：体用生克图 + 互卦变卦
  - 测字：字形拆解图 + 笔画数 → 卦
  - 姓名：五格剖象图（天/人/地/外/总格）
  - `diagram.ts` 已有 SVG 图元基础，扩 `ZhouyiBlock` kind 即可，不引第三方图库、不 `v-html`。
- **结果页结构**：盘面 → 解卦（卦爻辞/注解分层）→ 事类用神 → 古籍断语（带出处 + 规则演示标）→ 回到课程 → 记录。仍保持一次一步、顶栏四项、无行内折叠。
- **配色**：沿用 `--dv-*`（墨底 + 宣纸 + 金铜/朱砂），盘面用细线 + 留白，去掉后台控件感；字号阶梯从 10–13px 提到 12–15px（当前总览层确实偏小）。
- **角色化解读**：复用现有三个陪练 agent 的口径，做成「先生按盘面讲一遍」，**程序算盘、模型只读盘面讲解**，与 YiSphere 同款分工。

## 8. 测试计划（不接受「应该没问题」）

- 纯函数真跑：每事类 → 用神 → 白名单断语链路；每占法同 seed 可复现；换输入结果必变。
- 白名单硬闸：断语必须命中 `ZHOUYI_RULE_TABLE` 且带出处；不得出现「你该 / 建议你 / 近期会」等个人化预测句式。
- 隐私：记录 / 导出 JSON 不含 input 与生辰；`steps[].input` 剥离逐字段断言。
- 挂载：事类筛选固定顶部 + 列表独立滚动 + 子项不收缩；沉浸台一次一步、无 `<details>`、顶栏四项、Escape/←→。
- 回归：`zhouyi-*.test.ts` 四个服务端类 + 两个 mount 类 + `Learning.mount.test.ts`；按用户视角 curl 验证词库/事类接口真下发。
