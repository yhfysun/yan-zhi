# 剪辑模式（视频剪辑工作台）方案

> 状态：待确认 | 2026-10-07
> 原则：只基于现有 media 工具链扩展；内部功能不新增用户侧噪音 UI；分阶段落地，先跑通再完善。

## 一、现状盘点（调研结论）

已有能力（全部在服务端 ffmpeg 链路，**只缺 UI 和动画字幕**）：

| 层 | 现状 | 位置 |
|---|---|---|
| ffmpeg 运行时 | 按需下载安装，路径解析完整 | `apps/server/src/mcp/ffmpeg-runtime.ts` |
| 组装 | `media_compose`：dub / concat / **subtitle 烧录** / normalize / drawtext 标题 | `apps/server/src/mcp/api-tool-executor.ts` L1416-1568 |
| 剪辑 | `media_edit`：trim / speed / snapshot / transform / fade / color / transition / overlay(画中画) / kenburns / bgsound / volume / loudnorm | 同上 L1585-2005 |
| 字幕 | `api_srt_generate` 生成 SRT（纯时间轴，**无动画**）；烧录走 `subtitles` 滤镜 + force_style | `apps/server/src/mcp/srt.ts` |
| 智能体挂载 | media 工具已挂任务模式智能体（`COMMON_MEDIA_FETCH_TOOLS`） | `apps/server/src/builtin-task-mode-agents.ts` L36 |
| 预览 | FilePreview 视频播放器 + ToolMediaPreview 媒体卡片可直接复用 | `packages/ui/src/components/` |

结论：**工具面已达到"爱剪辑基础功能"的 70%，缺口是 ① 字幕动画 ② 可视化剪辑界面 ③ 模式入口与专属智能体**。

## 二、总体设计

新增第五个 AppMode：**剪辑模式（clip）**，路由 `/clip`，形态仿 WorkflowWorkbench（左时间轴工作台 + 右栏对话）。

```
┌─────────────────────────────────────────────────┐
│  顶栏：ModeSwitcher 增加「剪辑」项                  │
├───────────────────────────┬─────────────────────┤
│  剪辑工作台（/clip）        │  右栏对话（沿用聊天）  │
│  ① 素材区：素材库/上传/生成  │  可直接说：           │
│  ② 时间轴：多轨（视频/字幕/  │  "给第三段加淡入"     │
│     音频/BGM 四轨）        │  "字幕逐字弹跳入场"    │
│  ③ 属性面板：选中片段的参数  │  → 模型调 media_* 工具│
│  ④ 预览：实时播放          │  → 时间轴同步更新      │
├───────────────────────────┴─────────────────────┤
│  交付：导出 mp4 → 交付文件区（已交付段）             │
└─────────────────────────────────────────────────┘
```

**双驱动设计（关键决策）**：
- **手动剪辑**：UI 直接操作时间轴，前端把编辑操作翻译成 `media_edit` / `media_compose` 调用（走同一服务端链路，不写第二套 ffmpeg 逻辑）。
- **对话驱动**：智能体调用同一批工具；每次工具执行产出「项目文件变更事件」，前端时间轴订阅后刷新。
- 项目工程文件（`.clipproj.json`）记录轨道/片段/参数，是 UI 与智能体共享的唯一事实源。

## 三、功能清单（对标爱剪辑/常见剪辑软件）

### P0（第一期，1-2 周）
- ✅ 素材导入：上传 / 素材库选取 / 复用已生成的图、视频、TTS 音频
- ✅ 时间轴基础：多轨拖拽排序、trim（起止裁剪）、分割、删除、变速
- ✅ 字幕轨道：SRT 导入 + 字幕样式（字号/颜色/描边/位置，复用现有 force_style 参数）
- ✅ **字幕动画（重点补齐）**：服务端把 SRT 转成 ASS，动画用 ASS 内联标签实现，新增 8 种预设：
  | 预设 | ASS 实现 | 效果 |
  |---|---|---|
  | 淡入淡出 | `\fad(300,300)` | 通用渐显 |
  | 逐字飞入 | `\t(0,200,\frz...)` + karaoke `\k` | 卡点感 |
  | 弹跳入场 | `\t(0,250,\fscx120\fscy120)\t(250,400,\fscx100\fscy100)` | 缩放回弹 |
  | 滑动入场 | `\move(x1,y1,x2,y2,0,300)` | 左/右/上/下进入 |
  | 打字机 | 按字拆分 Dialogue 逐条出现 | 旁白感 |
  | 描边闪烁 | `\t(\bord..\bord..)` 循环 | 强调关键词 |
  | 卡拉OK染色 | `\k` + `\2c` | 跟唱高亮 |
  | 关键词放大 | 行内 `\fscx140\fscy140` | 划重点 |
  - 实现：`media_compose` subtitle op 新增 `style_preset` 参数 + `subtitle_style.ts` 纯函数模块（SRT→ASS 生成器，含 PlayResX 缩放，带单测）——这是本方案唯一的"新算法"模块，其余全是参数透传。
- ✅ 音频：BGM（音量/循环/淡入淡出）、配音轨、响度归一（已有 loudnorm）
- ✅ 导出：分辨率/码率预设（1080p/720p/竖屏 9:16）

### P1（第二期）

## 四、页面设计细节

遵循既有规范：筛选/工具条固定顶部、面板独立滚动、极简无多余图标。

1. **素材区**（左上）：网格缩略图，来源 tab＝已上传 / 中间文件 / AI 生成；拖入时间轴。
2. **时间轴**（左中）：
   - 四轨固定：视频 / 字幕 / 音频(配音) / BGM；每轨独立横向滚动，同一滚动轴。
   - 片段即色块：视频=蓝、字幕=黄、配音=绿、BGM=紫；选中高亮描边；悬浮显示时长。
   - 工具条（固定顶）：分割 ✂、删除、复制、变速、撤销/重做。
3. **属性面板**（右侧或左下抽屉）：随选中片段切换内容（视频→变速/调色；字幕→样式+动画预设九宫格；音频→音量/淡入淡出）。
4. **预览**（右上）：复用 FilePreview 的 `<video>` 播放器 + 播放头联动；导出前用低码率快速合成预览（`-preset veryfast -crf 32` 预览档，成品才走高质量）。
5. **右栏对话**：复用 Chat.vue 的嵌入形态（仿 WorkflowWorkbench），会话自动挂「剪辑智能体」。

## 五、智能体接入

1. **新增内置智能体「剪辑师」**（`builtin-task-mode-agents.ts` 加一条，db.ts `force_sync` 落库）：
   - `builtin_tool_ids`：`media_edit` / `media_compose` / `api_srt_generate` / `api_tts_speak` / `api_video_generate` / `api_media_fetch` / `api_conversation_setup` / `media_install_ffmpeg`
   - `skill_ids`：新增 `skill_video_editing`（SOP：理解需求→列剪辑清单→逐条调工具→合成预览→交付；写明字幕动画预设清单供模型选择）
2. **项目联动**：智能体读写当前会话绑定的 `.clipproj.json`；UI 改动写回，智能体改动 SSE `clip:project-updated` 推给时间轴刷新（对齐现有 `context:compacted` 的可见性原则——所有变更必须可感知）。
3. **模式与授权**：
   - `mode.ts`：`AppMode` 加 `'clip'`，`MODE_DEFS` 加 `{ key:'clip', label:'剪辑', route:'/clip' }`
   - `router/index.ts`：加路由 + `MODE_ROUTE_KEYS`
   - `license.ts` `EDITION_MODES`：剪辑模式放哪一档由你定（建议 pro 档）

## 七、风险

| 风险 | 等级 | 对策 |
|---|---|---|
| ASS 动画在 libass 实机效果与预期不符 | high | 沿用既有铁律：逐条实跑 ffmpeg + 抽帧肉眼核验，不靠文档 |
| 时间轴与 ffmpeg 时间轴对齐误差（帧率/关键帧） | medium | trim 一律用 `-ss`/`-to` 秒级 + 预览校验；不承诺帧精度 |
| 打包体积（ffmpeg 已按需下载，无增量） | low | 无 |
| 剪辑长任务阻塞 | medium | 沿用现有长任务/进度推送机制 |

### 实施中修掉的真实缺陷
1. **模式白名单缺 clip**（后端 VALID_MODES + 前端 rowToConv + api_conversation_setup）→ 剪辑会话被静默落成 office；
2. **buildAss 只认单一动画预设** → 混用动画时后几条被静默按第一条渲染（改为逐条 preset/alignment）；
3. **草稿态无会话 id 可写** → 拖入素材刷新即丢（ensureConversation = createConversation **+ selectConv**，只建不切无效）；
4. **根节点 height:100% 取不到父高** → 整页缩成内容高度挤在上半屏；
5. **有配音分支多写前置 -map 0:v:0** → 产出两条视频流，规格/裁剪/调色静默失效；
6. **-t 卡在两个 -i 之间** → 归属到后一个输入，视频没裁反而截了配音；
7. **clip_project 未登记 MEDIA_TOOLS** → 成片渲染成功但文件管理里看不到。
