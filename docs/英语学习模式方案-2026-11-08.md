# 英语学习模式方案 · 2026-11-08

> 定位：给应用加一个「学习模式」——宠物或 AI 虚拟人（2D/3D）作为英语陪练，
> 覆盖四条学习线：**口语训练**（自由对话 + 场景卡）、**单词记忆**（关卡制 SRS 词本）、**语法学习**（预写规则 + 错因归因 + 微课 + 弱点地图）、**阅读朗读**（分级范文中英对照 + 表现力音色朗读 + 跟读）。
> 原则：**形象、语音、对话、记忆、插件五块地基全部复用现成的**，本方案只新增「教学层」。

## 二、产品定义

### 2.1 一句话

**「一个会陪你练英语的桌面陪伴」**：选一只 2D 宠物或一个 3D 虚拟人，它既是聊天对象，也是英语老师——能自由对话、能按场景出题、能纠错、能带单词和复习。

### 2.2 学习模式的两种形态（AI 陪练 × 学习应用，共享同一份数据）

| 形态 | 是什么 | 典型界面 | 驱动方式 |
|---|---|---|---|
| **AI 陪练形态** | 和形象对话着学：自由对话、场景卡、语法微课讲解、对话里收词 | 聊天流 + 形象舞台 | LLM 对话驱动（chat-ws 现有链路） |
| **应用形态** | 结构化的"学习 App"：单词闯关、关卡地图、听写、跟读、弱点地图、复习队列 | 关卡地图 / 答题面板 / 档案页 | 程序化界面驱动（`curriculum/vocab/grammar/review` 引擎出题判分，**不走 LLM 也能玩**） |

**关键设计：两种形态不是两个模块，是同一份数据的两个入口。**闯关记录、错误本、词本、SRS 到期、语法掌握度全部落同一套 learning 表——应用形态写入，AI 陪练形态读取；反过来 AI 陪练对话中收集的生词/错误，也实时出现在应用形态的关卡和复习队列里。这样做的直接收益见 §3.6（学习记录对大模型全量可见）。

### 2.3 四个训练模块（对应「口语 / 单词 / 语法」三条线，用户随时切）

| 模块 | 练什么 | 怎么练 | 首版优先级 |
|---|---|---|---|
| **① 自由对话陪练（口语）** | 敢开口、说得自然 | 用英语随便聊：自然纠错（recast：用正确说法复述你的意思），说中文时温柔拉回英语 | **P0** |
| **② 场景任务卡（口语）** | 真实场景的开口能力 | 抽场景卡（机场值机 / 餐厅点单 / 面试 / 电梯闲谈…）扮演角色完成对话，结束给评分 + 常用句型 | **P0** |
| **③ 单词记忆（关卡制）** | 词汇量 | **词书拆关卡**：内置词书（CET4/高考/雅思/新概念…每本拆成 ~20 词一关）+ **用户自定义词单**（手输/粘贴导入/AI 从一段英文生成），关卡地图选关 → 学词卡 → 闯关答题（选义/拼写/听写/例句填空）→ 按正确率给 1~3 星，三星解锁下一关；配合 SRS 排复习（1/3/7/14 天），到期词优先出题 | **P0（自定义词单+基础答题）/ P1（词书+关卡地图+星级）** |
| **④ 语法专项** | 语法体系 | 见 §2.4-语法体系：错题归因到语法点 → 语法点掌握度台账 → 微课讲解 + 专项练习 → 与错误本共用 SRS 复习调度。**语法规则全部预写内置**（不靠 LLM 现场生成，见 §2.4） | P1 |
| **⑤ 阅读与朗读** | 语感 + 听力 + 词汇巩固 | 分级范文库（内置 + 下载 + 粘贴自己的文章）：**中英文逐段对照**显示，点任意生词 → 释义 + 一键收进词本；全文朗读（有感情的英语音色，见 §3.5）、逐段跟读 | P1 |

> 口语线（①②）P0 先行；单词线 P0 先做「自定义词单 + 基础答题」最小版，语法线整体 P1——因为语法的前提是错误本积累出数据。

### 2.4 教学设计核心（这层决定产品成败，不是渲染）

- **分级**：首次进入做 3 分钟摸底对话 → 定 CEFR 等级（A1~C1，粗判即可），存进学习档案；此后陪练输出锁定在「i+1」（比用户水平略高一点），太难自动降速降词汇。
- **纠错策略分两档**（按形态选，不混用）：
  - 自由对话用 **recast**（不 interrupt、不打断对话流，用正确的句子自然接话）；
  - 场景卡/小课用 **explicit correction**（结束后集中给「原句 → 建议说法 → 一句原因」，每次最多挑 2 个最重要的错，不搞满屏红笔）。
- **错误本**：被纠过的表达自动入本（原句、正确说法、时间、来源会话），复习课优先从错误本出题——**错过的东西再练**，这是留存的核心。
- **语法体系（单词之外的第二条知识线；规则全部预写内置，LLM 只做归因和补例）**：
  - 内置一份**语法点目录**（首版 ~40 个高频点：时态 8 / 从句 6 / 非谓语 5 / 冠词介词 6 / 比较与倒装等 15）。**每个语法点的讲解内容离线预写好**，不是出题时让 LLM 现编：规则表、3~5 个典型例句（配 TTS 播放）、正误对照（❌ I have seen him yesterday → ✅ I saw him yesterday + 一句为什么）、常见错误清单、2~3 道配套练习模板——LLM 只在两处介入：把用户真实错句**归因**到语法点、按模板**补个性化例句**（用用户词本里的词造句）；
  - 语法点内容也是 JSON 内容包，与词书一样走「内置 + 下载」分发（课程/等级分类）；
  - 每次纠错时 LLM 顺手做**错因归因**：标注这条错误属于哪个语法点（如「第三人称单数漏 s」→ `grammar.present_3rd`），入错误本时带上 `grammar_point` 字段；
  - 同一语法点错误 ≥2 次 → 推送**语法微课**（直接播预写的讲解 + 例句朗读 + 3~5 道专项练习）+ 形象做个「严肃脸」动作开讲；
  - 语法点也有掌握度台账（`learning_grammar_point` 表，熟练度随练习与复习更新），档案页能看到「你的语法弱点地图」；
  - 语法点的复习与单词共用同一套 SRS 调度（复习课混排单词卡 + 语法练习题）。
- **范文与朗读（阅读线）**：
  - **范文库**：内置分级范文（每级 10~20 篇，短文 100~300 词，题材：日常对话体/新闻体/故事体），与词书同机制可下载扩充；用户也能粘贴自己的英文文章/教材课文进「我的文章」；
  - **中英文逐段对照**：原文一段、译文一段交替排列（或左右分栏），段落级对齐（LLM 翻译一次后缓存，不重复翻译）；点任意单词 → 浮层显示音标/释义/例句 + 「收进词本」一键入词本（走 `learning_word`，自动进 SRS）；
  - **朗读驱动学习**：整篇朗读 / 逐段朗读 / 单句循环；朗读时文字逐句高亮（跟读字幕）；「跟读模式」= 播一句 → 录一句 → 回放对比（P1 先不做打分）；
  - 读过的生词自动汇总成「本篇生词表」，读完弹一道快速回顾（3 题）——阅读闭环到记忆。
- **单词记忆细节（关卡制）**：
  - **词书与关卡**：词书 = JSON 内容包（词表 + 每词音标/释义/例句），每本自动按 20 词一关切分；关卡地图（LevelMap）按关排列，显示星级与锁定态。**通关规则**：闯关答 10 题（从本关 20 词出），≥80% 过关、90%+ 三星；过关词自动进 SRS 复习队列。
  - **词书来源三档（按课程/等级分类，内置 + 下载 + 自定义）**：
    1. **内置**：随应用分发，按「课程 × 等级」两级分类（课程：校园英语/CET4/CET6/雅思托福/新概念/职场…每课程内按等级排序），首版内置 2~3 本；
    2. **在线下载**：词书库（词书商城），同样按课程/等级筛选，内容包按需下载（不占安装体积），下载链路复用既有 `tts-packs.ts` 的镜像/代理下载先例；词书包格式与内置完全一致，二期开放社区自制（`contributes.wordBooks` 插件贡献点）；
    3. **自定义**：① 手动逐个添加（P0）；② **粘贴导入**：贴单词列表或英文文章，LLM 自动收词并补齐音标/释义/例句，生成自定义词书、一样拆关可闯（P1）；③ 对话收集：陪练遇到你不会的词，一句「要不要收进词本？」（P0）。
    三档词书走同一数据结构与关卡体验，LevelMap 上统一呈现。
  - **答题题型四选轮换**：看词选义 / 看义拼词 / 听写（TTS 念词 → 拼写）/ 例句填空；同一词答错立即回 SRS 第 1 盒，答对升盒。
  - 当堂新词 ≤5 个（多了记不住）；拼写练习对中文用户重点抓。
  - 形象参与：通关播「跳一跳 + ready」，三星再叠一个庆祝动作；连续答错 3 题形象做「歪头 + 张望」，提示「这关先缓一缓，我陪你复习一下之前的？」——关卡挫败感用动作化解，不用文字说教。
- **中英混说兜底**：用户全程中文时，陪练用「中文回应 + 对应英文表达」的方式教学；连续 3 轮纯中文，形象做个「歪头」动作问一句「要试试用英语说吗？」——不强推。

### 2.5 形象在教学中的参与（低成本高感知）

| 事件 | 形象反应 | 实现方式 |
|---|---|---|
| 用户答对/连续答对 | 开心动作（跳一跳/招手）+ 表情 happy | `Performer.playAction/setExpression`，宠物六动作全现成 |
| 用户答错 | 歪头/思考表情，不摇头不哭——不惩罚 | 同上 |
| 长时间没学 | 宠物照常桌宠生活，不做负反馈 | 状态机不动 |
| 完成一课 | 播 ready 动作 + 一句英语夸奖（TTS） | 既有 terminal 瞬态机制 |
| 口型 | 虚拟人说英语时开合嘴（振幅驱动） | `useLipSync`（直播方案已设计） |

### 3.1 架构（在现有三层之间插一层教学引擎）

### 3.2 服务端新增（`apps/server/src/learning/`）

| 文件 | 职责 |
|---|---|
| `agents.ts` | 三个内置教学智能体定义（chat-coach / scene-coach / lesson-coach），各自 system_prompt。照抄 `builtin-douyin-agents.ts` 的注册范式，建 `agent` 表记录 |
| `session.ts` | 学习会话编排：进入/退出学习模式、形态路由、教学事件（答对/答错/课完成）→ cue 给形象层 |
| `assessment.ts` | 摸底对话引导词 + CEFR 粗判（LLM 判级，一次调用）+ 档案落库 |
| `curriculum.ts` | 场景卡库（首版 12 张卡，JSON 定义：场景、双方角色、目标句型、退出条件）+ **语法点目录**（~40 点，讲解内容**离线预写**进 JSON）+ **内置词书内容包**（按课程×等级分类的 JSON）+ **范文库内容包**（分级短文 + 预缓存译文）+ **词书包管理**（内置/下载/自定义三档，下载走词书库）+ 课程定义格式 |
| `reading.ts` | 阅读服务：范文/文章管理（内置/下载/粘贴）、逐段对照数据（LLM 译文一次翻译后缓存）、点词查询（音标/释义/例句）、收词入词本、阅读进度、朗读编排（整篇/逐段/单句循环 + 逐句高亮时间轴） |
| `context.ts` | **学习上下文注入**：开场把档案/近期记录/到期词/薄弱点产成摘要进 system_prompt（§3.6 第 1 层） |
| `vocab.ts` | 单词服务：词书/关卡管理（切关规则、星级计算）、自定义词单（粘贴导入 → LLM 收词补齐音标释义例句 → 建自定义词书）、SRS 调度（Leitner 7 盒）、闯关出题（四题型轮换）、听写模式、对话收集确认 |
| `grammar.ts` | 错因归因（复用纠错抽取调用，标注 grammar_point）、掌握度更新、语法微课生成（讲解 + 专项练习）、弱点地图数据 |
| `review.ts` | 统一复习调度：单词卡 + 语法练习 + 错误本混排出复习课（间隔 1/3/7/14 天） |
| `ws-learning.ts` | `/ws/learning`：语音上行下行复用 avatar-live 方案的 ASR/TTS 管线，教学事件单独走 WS |

### 3.3 数据表（SQLite，新建 7 张，不动存量表）

```sql
learning_profile(user_id, cefr, vocab_hint, goals, updated_at)              -- 档案
word_book(id, name, kind, source, created_at)                              -- 词书：builtin | custom（kind=custom 的词全量存词表）
word_level(user_id, book_id, level_no, stars, status, best_score,
           cleared_at)                                                      -- 关卡进度（星级/锁定/最佳成绩）
learning_word(user_id, book_id, word, phonetic, gloss, example,
              box, due_at, source_conv)                                     -- 词本+SRS盒（词挂在词书下）
learning_grammar_point(user_id, point_id, mastery, last_drill_at,
                       due_at)                                               -- 语法点掌握度
learning_error(user_id, wrong, right, reason, grammar_point,
               source_conv, box, due_at, created_at)                        -- 错误本(归因语法点+SRS)
learning_reading(user_id, article_id, para_done, words_collected,
                 last_read_at)                                               -- 阅读进度与收词
learning_session(user_id, mode, scene_id, score, started_at, ended_at)      -- 每次练习记录
```

> 内置词书只存 `word_book(id, name, kind='builtin')` 一行，词表来自 JSON 内容包不进库；
> 下载词书 `kind='downloaded'` 同样内容包不进库，存 `<dataDir>/wordbooks/`（词书库按课程×等级两级分类，下载链路复用 `tts-packs.ts` 先例）；
> 自定义词书 `kind='custom'` 把词表落 `learning_word`。
> 内置词书内容包与场景卡/语法点目录同放 `apps/server/src/learning/data/`（二期可转插件贡献点 `contributes.wordBooks`）。

同时 memory 体系加 **`learning` 维度**（type=`learning`）：跨会话的教学摘要（"用户面试场景总卡在 self-introduction"），供陪练开场召回。

### 3.5 语音闭环（两条音色线：陪练对话 vs 文章朗读）

- 陪练说话：sherpa TTS 音色 → 音频 URL → 前端播 + 口型驱动。
- 用户说话：麦克风 → 流式 ASR（英语模型）→ 文本进对话链路；VAD 打断复用 avatar 方案设计。
- **朗读/文章配音用专门的"表现力音色"，与对话音色分开**：
  - 首选 **Kokoro-82M**（Apache 协议开源模型）：英文自然度明显高一档、语调有起伏、接近真人朗读，多音色（男女/英音/美音可选），语速可调——**且它就跑在仓库已有的 sherpa-onnx 同一运行时上**（sherpa-onnx 官方支持 kokoro 模型），不引入新推理栈、全本地离线，符合项目「全本地优先」原则；
  - 朗读增强参数：句间停顿、疑问句升调、语速档位（0.8x/1.0x/1.2x）——都在 sherpa-onnx 侧可调；
  - 模型包 ~300MB 级，按需下载，复用 `tts-packs.ts` 的镜像/代理下载链路；
  - 兜底：kokoro 下载前/低端机器可退回 sherpa 轻量 vits 音色（自然度降档，功能不缺）；
  - 备选评估过不采用：edge-tts（微软在线神经音色，表现力最强，但走云端、与全本地原则冲突，可作日后可选项）。
- **跟读评分 P1 才做**：首版只做「录音回放 + 原声对比」，不做发音打分——打分需要音素对齐（如 Goodness of Pronunciation），工程量和误导风险都高，缓一步。

### 3.6 学习记录对大模型全量可见（用户拍板的核心机制）

**原则：用户的学习记录、闯关记录、游戏记录，AI 陪练都要"看得见、用得上"**——这是两种形态共享同一套 learning 表的直接收益（见 §2.2）。分两层实现：

**第 1 层：开场自动注入（无感知，P0 就做）**
陪练会话建立时，server 端把学习上下文摘要注入 system_prompt（受 token 上限约束，只注入高价值字段）：

```
[学习档案] CEFR B1；目标：能应付日常口语
[最近学习] 昨天完成 CET4 词书第 3 关（2星），第 4 关未解锁；连续学习 5 天
[到期复习] 14 个词今天到期：abandon, casual, ...（取前 8 个）
[薄弱点] 语法点 present_perfect 错 3 次；错误本 top3：...
[自定义词单] 「面试词汇」（用户粘贴导入，12 词，学到第 1 关）
```

注入数据由 `learning/context.ts` 统一产出（纯函数，可单测）；陪练据此自然开口：「昨天第 3 关拿了两星，卡在哪几个词了？正好今天有 14 个词到期，先清一轮？」

**第 2 层：模型主动查询（工具，P1）**
给教学智能体挂 3 个只读学习工具（走既有智能体工具挂载机制，不改工具协议）：
- `learning_get_profile` —— 查完整档案 + 语法掌握度
- `learning_query_words` —— 按词书/关卡/到期/盒数查词本
- `learning_get_history` —— 查 learning_session 练习记录与闯关/游戏成绩明细

模型在对话中按需调用（"你说想练面试，我看看你那个面试词单学到哪了"）。**权限边界**：这 3 个工具只挂在教学智能体上，其他智能体不可见，且全部只读——学习数据不外泄到无关会话。

**游戏记录同理**：关卡闯关成绩、每日 streak、以及 P2 的宠物小游戏（Worlds 单词掉落）战绩都写 `learning_session`（mode 区分 `drill`/`minigame`），模型可查可引用——宠物能说出「你上周单词掉落游戏拿了 1200 分，但『th』开头的词老掉」这种细节，个性化感直接拉满。

### 3.7 提示词设计要点（agents.ts 里最重要的资产）

三个智能体的 system_prompt 共享一段「教学宪法」，要点：

1. 角色 = 用户选定的宠物/虚拟人人设（复用现有人设注入）+ 英语老师双重身份；
2. 输出语言纪律：自由对话默认纯英语（CEFR 锁级）；讲解/纠错用「英语句子 + 中文短注」双语；
3. 每条回复 ≤ 3 句英语 + 可选 1 句中文注释（陪练不是阅读理解）；
4. 纠错上限：单轮最多 2 处，且必须给「你说 → 母语者会说 → 为什么」三段式；
5. 场景卡模式：严格按场景角色说话，不跳出场景；达到目标句型即给结束信号（结构化标记，session.ts 捕获后触发评分与动作 cue）；
6. 结束信号用固定标记（如 `[SCENE_END]`）+ 结构化 JSON 块，解析失败不崩溃——降级为普通文本展示。

## 四、分期计划

### P0 —— 口语陪练 + 单词最小闭环（目标：能听、能说、能纠错、能记词）

1. `agents.ts`：chat-coach 智能体 + 教学宪法提示词（~半天）
2. 摸底对话 + CEFR 档案（assessment + learning_profile 表）（~半天）
3. 自由对话陪练：文字链路先通（对话 + recast 纠错）（~1 天）
4. 词本最小版（关卡基础形态）：自定义词单（手输/粘贴直存）+ 关卡答题（看词选义/拼写两题型）+ SRS 调度，过关记 `word_level` 星级（~1.5 天）
5. 学习上下文注入：`learning/context.ts` 开场摘要进 system_prompt（§3.6 第 1 层）（~0.5 天）
6. `Learning.vue` 舞台：宠物 2D/3D 先接入（Performer 最小集：setSpeaking + playAction + setExpression）（~1 天）
7. TTS 说英语 + 用户语音输入（sherpa ASR 英语模型接入）（~1.5 天）
8. 错误本最小版：会话结束 LLM 抽取 2~3 条入 `learning_error`（含错因归因语法点字段先落库、先不展示）（~0.5 天）

**验收**：戴上耳机和虚拟人说 5 分钟英语，它听得懂、级别合适、会自然纠错，**而且开场就知道你学到哪了**；建一个自定义词单、闯一关拿星级；对话里遇到生词能收进词本；结束后错误本有记录。宠物形象同样可用。

### P1 —— 场景卡 + 词书下载 + 语法专项 + 阅读/朗读 + 复习体系

9. 场景卡库 12 张 + scene-coach + 结束评分卡（~1.5 天）
10. **词书库**：内置词书补齐（按课程×等级分类）+ 在线下载（`tts-packs` 链路）+ 粘贴导入生成自定义词书 + 关卡地图 LevelMap（星级/锁态/词书切换）（~2 天）
11. **语法专项**：语法点目录 40 点（讲解内容预写进 JSON）+ 归因生效展示 + 微课 + 专项练习 + 弱点地图（~2 天）
12. **阅读与朗读**：内置范文库 + 中英逐段对照阅读页 + 点词收词 + 朗读（Kokoro-82M 音色接入 + 逐句高亮）+ 跟读录音回放（~2.5 天）
13. 统一复习课：单词 + 语法 + 错误本混排 + 每日 streak（~1 天）
14. 虚拟人口型 + 表情 cue 全量接通 + 学习查询工具 3 只挂教学智能体（§3.6 第 2 层）（~1.5 天）
15. 复习面板 ReviewPanel + memory `learning` 维度召回（~1 天）

### P2 —— 打磨与生态

12. 跟读发音评分（音素对齐，选型再定）
13. 课程/词书做成插件包（`contributes.learningCourses` / `contributes.wordBooks`），开放社区自制课程与词书包 + 商城
14. 多语言扩展（日语/韩语走同一教学层，只换模型与 TTS 音色）
15. 宠物专属玩法：单词掉落小游戏（Worlds 体系）、宠物对你的错误本「打小报告」

**工作量合计**：P0 约 7~8 天（口语 + 单词关卡基础闭环 + 学习上下文注入）；P1 约 11~12 天（场景卡 + 词书库 + 语法专项 + 阅读朗读 + 复习 + 查询工具）；P2 待定。

## 八、同类产品交互调研与借鉴（2026-11-08 补，调研当日落地）

对标对象：**Duolingo**（游戏化/习惯闭环）、**Speak**（课程+AI 对话）、**TalkPal**（场景角色扮演）、**ELSA Speak**（音素级发音）、**Praktika**（AI 虚拟导师 Avatar）、**Loora**（成人极简对话）。

### 8.1 核心结论（决定我们不做什么）

1. **「能聊天 ≠ 在学习」**（行业共识误区）：大模型都能聊 30 分钟，但没有「错误识别 → 记录 → 针对性复习」闭环就只是聊天机器人。我们的错误本 + SRS + 学习上下文注入正是这个闭环——**方向已对，坚持做深**。
2. **纠错不是越多越好**：每句都打断会再次制造「不敢开口」。Loora 的「一次只留 1~2 个主要改进点」与我们的「单轮 ≤2 处」一致——**已写进教学宪法**。
3. **AI 评分是长期趋势参考，不是考试标准**：ELSA 的音素级打分是它的护城河但易让人「练分数」。我们维持「跟读先做录音回放对比、打分放 P2」的决策**被验证正确**。
4. **场景数量不重要，动态调级才重要**：几百个场景如果初级和高级用户进「商务会议」拿到一样的内容，就是数量不是个性化。我们的 CEFR 锁级 + i+1 已覆盖——**场景卡（P1）出题必须带 level 参数**。
5. **Praktika 的 Avatar 是双刃剑**：形象越逼真，停顿/机械感的违和越大。我们的 2D/3D 可选 + 宠物低预期路线是差异化安全区；**陪练 TTS 首句延迟要压**（失败案例的共同槽点）。

### 8.2 Duolingo 习惯闭环的借鉴清单

| 机制 | Duolingo 做法 | 我们的采纳 |
|---|---|---|
| Streak 火焰 | 主界面最显眼位 + 连续天数=身份信号；7 天 streak 用户 6 月留存高 3 倍 | ✅ **已落地**：学习页头部 `🔥 连续 N 天`（profile.streakDays） |
| Streak Freeze/Repair | 保险机制，miss 一天可补救，「粘性但人道」 | P2：桌面端可用「补打卡（24h 内做一节复习恢复）」替代冻结，不做付费货币 |
| 到期复习环 | Skills 衰减变灰→Practice 恢复；练旧课赚红心 | ✅ **已落地**：「今日复习」卡（due 计数 + 跨词书复习闯关，`GET/POST /api/learning/review`），SRS 到期优先于闯新关 |
| Hearts 生命值 | 错题扣红心、归零锁关 | ❌ **不抄**：与「不惩罚错误」原则冲突（Praktika/Loora 也都不用） |
| XP/周联赛 | 社交竞争驱动周活 | P2 观察：单机桌面端缺社交面，先不做；若做只做「自我周报」 |

| Checkpoint 跳关 | 通过 checkpoint 测试可跳级 | P1：给已解锁词书加「直接考本关」入口（锁只挡新关，测试通过可跳） |
| 微奖励 | 答对 ding + 烟花 + Duo 挥手 | ✅ **已落地**：形象动作（过关 hop / 没过 look），P1 配 TTS 一句夸奖 |
| 课程 3~7 分钟 | 小课时 + 进度条 + 错题回落 | ✅ 结构一致：10 题一关；P1 把「交卷动画」做成进度条式收尾 |

### 8.3 Speak / TalkPal / Praktika 的对话侧借鉴（P1 教学层用）

| 来源 | 机制 | 落点 |
|---|---|---|
| Speak | **Learn→Practice→Apply** 三段循环：先给目标句型→模式操练→进对话应用 | P1 场景卡开场：先展示 3~5 个 keyPhrases 再开始对话（教学宪法补一条） |
| Speak | 纠错解释「为什么别扭」而不只「错了」 | ✅ 已有：三段式的 why 一句 |
| Speak | 同一对话可无限 retry、从错误生成 custom review | ✅ 错误本 + 复习环已覆盖；retry 在场景卡上补「再来一次」 |
| TalkPal | 角色扮演按上一句真实接话（不照稿念） | ✅ 教学宪法已有「严格按场景角色说话，不跳出」 |
| Praktika | 母语辅助给初学者（新手不全英文环境） | ✅ 已有：中文回应 + 对应英文表达兜底 |
| Loora | 「说→纠错→继续说」极简主流程；英/美音可选 | 朗读音色选型时提供英音/美音两档（Kokoro 多音色天然支持） |

### 8.4 已落地的两项（2026-11-08 本轮实现）

1. **Streak 火焰**：`GET /api/learning/profile` 增 `streakDays`（learning_session 相邻日期链，今日或昨日为链尾才有效）；学习页头部展示。
2. **今日复习环**：`GET /api/learning/review`（due 计数 + 跨词书到期词出题）/ `POST /api/learning/review/submit`（只更 SRS 不记关卡，session mode='review'）；学习页右栏「今日复习」卡。冒烟实测：due=2、跨词书出题、交卷后 streak 更新 ✓。
