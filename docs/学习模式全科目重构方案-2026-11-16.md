## 一、这次要解决什么

用户明确两点：

1. 新增党史、政治、经济学、军事、历史、书法、记忆训练、思维训练、数学、物理、百家思想、日语十二科。
2. 不再只修旧页面零散问题，学习模式整体重构。英语、软考、网络安全、传统文化、音乐、周易也进入同一套页面语法。

本方案不再把“桌面三栏、各科技 Tab、课程卡、学习内容”混在同一个总览页，也不把移动端当成桌面端的缩小版。

### 已开始实装

- 新增 `/learning-v2` 独立路由，保留旧 `/learning` 作为回退入口。
- 前端插件目录同步登记 `LearningV2.vue`，避免“后端有路由、前端包内没有组件”的空白页。
- 新增共享课程目录：19 个科目、327 个课程与精读单元。
- 新增 8 类页面：总览、课程地图、书籍研读、沉浸学习、实践、练习测评、复习、陪练。
- 新增课程级零基础教案生成：前置知识、白话目标、示范、独立练习、常见错误、来源。
- 当前已有 120 门正式审校课程，覆盖全部 19 科；其余 207 门显示“建设中”并禁止进入沉浸学习，不会被伪装成已完成精品内容。
- 公共图书馆已扩展为发现、书架和书源三区，覆盖经典名著、志怪小说、授权网络小说平台、公版漫画和 19 科课程原典；书源管理支持 HTTPS 自定义入口、启停和本地持久化。
- 课程地图和移动课程下拉都按同一准入函数判断；草稿课程不能通过保存的旧会话绕过。
- 新增全局公共图书馆弹窗：跨科搜索书目、原文、译文与出处。
- 公共图书馆在移动端使用独立书目详情浮层，不再把详情排在全部书目之后。
- 新增笔记入口，复用现有 `NoteQuickCreateDialog` 与笔记 API。
- 完成课程会写入现有 `/learning/lesson-progress`，本地状态与后端进度双写。
- 进度请求按科目和请求序号隔离，快速切换科目时旧响应不会写入新科目。
- 桌面与移动端使用不同骨架：移动端为科目浮层、单一下拉、横向课程轨、吸底继续学习；桌面端保留科目栏与浏览型总览。
- 沉浸学习台改为真正全屏覆盖，锁正文滚动，支持 `Esc` 退出，并通过按钮态显示朗读不可用原因。
- 新增全科通用陪练智能体；英语、传统文化、音乐、周易继续使用各自专属陪练。
- 网络安全实践台可执行授权确认、隔离请求重放、权限矩阵、修复回归、卡/NFC 授权检查和报告导出。
- 周易实践台包含经传注疏、象数推演、天文历法、地理图谱；占卜实践包含文化娱乐边界、牌阵与概率复盘。
- 书法实践提供公版碑帖选择、范字叠合、硬笔/毛笔绘制与清空重写；音乐实践提供四拍音级块与试听。
- 原型数据由 `pnpm generate:learning-v2` 生成到 `@yan-zhi/shared`，防止设计稿与实现目录漂移。

框架实现依据：

- Vue 3 Composition API：<https://vuejs.org/guide/extras/composition-api-faq.html>
- Vue Teleport：<https://vuejs.org/guide/built-ins/teleport.html>

核心结论：

- 19 个科目共用一套学习信息架构。
- 政治、军事、历史的教学范围覆盖古今中外，但界面标题只显示科目名，不把范围说明塞进科目标题。
- 每个科目覆盖 8 类页面：学科总览、课程地图、书籍研读、沉浸学习、实践、练习测评、复习巩固、AI 陪练。
- 最新代码的 95 个课程与精读单元全部保留入口；新方案首批登记 232 门课程，总计 327 门。
- 每门课程都有桌面端和移动端直达入口，共 5,232 个原型链接，覆盖 327 × 8 × 2。
- 公共图书馆作为全局入口，不归属传统文化，统一检索所有科目的原文、注释、译文、版本、出处与许可状态。
- 各科差异不靠“每科一套页面”解决，而靠可组合的学习步骤引擎与科目内容包解决。
- 旧 Bug 不在旧页面继续叠加补丁；与学习体验直接相关的导航、移动可用性和实践链路已在 V2 重新实现并验收。

## 二、现状问题

### 2.1 页面问题

- 同一科目里，科目选择、课程目录、路线、Tab、继续学习、工具入口和知识内容同时争夺首屏。
- 软考、网络安全、传统文化、音乐、周易各自形成一套布局，导致移动端要逐科补丁。
- 移动端已有 v1.1 骨架，但部分科目仍把科目级导航、课程级导航和内容级操作叠在一起。
- 同一动作出现多次入口，例如左侧课程卡、中栏 Tab、顶部 CTA 指向同一目的地。
- 沉浸学习台在不同科目中的覆盖层级、返回位置、朗读状态和底部操作不一致。

### 2.2 架构问题

- `Learning.vue` 仍存在大量按科目分支的硬编码。
- 旧科目和新科目使用两套接线方式：存量分支 + `subject-extensions.ts`。
- 课程 `kind` 与页面展示、学习步骤、陪练上下文、进度 key 多处耦合。
- 移动端改造依赖媒体查询和局部 CSS 覆盖，难以保证每科都可用。

### 2.3 结论

本次必须以“科目注册、页面语法、步骤引擎、内容包”四层重构，不能继续在现有单页里追加 `v-if`。

## 三、产品结构

### 3.1 两层结构

```text
导航层
  学习首页
    → 科目总览
      → 课程地图
        → 选择具体课程

学习层
  沉浸学习台
    当前课程 + 当前步骤 + 进度 + 退出
      → 下一步
        → 练习 / 自测
          → 完成并进入复习队列
```

导航层允许浏览、比较和回看进度。学习层只解决当前一个问题。

### 3.2 八个页面族

| 页面 | 负责什么 | 不负责什么 |
| --- | --- | --- |
| 学科总览 | 继续学习、科目统计、最近课程、今日任务 | 不铺完整知识内容 |
| 课程地图 | 阶段、课程、完成度、课程选择 | 不展开课时正文 |
| 书籍研读 | 原文、注释、注解、译文、版本与来源 | 不把注解和原文混成一段 |
| 沉浸学习 | 当前知识点的单步学习 | 不显示全局导航、课程列表、工具市场 |
| 实践 | 模拟、实验、临写、试奏、推演、创作与产出 | 不自动判分，不替代练习测评 |
| 练习测评 | 单题或单组练习、反馈、错因 | 不一次铺整套题库 |
| 复习巩固 | 到期项、薄弱项、最近错因 | 不混入其他科目上下文 |
| AI 陪练 | 追问、解释、苏格拉底式引导 | 不替学习者跳过思考 |

### 3.3 学习步骤引擎

各科步骤名称不同，底层只保留以下可复用类型：

| 引擎 | 用途 | 使用科目示例 |
| --- | --- | --- |
| `read` | 原文、案例、材料精读 | 党史、传统文化、周易、百家思想 |
| `source` | 一手材料、来源卡、证据层级 | 党史、历史、政治 |
| `compare` | 多维对照、概念辨析、制度比较 | 政治、百家思想、文学 |
| `map` | 时间线、地理态势、关系图 | 党史、军事、历史 |
| `trace` | 临摹、叠合、跟读、手势操作 | 书法、英语、音乐 |
| `simulate` | 授权实验、规则演练、状态推演 | 网络安全、军事、周易 |
| `drill` | 记忆、提取、间隔复习 | 记忆训练及全科复习 |
| `construct` | 编曲、写作、画图、建模 | 音乐、数学、思维训练 |
| `proof` | 推导、论证、反证与检查 | 数学、历史、思维训练 |
| `debate` | 立场复述、反驳与代价分析 | 政治、百家思想 |
| `check` | 自测、判卷、反馈与复习入队 | 全科 |

页面不按科目复制，步骤按内容组合。

### 3.4 零基础到进阶的统一编排

所有科目的课程地图都按同一深度顺序组织：

```text
零基础 → 基础 → 进阶 → 实战与专题
```

每节课必须有可执行教案，而不是只给标题：

- 前置知识：不会时回看哪一课。
- 一句话目标：本课只解决什么问题。
- 直觉入口：先用生活或已学内容建立感觉。
- 核心概念：新术语第一次出现时必须解释。
- 教师示范：完整走一遍例题、材料或操作。
- 引导练习：给步骤和提示，学习者跟着做。
- 独立练习：撤掉提示后完成一次。
- 常见错误：至少列出两个可观察误区。
- 提取自测：先回忆，再看答案。
- 下一步：明确继续、补基础或进入实践。

没有完整教案的课程不直接展示空白页；总览层可以标“建设中”，但不可进入。

## 四、桌面端设计

### 4.1 总览层

```text
┌ 应用模式轨 ┬ 科目栏 ┬ 当前科目工作区 ─────────────┬ 今日状态 ┐
│ 学习         │ 19 科  │ 八类页面导航                │ 清单     │
│ 复习         │ 进度   │ 继续学习主条                │ 掌握度   │
│ 笔记         │        │ 课程横向预览 + 阶段路径       │ 最近记录 │
└─────────────┴────────┴────────────────────────────┴─────────┘
```

设计原则：

- 科目栏只负责切换学科，不显示当前科目课时。
- 中栏的第一优先动作永远是“继续学习”。
- 阶段和课程使用列表与路径表达，不用大面积装饰横幅。
- 右侧栏只显示今日目标、复习和最近记录，不重复课程目录。
- 课程卡只用于浏览；点课程后进入独立沉浸学习台。

### 4.2 沉浸学习层

- 全屏覆盖，不保留应用顶栏、科目栏和右侧栏。
- 顶栏只保留四项：返回路线、当前课程、步骤 x/n、退出。
- 步骤导航为紧凑横向胶囊，可回看已完成步骤，不直接解锁未学步骤。
- 阅读面最大宽度 820px，正文与背景满足 WCAG AA。
- 底部固定上一步/下一步；最后一步变为“完成本课”。
- 朗读、记笔记属于本步工具，不常驻挤占正文。
- `Esc` 退出，`←/→` 切换步骤，焦点锁定在沉浸层内。

### 4.3 桌面端不再“各科一套”

各科只替换：

- 科目色彩与标识。
- 课程包与阶段。
- 沉浸步骤组合。
- 步骤渲染器。
- 陪练提示词与引用范围。

布局、导航、阅读宽度、焦点和完成流程统一。

## 五、移动端设计

### 5.1 总览层骨架

```text
┌ 科目 ▾                         学习  搜索 ┐
├ 阶段 + 课程，一个 44px 下拉选择 ─────────┤
├ 继续学习主卡：标题 + 进度 + 开始本节 ────┤
├ 练习 / 复习 / 陪练 / 笔记，一行工具入口 ─┤
├ 本阶段课程，一条横向滑动轨 ──────────────┤
├ 今日复习，纵向只显示 1~3 项 ─────────────┤
├ 吸底：继续学习 / 开始复习 ───────────────┤
└ 今日 / 学科 / 复习 / 我的 ───────────────┘
```

硬约束：

- 科目收进顶栏标题，点击弹出 App 内科目浮层。
- 阶段与课程合并为一个分组下拉，不恢复纵向手风琴。
- 全页只有一张大卡：继续学习。
- 课件使用单行横轨，单卡约 146px。
- 长列表（软考真题、网安模块、周易 53 个课程与精读单元）使用底部浮层 + 搜索 + 吸底继续。
- 高频 CTA 固定在 TabBar 上方，触摸目标 ≥44px。
- 不使用 `:has()` 作为关键布局依赖，兼容老 WebView。

### 5.2 沉浸学习层

- 全屏覆盖应用顶栏和 TabBar。
- 顶栏只有返回、当前课程、步骤计数、退出。
- 步骤导航横向滚动，当前步高亮。
- 正文在独立浅色阅读面，外层深色降干扰。
- 底部上一步/下一步固定，适配 safe area。
- 朗读失败必须显示按钮态原因，不允许无声无息。
- 退出后回到原课程和原步骤。

### 5.3 移动端验收视口

- 320px：所有文字不横向溢出，按钮不重叠。
- 390px：主流安卓与 iPhone 的主要设计基准。
- 430px：大屏手机。
- 768px：小平板仍使用单列。
- 900px：切换为桌面布局的边界。

## 七、重点科目设计

### 7.1 书法

用户要求：毛笔、硬笔，优秀字帖可照着练，楷书、行书、行楷为主。

#### 学习路径

1. 工具与笔法：坐姿、执笔、运腕、中锋、提按、起收。
2. 楷书：欧体、颜体、柳体、赵体。
3. 行楷：赵孟頫《洛神赋》《赤壁赋》等。
4. 行书：王羲之《兰亭序》、颜真卿《祭侄文稿》、苏轼《黄州寒食帖》、米芾《蜀素帖》。
5. 硬笔：基本笔画、间架结构、横线格、日常笔记速度与清晰度。
6. 创作：章法、落款、临创转换。

#### 临帖工作台

```text
范字（可缩放）  |  描红层  |  自写层
             叠合对照
偏差标记：位置 / 角度 / 粗细 / 起收 / 收笔
操作：看一笔 → 摹写 → 叠合 → 临写 → 只改一个变量
```

核心要求：

- 毛笔与硬笔两套笔顺、力度和速度提示。
- 经典碑帖只使用公版扫描或明确授权的资源。
- 硬笔范字优先自研，或基于公版结构重新设计，不直接复制现代商业字帖。
- 反馈必须可观察、可解释，不用“气韵不足”一类空泛评价。
- 每次只给一个修改目标，第二遍后再比较。

#### 首批范本

- 楷书：欧阳询《九成宫醴泉铭》、颜真卿《多宝塔碑》《颜勤礼碑》、柳公权《玄秘塔碑》、赵孟頫《胆巴碑》。
- 行楷：赵孟頫《洛神赋》《赤壁赋》、文徵明《滕王阁序》等公版资源。
- 行书：王羲之《兰亭序》冯承素摹本、颜真卿《祭侄文稿》、苏轼《黄州寒食帖》、米芾《蜀素帖》《苕溪诗帖》。

### 7.2 百家思想

“百家”不是传统文化课程的附属阅读，而是独立的思想比较与论证训练。

#### 中国诸子

儒、道、墨、法、名、阴阳、纵横、农、兵、医、杂、小说等传统均应有入口。首版先做代表原典与核心概念，不把“百家”缩成儒道法三家。

#### 世界思想

古希腊、印度思想、启蒙、德国古典、自由主义、社会主义、保守主义、共和主义、存在主义、实用主义、分析哲学、女性主义、生态思想等按时代与问题两条轴组织。

#### 学习方式

- 原典短读：谁在回答什么问题。
- 概念拆解：同一个词在不同传统中指向什么。
- 比较：按动机、规则、后果、自然、权力、自由等轴线。
- 争辩：先复述对手最强理由，再反驳。
- 自测：判断、证据、限定条件、反例。

### 7.3 党史、政治、军事、历史的内容边界

| 科目 | 来源原则 | 教学边界 |
| --- | --- | --- |
| 党史 | 官方公开文献、会议文件、权威党史著作、可核验史料 | 强调来源与时间，区分一手材料、回忆材料和研究解释 |
| 政治 | 经典原典、公开制度文本、学术通识、案例材料 | 区分描述性事实、规范判断和价值立场；比较制度时不把偏好包装成事实 |
| 军事 | 公版战史、公开军事理论、公开地图与学术研究 | 讲战略、战役、后勤、组织与历史约束，不提供武器制作、攻击目标选择或现实行动指导 |
| 历史 | 一手史料、考古材料、公版史书、可追溯研究 | 多源互证，明确“事实 / 解释 / 立场”，允许展示争议 |

### 7.4 记忆训练与思维训练

这两科不是孤立题库，要成为全科学习工具：

- 所有科目完成自测后，可自动生成记忆卡。
- 复习队列按科目隔离，首页可跨科汇总。
- 记忆训练教方法，真正迁移到英语词汇、历史年代、政治概念、数学公式、书法结构。
- 思维训练教拆解、建模、证据与迁移，和练习页共享“先解释再选择”的反馈。
- 禁用伪科学承诺，不用“过目不忘”“右脑开发”等宣传。

### 7.5 数学

数学按学段与能力双线组织：

- 小学：数感、运算、分数、几何、统计。
- 初中：方程、函数、几何、概率。
- 高中：函数、数列、解析几何、导数、概率统计。
- 大学：微积分、线性代数、概率论。
- 数学思维：证明、建模、算法与数学史。

学习台必须有“操作”和“证明”两种路径，不能只做选择题。

### 7.6 书籍研读

每个科目都必须有对应书库，书籍页固定保留原文，再按层查看：

- 原文：公版全文、授权全文，或用户自有书库导入。
- 注释：字词、读音、术语、专名、公式符号与技术概念。
- 注解：历代注家、研究解释、编者按或工程经验，转述必须标明。
- 译文：古文白话、外文对译、公式或图表说明。
- 来源：作者、版本、页码、许可与引用信息。

古文与外文采用同一原则：原文始终可见，注释和译文不覆盖原文。外文至少提供句级对译、关键词、语法或术语说明；古文至少提供断句、难字、通假、历代注解和白话。技术书保留代码、公式、图表与术语解释。

受版权保护的书目不在应用内分发全文。接授权版本，或只提供用户自有书库导入；不能以“学习功能”为由复制未授权全文。

### 7.7 实践与练习分界

| 页面 | 回答的问题 | 例子 |
| --- | --- | --- |
| 实践 | 我能不能做成、做出产物或完成一次模拟 | 网安靶场、周易演练、书法临写、音乐试奏、经济市场模拟 |
| 练习测评 | 我是否理解并能判断 | 选择题、纠错、证明检查、自测与错因 |

实践页必须有明确产出与边界。网络安全只连授权教学靶场；周易只做规则与文化演示；军事只做历史战例推演；音乐实践为试奏与编曲，不把练习评分当成实践。

网络安全原有实操台不删除，统一迁入“实践”页面，保留授权靶场、隔离教学数据、复现、修复和回归复盘能力。

网络安全实践台至少包含：隔离靶场环境、请求重放、流量与日志查看、权限矩阵、漏洞复现、修复编辑器、回归测试和报告导出。硬件与卡安全实验（包括授权 NFC/门禁卡读取分析）只允许用户自己的设备或明确授权设备，不得连接真实第三方目标。

实践不是科目级占位页。每门课程的内容包都必须带 `studioTask`，进入实践后自动带入当前课程、任务、产出和边界。周易 53 个课程与精读单元分别进入文化演练台，其中经传课做原文与注疏核对，术数课做规则演练；网络安全 12 门课程分别进入对应授权靶场，不共用同一个越权案例。

周易实践台按最新代码扩展为四类工作区：

- 经传注疏：原文、注释、历代注解与白话分层。
- 象数推演：爻位、八卦、六十四卦、干支与筮法规则。
- 天文历法：节气、历法、卦气与天象文化，不把天象当现实预言。
- 地理图谱：方位、地形、历史地图与堪舆文献，仅作文化研究。

### 7.9 占卜学科

“占卜”作为独立学科，不与周易混在一起。它研究世界占卜文化、象征系统和解释实践，首版 20 门：

- 占卜文化基础：历史、象征、概率与心理、记录复盘、伦理边界。
- 星象与宇宙：天文基础、星座文化史、黄道十二宫、行星宫位相位、星盘实践。
- 塔罗与牌阵：公版塔罗图像史、大阿卡纳、小阿卡纳、三张与十字牌阵、解读复盘。
- 器物与地方传统：水晶球凝视、骰子与签筒、数字占卜、地理方位与地方占俗、中外比较。

实践台提供星图、黄道十二宫、塔罗牌阵、水晶球凝视、骰签随机、概率提醒和解读日志。所有结果固定标注“文化与娱乐体验，不构成医疗、法律、金融或现实预测建议”。塔罗、星图和水晶球图像只使用公版或授权素材。

### 7.10 公共图书馆

公共图书馆属于学习模式全局导航，不属于任何一个科目：

- 统一索引所有科目的书目、原文、译文、注释、版本与出处。
- 支持按科目、作者、体裁、原文类型、版本、许可状态和关键词检索。
- 科目内“书籍研读”展示本书架与当前阅读；公共图书馆负责跨科查找。
- 书目至少保存标题、作者、版本、来源、许可和可访问状态。
- 未获授权的现代书籍只登记书目和来源，不展示全文；用户自有书库导入单独标识。
- 所有考核内容必须能回溯到 `verified` 原文或预写教案。

## 八、内容质量与版权

### 8.1 内容分层

| 层级 | 要求 | 是否进入考核 |
| --- | --- | --- |
| `verified` | 人工校订原文、来源、注释、答案 | 是 |
| `assisted` | AI 生成解释或补充，明标“AI 生成，供参考” | 否 |
| `community` | 用户共创或外部导入 | 默认否，需审核 |

### 8.2 来源规则

- 原典、碑帖、史书、公版文献逐条保存来源、版本和权利状态。
- 不使用未授权现代注本、商业字帖、受版权保护的题库扫描件。
- 党史与政治优先官方公开材料与可核验经典。
- 历史材料必须能追溯作者、时间、版本与传播链。
- 周易的术数部分只做规则与文化演练，不宣称预测现实。

### 8.3 AI 边界

- AI 可以解释已预写内容、追问、出变式题。
- AI 不得伪造原文、出处、注家引文或历史事实。
- AI 生成内容必须明标来源层，不覆盖 `verified` 内容。
- 练习判卷以预写答案和纯函数规则为主，AI 只做解释辅助。

### 8.4 精品课程验收门

课程不能以“已录入标题”算完成。进入可学习状态前必须同时满足：

- 有至少一条可追溯原文、官方文件、公版资料或平台原创底稿。
- 每个原文片段保存作者、版本、出处、页码或链接、许可状态。
- 注释、注解、译文与转述分层，不伪造引文。
- 有零基础入口、进阶路径和完整单课教案。
- 有练习测评、实践任务、复习卡和常见错误。
- 图片、牌面、碑帖、曲谱和表格逐件核验版权。
- 涉及健康、法律、投资、现实安全或占卜预测时，显示明确边界。
- 自动检查和人工抽检均通过；未通过的课程只能显示“建设中”，不能进入空白页。

## 十二、风险与对策

| 风险 | 对策 |
| --- | --- |
| 新科目内容量过大 | 先定义完整课程骨架，再做 P0 精读课；只把 `verified` 内容用于考核 |
| 政治、军事、党史内容争议 | 来源卡、版本、时间、立场标签前置；统一学术边界与审核清单 |
| 书法字帖版权 | 只用公版碑帖扫描或授权资源；硬笔范字自研；逐件保存许可 |
| 书籍全文版权 | 仅分发公版或授权全文；受版权保护书目使用授权版本或用户自有书库 |
| 占卜内容被误当现实建议 | 固定免责声明、概率与心理提示、危险主题转介专业意见 |
| 塔罗/星图/水晶球素材版权 | 只使用公版或授权图像，逐项记录许可与版本 |
| AI 伪造引文 | 原文库、引用 id、白名单注本，AI 不得直接生成考核材料 |
| 移动端再次“各科补丁” | 页面骨架和选择器共用，科目只提供内容与步骤，不拥有独立布局 |
| 旧 Bug 干扰重构 | 不在旧结构继续叠补丁；重构后按新契约重新验收旧问题 |
| 课程入口数量爆炸 | 桌面分组路径、移动分组浮层 + 搜索；总览只展示当前阶段和继续学习 |
| 书法反馈主观 | 只反馈位置、角度、粗细、起收等可观察指标，不做笼统审美打分 |

## 十三、需要拍板

1. 是否接受“19 科统一八页面族 + 科目专属步骤引擎”的总方案。
2. 是否接受新增十三科共 232 门首批课程骨架，其中占卜 20 门、物理 20 门、日语 19 门、经济学 20 门、书法 19 门、数学 19 门、百家思想 19 门。
3. 书法是否按“公版经典碑帖 + 自研硬笔范字”执行。
4. 党史、政治、军事是否采用本方案的来源与边界规则。
5. 首批实施顺序是否按“书法、数学、百家思想 → 党史、历史、政治、军事 → 记忆、思维 → 现有六科迁移”。
6. 旧 Bug 是否统一放到新底座完成后重新验收，而不是继续在旧页面上打补丁。
