# 学习模式设计准则

## 核心原则：学习内容优先于工作区

学习模式不是把课程卡片、路线地图、聊天、术语表和工具同时铺在页面上。用户进入一个知识点后，界面必须让位于这个知识点本身。

### 1. 先选课，再沉浸

- 路线、课程目录、进度和术语索引属于“进入学习前”的导航层。
- 点击某个知识点或模块后，进入独立沉浸学习台。
- 沉浸学习台必须覆盖或收起全局导航、侧栏、路线图和其他非当前学习内容。

### 2. 一次只显示一个学习步骤

- 概念、推导、攻防、实验、自测是独立步骤，不应全部展开在同一个长页面里。
- 当前步骤只显示当前知识点相关内容；上一题、下一题和步骤导航使用紧凑控件。
- 主要学习内容不得使用下拉折叠作为默认交互。展开式列表只适合次要说明，不承担主学习流程。

### 3. 保持方向感，但不制造噪音

- 沉浸学习台只保留四项必要信息：当前课程、当前步骤、进度、退出入口。
- 需要时再显示术语、提示、答案和辅助说明；不要持续占用阅读区域。
- 退出沉浸后必须回到原来的路线位置，并保留完成进度。

### 4. 适合长内容阅读

- 阅读区域应有稳定最大宽度，正文对比度满足 WCAG AA。
- 深色外层可以降低环境干扰，正文使用独立阅读表面，避免整屏高饱和色和装饰性背景。
- 桌面端支持键盘操作，移动端步骤导航改为横向滚动，底部前进按钮保持可见。

### 5. 所有学习科目最终都要遵守

英语、网络安全、软考以及后续新增学习科目，都应采用“总览层 + 沉浸学习层”的结构。迁移必须按科目分批进行；修改某一科目时，不要顺带重构其他科目的交互。

## 网络安全课程的当前实现

- 路线总览：路线切换、模块列表、完成进度、授权范围。
- 沉浸学习台：当前模块、五步学习导航、单步内容、上一页/下一页、完成页。
- 概念术语与自测答案均使用显式切换或按钮，不使用下拉展开。
- 沉浸期间锁定页面滚动，并通过 `Escape` 或“返回路线”退出。
