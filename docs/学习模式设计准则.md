# 学习模式设计准则

## 核心原则：学习内容优先于工作区

学习模式不是把课程卡片、路线地图、聊天、术语表和工具同时铺在页面上。用户进入一个知识点后，界面必须让位于这个知识点本身。

### 1. 先选课，再沉浸

- 路线、课程目录、进度和术语索引属于“进入学习前”的导航层。
- 点击某个知识点或模块后，进入独立沉浸学习台。
- 沉浸学习台必须覆盖或收起全局导航、侧栏、路线图和其他非当前学习内容。

### 2. 一次只显示一个学习步骤

- 概念、推导、攻防、实验、自测是独立步骤，不应全部展开在同一个长页面里。
- 当前步骤只显示当前知识点相关内容；上一题、下一题和步骤导航使用紧凑控件。
- 主要学习内容不得使用下拉折叠作为默认交互。展开式列表只适合次要说明，不承担主学习流程。

### 3. 保持方向感，但不制造噪音

- 沉浸学习台只保留四项必要信息：当前课程、当前步骤、进度、退出入口。
- 需要时再显示术语、提示、答案和辅助说明；不要持续占用阅读区域。
- 退出沉浸后必须回到原来的路线位置，并保留完成进度。

### 4. 适合长内容阅读

- 阅读区域应有稳定最大宽度，正文对比度满足 WCAG AA。
- 深色外层可以降低环境干扰，正文使用独立阅读表面，避免整屏高饱和色和装饰性背景。
- 桌面端支持键盘操作，移动端步骤导航改为横向滚动，底部前进按钮保持可见。

### 5. 所有学习科目最终都要遵守

英语、网络安全、软考以及后续新增学习科目，都应采用“总览层 + 沉浸学习层”的结构。迁移必须按科目分批进行；修改某一科目时，不要顺带重构其他科目的交互。

## 6. 移动端总览骨架（≤900px，2026-11-16 用户评审定稿 v1.1，交互稿 mobile-learning-redesign/）

所有科目总览层共用同一骨架，桌面（>900px）零改动；**后续新增科目必须同时出桌面 + 移动双设计**：

1. **科目收进顶栏**：移动端顶栏标题即「{科目} ▾」，点击弹科目切换；科目选择行与引导文案在移动端隐藏（设置项不占首屏）。
2. **阶段 + 课程 = 一个下拉**（v1.1 评审定稿）：下拉按阶段分组（optgroup），选项 = 具体课程，一行 44px 替代 400px 纵向手风琴；选中即切换内容区并收起。
3. **继续学习主卡**：唯一的大卡 = 当前课程第一个未完成课件 + 进度条 + 主按钮；装饰 hero 横幅一律删除。
4. **课件 = 横向滑动单行**（v1.1 评审定稿）：全部课件进一条横轨（单卡 ~150px），不出现「展开全部 N 节」按钮，不用纵向长列表。
5. **带搜索的长列表（软考真题 / 网安模块库等）用 bottom sheet**：拖拽把手 + 搜索 + 吸底「从上次位置继续」；sheet 用 absolute 定位实现，不新增 `:has()` / fixed 依赖（老 WebView 兼容）。
6. **高频动作吸底**：今日复习/继续 CTA 常驻 TabBar 上方（拇指热区）。
7. **触摸目标 ≥44px**；工具入口一行图标 chips 替代割裂的 tab 行。
8. **朗读**：任何页面/步骤都有常驻朗读入口，失败必须显性化（按钮态提示原因），不允许无声无息。安卓无 TTS 引擎的设备由 APK 内置离线引擎兜底（sherpa-onnx），iPhone 走系统 AVSpeech。
9. **沉浸层必须完全盖住总览层**：进入沉浸学习后，底层课程卡、继续学习卡、总览 Tab、全局 TabBar 和页面滚动内容一律不可见、不可点击、不可获得焦点。禁止出现沉浸内容与底层页面上下同时露出的双层状态（2026-11-17 移动端截图问题，列为发版阻断项）。
10. **底部步骤操作属于沉浸层自身**：上一页/下一页必须固定在沉浸层的安全区内，不得叠在底层页面内容上；退出后恢复进入前的滚动位置和课程定位。
11. **移动端科目切换固定在顶栏**：顶栏主标题始终显示当前科目并带下拉标识，点击打开完整 19 科选择抽屉；切换后课程卡、进度、复习和训练内容同步更新。
12. **图书馆必须有独立入口和独立页面**：学习总览顶栏显示带文字的“图书馆”入口；图书馆使用“发现 / 书架 / 书源”三区，不是学习页的第四个 Tab，也不藏在课程下拉或折叠项里。

## 网络安全课程的当前实现

- 路线总览：路线切换、模块列表、完成进度、授权范围。
- 沉浸学习台：当前模块、五步学习导航、单步内容、上一页/下一页、完成页。
- 概念术语与自测答案均使用显式切换或按钮，不使用下拉展开。
- 沉浸期间锁定页面滚动，并通过 `Escape` 或“返回路线”退出。

## 英语课程的当前实现

- 主线总览：7 个阶段、120 节课程，覆盖自然拼读、词根词缀、高频语法、寓言精读、短篇阅读、长篇连载和口语任务。
- 沉浸学习台：每课固定按“理解 → 例句 → 练习 → 自测”四步展开，一次只显示当前步骤。
- 词根课至少提供 8 个同根词，例句页使用可点读词族卡和拆词提示，避免把词根课做成四词示例。
- 语法微课：42 个高频语法点使用独立全屏微课，按“规则 → 例句 → 纠错”三步学习，不再使用行内折叠。
- 故事内容：寓言使用公版素材原创改写；长篇使用同一故事线分章连载，避免只给阅读样例。
- 进度与退出：课程完成状态保存在本地，退出沉浸后回到原路线位置。

## 周易课程的当前实现（独立学科，docs/周易课程方案-2026-11-15.md）

- **独立学科注册**：与英语/传统文化/音乐平级，走声明式扩展表（`subject-extensions.ts` 周易三 Tab：课程主线 / 测算实践 / 陪练对话）；不进传统文化四阶，不共享 `CultureWorkbench`，`culture/` 目录零改动。
- 总览层：T0–T7 八条路径折叠展开；课时列表筛选固定顶部、列表区独立滚动；未就绪课程带「建设中」徽标且不可进入（总览层 disabled + 组件内双保险），绝不出现空课页。
- 沉浸学习台：`position:fixed; inset:0; z-index:3000`，顶栏四项（返回路线 / 课程名 / 步骤 x/n / 退出），一次一步，Escape/←→/Tab 焦点陷阱，锁 body 滚动。
- 步骤序列：`annotate`（注释步：term 最长匹配切词，点词开右侧 AnnotationPanel 抽屉）→ `interpret`（注解步：按传/注/笺/疏/今按显式分组，逐字原注 / 大意转述 / 今按·编者释义三类标签）→ `plain`（白话）→ `structure`（脉络）→ `check`（自测）。read 课注释步提供中文诵读（`useZhSpeech` 复用，不调英文 `/tts`）。
- **注释与注解两层是硬约束**：每行原文两者都非空（行级 100%，`zhouyi-curriculum.test.ts` 按行断言）；转述必须显式标注，绝不编造逐字古注。
- 测算实践台：独立一级 Tab，五步（输入 / 推演 / 原文对照 / 规则复盘 / 记录）一次一步；推演用 `packages/shared/src/zhouyi/` 纯函数（同 seed 可复现）；断语只查古籍规则白名单并标「规则演示」；进台与结果页都带「民俗文化体验 · 教学演示」标识；出生时间不落 localStorage、导出剥离输入。
- 进度：本地 `yz.zhouyi.*` key + 服务端 lesson-progress（subject='周易'）双写；退出沉浸回原路线位置。

## 学习 V2 精品课准入（2026-11-17）

- 正式教案集中在 `packages/shared/src/learning/v2-curated/`，按学科分文件维护，不把长文案重新塞回页面组件。
- 每门已审校课程必须包含前置知识、可观察学习目标、示范、独立练习、至少两个常见错误、带链接的来源和完整单步教案。
- 每个学习步骤必须能直接教学：显示本步目标、分段讲解、跟做记录、完成检查和本步最易出现的偏差；不能只给一句摘要。
- 教案正文只写学科事实、背景、机制、例子和论证。写作意图、学习流程说明、对读者的提醒不得混入正文，应放进独立的“本步目标 / 怎么做 / 完成检查”区域。
- 每个知识步骤提供可展开的“学霸笔记”：一句话结论、核心知识、解题或操作模板、高频坑、闭卷自测，并附整章索引；学生可一键套用到自己的笔记。
- 每本书的注解示范固定分五层：原文、字词注释、章旨注解、白话转述、来源与边界。注解必须解释内容，不能写“注释负责什么”这类教学说明。
- 学习总览必须透出用户当前壁纸；学习内容使用分层玻璃表面保证可读，不得用整页实色灰底把壁纸盖掉。
- 桌面科目栏必须支持展开/收起，收起后保留可识别的科目图标和可达入口。
- 课程地图的阶段标题必须可折叠，并显示阶段序号；课程必须显示全局课时序号。
- 当前 327 门课程全部可学，覆盖全部 19 科。其中 173 门为人工审校教案，154 门为按学科步骤规则整理并经过内容契约校验的完整教案；不再保留不可进入的“建设中”课程。
- 课程地图、移动课程下拉和旧会话恢复共用 `isLearningV2CourseReady()` 准入判断；草稿课程显示“建设中”且不可进入。
- 课程卡的“已完成/进行中/未开始”由真实进度计算，不再使用原型目录里的示例状态。
- 新增课程内容后至少运行 shared 内容契约、Learning V2 挂载测试和 Web 生产构建。

## 公共图书馆与书源（2026-11-17）

- 图书馆采用“发现 / 书架 / 书源”三区，桌面三栏、移动端列表加底部详情抽屉，不使用套娃卡片。
- 书籍分类固定包含经典名著、志怪小说、网络小说、漫画和课程原典；课程原典继续允许跳回对应科目的书籍研读。
- 书架、书源启停和自定义书源保存在本地；自定义书源只接受完整 HTTPS 地址。
- 内置书源必须写明公版、开放许可、馆藏借阅或官方授权状态，并保留逐条许可说明。
- 网络小说只登记官方授权平台入口，不在应用内抓取、复制或绕过登录、付费和地区限制。
- 图书馆内置小说、文章、名著与漫画阅读器：TXT/MD 可导入为可读正文，多张图片可按文件名顺序导入为漫画分页；阅读器提供章节目录、阅读进度、注释、翻译、五种阅读背景、护眼/关灯模式、字号、行距、字间距、正文页宽和漫画缩放设置。
- 书架同时提供卡片/列表视图与嵌套目录。卡片用于浏览封面，列表用于快速定位；书籍可在“发现”页加入书架并移动到任意目录，删除目录时其内容回到父目录，不丢书也不丢进度。
