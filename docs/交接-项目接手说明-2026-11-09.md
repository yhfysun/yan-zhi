## 2. 环境与运行（换机器最容易卡的地方）

- **端口**：后端统一 **3001**（旧记 dev=3002 已废）。`netstat` 见 `1420(vite dev) + 3001` ⇒ dev；
  只有 3001 ⇒ 打包版。自起独立验证实例用 `PORT=5199`。
- **数据库**：`%APPDATA%/yan-zhi/server-data/data.db`（dev 与安装版同一库，改数据会影响实机）。
  读实时 SQLite 必须把 `-wal` / `-shm` 一起复制；诊断用 Python 内置 `sqlite3` 只读。
- **dev 后端不是 watch**：electron + tsx loader，改服务端代码必须**重启 dev 应用**才生效
  （曾出现 curl 3001 返回 404 误判为代码没写）。
- **GitHub 网络**：本机直连 `github.com` 必超时。git 一律
  `git -c http.proxy=http://127.0.0.1:7890 ...`（FlClash）。环境变量注入的代理端口每次不同
  （实测过 51127 / 51163 / 55944 / 60972），排障先 `env | grep -i proxy` + `netstat -ano | grep 7890`；
  `git config --get http.proxy` 为空不代表没代理。大仓库 fetch 用单分支 refspec，别 `--prune` 拉全分支：
  ```
  git -c http.proxy=http://127.0.0.1:7890 fetch --no-tags origin \
    '+refs/heads/dev0.1-mobile:refs/remotes/origin/dev0.1-mobile'
  ```
  credential-manager 路径缺失告警不影响 push。
- **常用命令**（本机 pnpm 11.20.0 可用；`vue-tsc`/`vitest` 走 pnpm 真实入口，`.bin` shim 在 Git Bash 不可用）：
  ```
  pnpm exec tsc -p apps/server/tsconfig.json --noEmit
  pnpm --filter @yan-zhi/core typecheck
  pnpm --filter @yan-zhi/ui typecheck
  pnpm --filter @yan-zhi/ui exec vitest run <file> --no-file-parallelism
  pnpm --filter @yan-zhi/server exec vitest run --no-file-parallelism
  node --test apps/desktop/test/<file>.test.cjs
  pnpm build:web
  ```
  ⚠️ vitest 多 worker 并发会触发沙箱 fs `EPERM` 并**静默丢测试文件**（指定 5 个只跑 3 个却显示通过）
  ⇒ 一律 `--no-file-parallelism`；UI 测试与 `build:web` 别并行跑（会以 exit 143 假失败）。
- **打包**：新增 `main/preload` 的 `.cjs` 必须登记 **4 份** `electron-builder.{full,lite,mac,shell}.yml`
  （守门测试拦的是 mac.yml，别只记三份）；打包版 userData 名 `yan-zhi`；`apps/server/src` 禁放 `.test.ts`。
- **electron 二进制缺失**会让 3 个 extension-* 测试假红：
  `cd apps/desktop/node_modules/electron && ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ node install.js`。
  清 node_modules 需 `CI=true`。
- **插件改 src 不生效**：运行时加载 `apps/server/plugins/builtin/<id>/backend/index.js` **构建产物**，
  改完必须 `node apps/desktop/scripts/build-plugins.mjs --id=<id> --out=apps/server/plugins/builtin`
  再 touch `apps/server/src/index.ts` 触发重启。

## 6. 最贵的工程判据（重踩过的，动手前先过一遍）

1. **断言「存在」≠ 断言「生效」**：写入≠读取、包了壳≠进判定集合、调用在≠分支可达。能真跑就真跑。
2. **改阈值 / 系数 / 默认值前先 grep 附近注释**：值往往有「为什么不能改成别的」的记录。
3. **同一语义只能有一处实现**，必要保护收口到唯一出口（`registry.execute` 裁输出、
   `selectMemoryLines` 选记忆、`allowedRootsFor()` 守边界、`testKindsOf` 定测试项）。逐处补必然漏。
4. **跨层改动要核查下层是否把效果抵消**；给列表加筛选后「全选 / 批量」的作用域会静默变错。
5. **带 App 外壳的页面别用 `100vh` / `calc(100vh - 常数)`**：可用高 = 视口 − 顶栏 − AppStatusBar，
   用 `flex:1 + min-height:0` 继承父级剩余空间。
6. **往 `v-if/v-else` 链插分支必须连链首一起改**：只插 `v-else-if` ⇒ Vite `Codegen node is missing` 崩，
   `vue-tsc` 不报，只有 SFC 编译报。
7. **`api.get` 返回 `ApiError | {data}` 联合类型**：`unwrap<X>(r)` 只解一层，再 `.data` 恒 undefined ⇒
   全页数据静默失效。unwrap 类助手必须配真挂载测试钉住解包层数。
8. **跨实体视图绝不共用「当前实体」缓存**：`platformStore.models` 被 `loadModels(pid)` 覆盖成单平台清单
   ⇒ 跨实体页静默空列表；独立页用 `ensurePlatforms/ensureModels`（走 `/platforms/all-models`）。
9. **`export *` 的同名导出会静默覆盖且 tsc 不报错**；新增导出前先 grep 全仓同名符号，重名复用既有实现。
10. **个人数据必须强匹配 `user_id`**：`IS NULL OR = 本人` 对 `custom` 数据是泄露模式，NULL 只该属于显式共享类型。
11. **CSS 自定义属性值含引号外的顶层分号 → `setProperty` 整条静默丢弃**：图案 / data URI 必须包 `url("...")`。
12. **git**：并行会话下 `git status` 不可信；`git add` 逐文件挑、提交用**不带路径**的 `git commit`、
    验收看 `git show --stat`；`git commit -- <paths>` 不收新文件（新文件必须先 add）；
    `core.autocrlf=true`，批量改源码别用 Python 文本模式整文件写（会把 LF 变 CRLF，锚点含 `\n` 的测试全断）。

   明确区分「已完成 / 未完成 / 未验证」。
