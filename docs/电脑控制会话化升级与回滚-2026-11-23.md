# 电脑控制会话化升级与回滚（2026-11-23）

## 已启用行为

- 会话工具：`computer_control_start` → `computer_control_observe` → `computer_control_act` → `computer_control_end`。
- 黄色目标窗口边框在观察和输入动作时持续续租；默认 1.8 秒无动作自动消失。
- 控制条可接管或取消；`Esc` 触发急停，主进程立即拆除 overlay。
- `computer_control_handoff(action="take")` 冻结 AI 输入；`return` 后必须重新观察窗口。
- 应用首次访问返回 `APP_APPROVAL_REQUIRED`，用户确认后使用 `computer_control_app_approval` 记录授权。
- 风险动作按 `read/local_write/external_send/destructive/financial/security_or_auth/unknown` 分级；
  高风险动作必须先用 `confirm_user` 取得具体动作、目标和数据确认，再传 `preapproved=true`。
- 任务进入终态时 UI 调用 `/api/plugin/computer-use/control-end`；插件管理页也可查看活动会话并结束全部。

## 零残留规则

- Electron 主进程是 overlay 唯一所有者。
- 正常停止、取消、急停、插件禁用或应用退出时立即 `hide + destroy`。
- 心跳丢失、后端断开、渲染崩溃或窗口关闭时由租约看门狗清理，最长残留 2 秒。
- 会话结束、过期或插件禁用时同步删除该会话临时截图。

## 回滚

1. 在插件配置中设 `sessionV2: false`：停止注册新会话路径的常驻输入路由，保留旧 `computer_*` 工具。
2. 无法读取配置或需要立即止损时，禁用 `computer-use` 插件；overlay 和输入代理会一起关闭。
3. 全局急停 `Ctrl+Alt+Esc` 仍是最高优先级安全阀。
4. 回滚后检查插件管理页活动会话为 0，并确认桌面上没有黄色边框、AI 光标或控制条。
