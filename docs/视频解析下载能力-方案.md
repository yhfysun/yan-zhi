# 视频网站解析下载能力 —— 方案

> 目标：让智能体能**直接拿 YouTube / B站 / 抖音 等页面链接**就下载视频，真正能下
> 「骑单车 / 修驴蹄 / 压缩机」这类解压长视频，不必先手工找 `.mp4` 直链。

## 一、现状与缺口

- `api_media_fetch` 只处理**文件直链**（`.mp4/.webm`）。页面地址（YouTube/B站/抖音）会下成 HTML 失败。
- 解压视频 90% 在 YouTube，直链基本拿不到 → 现有能力**下不动**。
- 这是 2026-09-27「让大模型去下载公开解压视频」诉求的**下半场**（上半场已加直链下载+提示词放行）。

## 二、技术路线（推荐）

**集成 `yt-dlp`（独立 exe 路线，不依赖 Python）**

- 理由：覆盖 YouTube + B站 + 抖音 + 西瓜 + 上千站；自带 ffmpeg 合并音视频（本机 ffmpeg 已装）。
- 装法照 `ffmpeg-runtime.ts`：下载 `yt-dlp.exe` 到应用数据目录，`resolveYtdlp()` 返回路径，`installYtdlp()` 从 GitHub release 拉取；环境变量 `YZ_YTDLP_PATH` 可覆盖。
- 运行时：`yt-dlp.exe -o <out.mp4> -f best <url>`，音视频自动合并（用已装 ffmpeg）。

## 四、风险分级

- **HIGH**：YouTube 受反爬 + bot 检测，常需代理 / cookie（`yt-dlp` 支持 `--proxy` 与 `--cookies-from-browser`）。本机有 FlClash 代理（127.0.0.1:7890），但 YouTube 仍可能要浏览器 cookie 才能下。B站/抖音/西瓜国内直连稳定。
- **MEDIUM**：`yt-dlp` 需随上游更新（YouTube 改版即失效），安装后保留更新入口。
- **LOW**：代码改动局部，不影响现有直链下载路径（零回归，直链分支逻辑不变）。
