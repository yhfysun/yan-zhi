## ✅ 改了什么

1. **新增模块级助手（`insertMessage` 之后）**：
   - `SubAgentOwnership` 接口：子智能体归属四连字段（parentToolCallId/subAgentId/subAgentName/subAgentDepth）
   - `insertToolMessageAndEmit(task, convId, userId, toolCallId, content, ownership?)`：落库 tool 消息 + 推送 `message:added`，归属字段两处口径在此对齐
   - `runToolCallAndPersist(opts)`：**工具调用统一出口** —— emit tool:start → executeTool（或取并发预执行结果 `precomputed`）→ 中止分支（落库 `[已中止]` 后原样上抛）→ 错误串 → `runAfterToolHooks` → `capToolResult` → 落库 → `message:added`

2. **主循环**（runTask）工具调用块 ~60 行 → 调 `runToolCallAndPersist`（含 `precomputed` 支持并发 call_agent 已执行结果）

3. **子智能体循环**（runSubAgent）工具调用块 ~60 行 → 同一出口，差异只通过 `ownership: subOwnership` 表达；`subOwnership` 在 `subAgentName` 声明后定义
