# AI Assistant 产品需求文档（PRD）

> 项目代号：AI Assistant（参考 Cherry Studio + DE-GPT 设计，基于 OpenAI 标准协议）
> 项目路径：`C:\Users\yhfys\Desktop\ai-assistant`

## 1. 产品概述

一款本地优先的跨端 AI 助手应用，覆盖桌面（Windows/macOS/Linux）、Web、移动端（iOS/Android）三端，统一一套 Vue 3 代码库。核心理念是"协议开放、数据本地、工具可挂、智能体可编排"。

- **目标用户**：开发者、AI 应用搭建者、需要把多个 LLM 平台与工具编排成工作流的人
- **核心价值**：替代 Cherry Studio，并扩展智能体工作流 + Skill 商店 + 子智能体编排 + 上下文压缩能力
- **协议基础**：所有模型接入遵循 OpenAI Chat Completions / Embeddings 协议，支持流式输出、函数调用、思考模型 `reasoning_content`

## 3. 核心功能

### 3.1 模型平台管理

**配置平台**：每个平台包含名称、协议类型（openai/anthropic/custom）、apiurl、apikey、默认 headers（如 `Authorization: Bearer xxx`、`Helicone-Auth: xxx`）、模型拉取策略（自动拉取 `/v1/models` 或手动添加）。

**模型管理**：
- 按平台分组展示模型表格
- 字段：模型 ID、别名、类型（llm/embedding/rerank）、上下文窗口、是否启用、是否默认
- 操作：编辑别名、设默认、启停、测试连通性（发送 `max_tokens=5` 的小请求验证）
- 模型元数据：支持手动填写 context_window、定价、能力标签（function_call/vision/reasoning）

**平台健康检查**：定时（默认 5 分钟）后台 ping `/v1/models` 端点，失败时卡片标红，并显示最近成功时间。

### 3.2 MCP 服务管理

**三种传输协议**：
- **stdio**（仅桌面端）：配置启动命令、参数、环境变量，由 Tauri Rust 启动子进程并通过 stdin/stdout 通信
- **SSE**（全端）：配置 URL + Headers，通过 Server-Sent Events 通信
- **Streamable HTTP**（全端）：配置 URL + Headers，单 HTTP 流式通信

**MCP 服务详情**：
- 工具列表预览：名称、描述、JSON Schema 输入参数
- 资源（resources）列表预览
- 提示词（prompts）列表预览
- 连接日志：最近 100 条 JSON-RPC 请求/响应
- 按会话启用统计：哪些会话挂载了此服务

**新增服务表单**：
- 名称、协议选择
- stdio：command、args（数组）、env（键值对）
- sse/http：url、headers
- 自动重连开关、重连间隔
- 启动时是否自动连接

### 3.3 聊天工作台（Cherry Studio 风格）

**会话管理**：
- 左侧会话列表，支持分组、置顶、搜索、重命名、删除
- 每个会话绑定：平台 + 模型 + MCP 工具集 + Skill 列表 + 系统提示词
- 会话主题（Topic）：同一会话下可分叉出多个话题，类似 Cherry Studio 的 Topics

**消息流**：
- 用户消息：右侧气泡，附件以卡片形式展示
- AI 消息：左侧无气泡卡片，Markdown 渲染（代码块带语言标识 + 复制按钮、表格、引用块、数学公式 KaTeX）
- 思考链：可折叠区域，渐显动画，灰色字体
- 工具调用：折叠条展示"调用了 xxx 工具"，展开看入参/结果 JSON
- 流式输出：字符级流式，首 token 显示光标
- 消息操作：复制、重新生成、编辑后重发、Pin 到侧栏、删除
- 多模态：图片粘贴/拖拽上传，按模型能力转换为 `image_url` content part

**输入区**：
- 多行自适应高度输入框
- `@` 触发工具/Skill 选择面板（类似 Slack @mention）
- 底部工具栏：模型切换 chip、温度滑块、最大长度、附件按钮、发送按钮
- 快捷键：Enter 发送、Shift+Enter 换行、Ctrl+K 清空、Ctrl+L 切换模型

**侧栏**：
- Pin 消息列表
- 变量面板（用于模板替换）
- 当前挂载的 MCP 工具列表（可临时取消挂载）
- 当前启用的 Skill 列表
- 上下文 token 用量进度条

### 3.4 Skill 商店与管理

**Skill 格式**（参考 DE-GPT 与 Claude Skills 规范）：
```markdown
---
name: excel-analysis
description: Excel 数据分析与可视化
triggers:
  - excel
  - xlsx
  - 数据分析
tools:
  - mcp:excel-reader
  - mcp:chart-renderer
---

# Excel 分析 Skill

当用户上传 Excel 文件时，按以下步骤处理：
1. 读取文件结构...
2. ...
```

**商店首页**：
- 卡片网格，4 列响应式
- 每个卡片：图标、名称、描述、作者、安装数、安装按钮
- 分类筛选：数据分析、写作、编程、设计、办公、自定义
- 搜索框

**本地管理**：
- 已安装 Skill 列表，启用/禁用开关
- 查看 SKILL.md 原文
- 编辑（仅自建）
- 卸载
- 导入/导出（.zip 或 .md 文件）

**自建 Skill**：
- Markdown 编辑器（带 front-matter 表单提示）
- 实时预览
- 测试运行：在右侧聊天区直接测试 Skill 效果

### 3.5 智能体编排

**工作流画布**（基于 Vue Flow）：
- 左侧节点库面板：拖拽添加节点
- 右侧属性面板：编辑选中节点配置
- 顶部工具栏：保存、运行、调试、版本切换、导出
- 画布：网格背景、节点圆角卡片、SVG 贝塞尔连线、运行时节点高亮流光

**节点类型**：
| 节点 | 配置 | 说明 |
|------|------|------|
| LLM 调用 | 平台、模型、系统提示词、温度、最大长度 | 调用 LLM 生成回复 |
| 工具调用 | MCP 服务、工具名、参数映射 | 调用 MCP 工具 |
| 条件分支 | 条件表达式（基于上一步输出） | 路由到不同分支 |
| 循环 | 迭代源、最大次数、退出条件 | 遍历列表或重复执行 |
| 子智能体 | 选择已注册智能体、入参映射、并行度、超时 | 委托给子智能体 |
| 记忆读写 | 读：查询条件、Top K；写：内容、标签 | 操作长期记忆 |
| 输入/输出 | 入参 Schema、出参映射 | 工作流入口/出口 |
| 代码 | JavaScript 表达式 | 简单数据转换 |

**运行模式**：
- 调试模式：单步执行、断点、查看每个节点上下文
- 正式运行：完整执行，记录轨迹
- 回放：查看历史运行轨迹，画布上逐步高亮

### 3.6 子智能体管理

**注册为子智能体**：任意智能体可勾选"允许被其他智能体调用"，自动生成函数签名（基于 inputs_schema）。

**主智能体调用方式**：
- 通过"子智能体"节点直接调用（同步等待结果）
- 通过 LLM 函数调用间接调用（LLM 决定是否调用、调用哪个）
- 并行调度：同时调用多个子智能体，汇总结果

**配置项**：
- 入参映射：从主智能体上下文取值填入子智能体入参
- 并行度：1-10
- 超时：默认 60s
- 回退策略：超时/失败时的兜底输出
- 结果处理：合并/取第一个/取最佳

**调用链可视化**：运行时显示主智能体 → 子智能体的调用树，可点击展开查看每层的输入输出。

### 3.7 记忆与上下文压缩

**短期记忆（会话级）**：
- 默认保留最近 N 条消息（可配置，默认 20）
- 超过 token 上限时触发自动压缩

**长期记忆（智能体级）**：
- 存储到 SQLite + sqlite-vec 向量表
- 写入时机：智能体运行结束时、用户手动添加、定时摘要
- 检索方式：向量相似度 + 标签过滤 + 元数据过滤
- 每条记忆字段：内容、标签、向量、元数据、创建时间、最近使用时间
- 衰减策略：长期未使用的记忆降低权重（可通过 last_used_at 排序）

**上下文压缩算法**：
1. 检测：当会话 token 数超过模型 context_window 的 80% 时触发
2. 切分：保留最近 N 条（默认 6）作为"短期记忆"
3. 摘要：把更早的消息交给小模型（如 gpt-4o-mini）生成摘要
4. 替换：用 `{role: system, content: "前文摘要：..."}` 替换被压缩的消息
5. 持久化：原始消息保留在数据库，仅在发送给 LLM 时压缩
6. 用户可手动触发"立即压缩"或"还原完整上下文"

## 4. 用户界面设计

### 4.1 设计风格

- **整体定位**：现代科技 + 毛玻璃质感，延续 DE-GPT Web UI 视觉语言（动态光球背景 + 半透明卡片 + saturate 增强）
- **主色调**：保留可随机切换的 5 套配色（Ocean / Forest / Sunset / Aurora / Rose），主色 #3B82F6
- **按钮风格**：玻璃底 + 渐变主色按钮 + 同色辉光阴影
- **字体**：UI 字体用 `-apple-system, "Segoe UI"`，代码字体用 `"JetBrains Mono", "Cascadia Code"`
- **布局**：左侧固定导航栏（56px 折叠/240px 展开）+ 主内容区，桌面优先
- **图标**：使用 `@element-plus/icons-vue` + lucide，线性风格，2px 描边
- **动画**：消息进入淡入 + 上滑 8px，卡片 hover translateY(-1px)，节点连线 SVG 流光动画

### 4.2 页面设计概览

| 页面 | 模块 | UI 元素 |
|------|------|---------|
| 聊天工作台 | 消息流 | 用户消息右侧气泡、AI 消息左侧无气泡卡片、工具调用折叠条、思考链渐显 |
| 聊天工作台 | 输入区 | 圆角玻璃容器、@提及弹出工具面板、底部模型选择 chip |
| 模型平台 | 平台卡片 | 64px Logo + 名称 + 状态点 + 模型数徽标 |
| 智能体 | 工作流画布 | 网格背景、节点圆角卡片、SVG 贝塞尔连线、运行时节点高亮 |
| Skill 商店 | 卡片网格 | 4 列响应式、悬停翻转展示描述、安装按钮渐变 |

### 4.3 响应式策略

- **桌面（≥1024px）**：完整三栏布局，画布全屏可用
- **平板（768-1024px）**：导航栏折叠为图标，侧栏改为抽屉
- **移动（<768px）**：单栏 + 底部导航 Tab，画布改为节点列表 + 步骤执行
- **触控优化**：按钮命中区 ≥44px，长按触发上下文菜单，画布支持双指缩放

## 5. 三端差异化

| 能力 | 桌面（Tauri） | Web（PWA） | 移动（Capacitor） |
|------|--------------|-----------|------------------|
| 本地数据存储 | SQLite (原生) | IndexedDB (Dexie) | SQLite (原生插件) |
| MCP stdio 子进程 | 完整支持 | 仅远程 SSE/HTTP | 仅远程 SSE/HTTP |
| 文件系统访问 | 完整 | File System API | 受限目录 |
| Skill 本地目录 | 文件系统 | IndexedDB 虚拟 FS | 应用沙箱目录 |
| 系统托盘/通知 | 支持 | 不支持 | 支持 |
| 离线可用 | 支持 | 需 PWA 安装 | 支持 |
| 自动更新 | Tauri Updater | Service Worker | 应用商店 |

## 6. 非功能需求

- **性能**：首屏 ≤2s（本地），流式首 token ≤800ms（不含上游 LLM 延迟），10 节点工作流执行开销 ≤200ms
- **数据安全**：API Key 使用系统钥匙串（Tauri keyring）/ Web Crypto API 加密存储，不明文落盘
- **隐私**：所有对话数据本地存储，不上传任何服务器；同步功能需用户显式开启
- **可扩展**：MCP server、Skill、智能体节点类型均支持插件式注册
- **可移植**：桌面端支持 Windows/macOS/Linux 三平台，移动端支持 iOS/Android
