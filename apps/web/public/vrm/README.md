# 内置 3D 形象（VRM）

`sendagaya_shino.vrm` —— VRoid Studio 早期样例模型 **Sendagaya Shino**。

- 授权：**CC0 1.0**（VRoid 官方明确放开：可自由编辑、可再分发、可商用、免署名）
- 出处：https://vroid.pixiv.help/hc/en-us/articles/4402614652569 （镜像：https://opengameart.org/content/vroid-studio-cc0-models）
- 说明：仅作宠物伴星的默认 3D 形象；用户可在「设置 → 宠物 → 3D 形象」换成自己的 .vrm，
  文件只在本机读取（主进程读字节经 IPC 交给渲染层），不会上传。

替换方式：换掉同名文件即可（保持文件名，主进程按 `dist/vrm/sendagaya_shino.vrm` 定位）。
