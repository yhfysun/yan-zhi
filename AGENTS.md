# Repository Instructions

## Learning UI

- Immersive learning is a product requirement for every learning subject.
- Separate browsing/navigation from studying: route maps and course lists belong to the overview layer.
- When a learner opens a knowledge point, show only the current lesson step and the minimum navigation needed to move or exit.
- Do not use inline accordions or expandable module rows as the primary learning experience.
- Apply this requirement to all learning modes over time, but do not refactor subjects outside the scope of the current request.
- Read `docs/学习模式设计准则.md` before changing learning-mode UI.
