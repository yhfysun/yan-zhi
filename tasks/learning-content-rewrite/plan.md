# Learning V2 全科教案重写计划

## 目标

重写 Learning V2 全部 22 科、1387 门课程。执行单位固定为“科目 → 章节 → 课程 → 五个教学步骤”，一次只验收一个章节，不接受按字数补丁、批量替换措辞或沿用旧教案后只改标签。

## 初始基线与完成结果

- 运行时目录：22 科、1387 门课程。
- 初始 1245 / 1387 门课程已有五个步骤；算法、医学存在非五步课程，编程与其余未接入重写层的课程仍显示 `structured`。
- 完成时 1387 / 1387 门课程均为五步、`curated` / `reviewed`，并且通过来源、四题、实践、学习标记和重复门禁。
- 初始审计只检查长度、重复、题选项和少数字段；本轮逐科增加章节专项测试、代码实验证据、算法复杂度证据和医学安全边界。
- 旧审计把“没有空壳”当成“可以教学”，本计划不再沿用这个结论。

## 不可妥协的质量底线

1. 每课必须有前置知识、可观察目标、五个独立教学步骤、引导练习、独立练习、至少两个常见错误、完整答案和无障碍阅读文本。
2. 五个步骤固定承担不同教学功能：情境与前测、材料与概念、示范与推导、引导练习、独立迁移与形成性评价。不得把同一段解释拆成五份。
3. 来源必须能直接定位到正文或具体馆藏/课程页。机构首页、搜索引擎首页、无日期综述不能充当证据。
4. 重大事件必须有独立事件档案：背景、关键时间线、结局、意义和逐条来源卡；时间线节点必须绑定来源。
5. 事实、解释、价值评价必须分层。历史类课程至少使用两类相互独立的材料；自然科学必须给出条件、公式或实验证据；代码课程必须给出可运行样例和预期输出。
6. 每课至少四道四选一题，覆盖概念、材料/推导、常见误区和迁移应用四种功能，不能四题都在问同一个记忆点。
7. 练习、测验答案和正文必须相互对应。正文没教的知识不能进入独立练习，题解不能只重复“因为答案正确”。
8. 每章完成后做一次纵向复审：章内课序、概念依赖、术语一致性、时间线/公式体系、前后重复和缺口全部检查。
9. 只有“章节已验收”的课程才能显示人工审校。单门课程改完不等于章节完成。

## 章节执行流程

1. 盘点章节课程、先修关系和现有失败测试。
2. 建立参考源清单：官方教材/课程标准、权威公开教材、原始文献/论文、同类优秀教案。现代商业教材和教案只借鉴结构，不复制正文。
3. 写出章节目标、核心问题、概念顺序和评价蓝图。
4. 逐课重写五个步骤、练习、常见错误、四道题、来源和重大事件档案。
5. 运行本章专项测试、内容质量测试和类型检查。
6. 做一次“反方审阅”：检查事实错误、超纲、歧义、不可核来源、题目泄题和答案唯一性。
7. 更新本章台账为 `已验收`，再进入下一章。
