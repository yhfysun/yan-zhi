# collection — 抖音合集

## ★ 首集前必做（系列任务，2026-10-23 定稿）

**第一次发布就要建合集并勾选第一集，不是发完再补。**

1. 发布页「添加到合集」→ 首次点会弹「创建新合集」→ 名称用**别名**（≤20 字）+ 简介 +
   1:1 封面 1080×1080 JPG ≤5MB → 创建（审核 1–3 小时，期间不影响视频发布）
2. 选中新合集 → 发布第一集 → 主页显示「第1集」；之后同系列直接勾选同一合集，按发布时间自动累加集数
3. **为什么不能先发再补**：第 1 集不在合集里 → 「第N集」从开头就断；
   补归集要走「合集管理 → 添加作品」逐条勾选，且合集创建要审核，期间新集挂不进去
4. 配方（`browser_run_recipe`）传了 `collectionName` 却没选中合集时会**停在发布前**：
   在页面上手动建/选合集后直接点「发布」，**不要重跑配方**（会重新上传并重置表单）

> 单集一次性任务可不建；只要计划做 ≥2 集，首集就必须建。

## ★ 先排查：为什么「合集操作实现不了」

> **实名 ≠ 全部条件**。合集开通需同时满足：
> **实名认证 + 绑定中国大陆手机号 + 账号状态正常（无违规）**。（2026-10-11 联网核实）

1. **是否「二级实名」**：只绑身份证但未完成**人脸核验**视为未认证。
   （App：设置→账号与安全→实名认证，确认状态为"已认证"且含人脸核验）
2. **手机号**：必须绑**中国大陆运营商**号且可收短信（虚拟号/境外号/停机都过不了校验）
3. **合集权限是单独开关，可能需主动申请**：creator.douyin.com → 内容管理 → **合集管理**
   - 有「自定义创建合集」按钮 = 权限已开通，直接建
     （名称 **≤20 字** + 简介 + 1:1 封面 1080×1080 ≤5MB，勾选公开作品，≥3 个为佳）
     → 保存并创建 → 审核 1–3 小时生效
   - 显示「暂未开通合集权限」→ 点右侧「**立即申请**」
     （填账号类型 个人/机构、主营内容方向 12 品类**单选、不可选"其他"**、近 7 日发布主题关键词）→ 人工审核
   - 页面空白/无入口 → 账号权限或灰度未放开
4. **反向激活路径（两条）**：
   - 单条视频播放量 **≥10 万** → 其详情页会动态出现合集关联入口，可绕过常规权限判断
   - App 端粉丝 **≥1 万** → 创作者服务中心「合集管理」直接建
   - 另：网页端**成功创建一次合集后**，后续管理权限自动解锁

→ 排查顺序：合集管理页看有没有「自定义创建合集」→ 没有就「立即申请」→ 申请也不给就走
   高播放量反向激活或 App 万粉 → 都不行**如实报告**。

## 发布页「添加到合集」（有权限时）

首次点弹「创建新合集」（名称 ≤20 字，建议用别名/书名主题，别叫「我的作品集」）；
之后同系列直接勾选 → 主页显示「第N集」，同合集视频**按发布时间自动累加集数**。

## 兜底路径（发布页无入口 / 想回溯归集）

```
creator.douyin.com → 内容管理 → 合集管理
├─「自定义创建合集」：名称(≤20字) + 简介 + 1:1 封面 1080×1080
└─ 进合集 →「添加作品」→ 勾选历史视频（单次 ≤50）→ 加入合集
   （可把已发布的第 1 章、第 2 章一起归入）
```

这是**无门槛/低门槛**的回溯路径 —— 发布页入口消失时一律走这里。
