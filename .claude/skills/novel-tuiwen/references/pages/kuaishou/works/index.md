# 快手 · 作品管理

> 站点：`cp.kuaishou.com`　入口：`https://cp.kuaishou.com/article/manage/video`
> 实抓：2026-10-15 / 2026-10-16（账号 `yqdbgz`）

## 何时用

- 发布后**核验**作品是否上架（发布时间 / 时长 / 状态）
- 取已发布作品的**公开视频链接**（回填番茄用）—— 列表里的作品 id 拼 `https://www.kuaishou.com/short-video/<id>`

## 展示

无限滚动卡片列表，页头有「共 N 个作品」。卡片 = 封面 + 时长 + 发布时间 + 状态 + 描述首句。

## 公共说明

- URL 的 `?status=` 是筛选：**`2` = 已发布**（发布成功后会带 `&from=publish` 跳到这里），**`1` = 疑似审核中**（推断）。
- 列表数据挂在 Vue 实例上，**接口读取比刮 DOM 稳**（见 list-works.md）。
- 页面同样受"面板收起 → 微前端不渲染"影响。
