# backfill-batch — 批量回填发文（xlsx 模板）

> 别名管理页工具条「批量回填发文」→ 弹窗「批量上传发文-番茄小说」

## ★ 先看这条：批量**不适用于快手**

模板列只有 **`别名 / 发文日期 / 发文链接 / 抖音号`** —— **没有平台列**。
所以：

- **抖音**多别名/多条目 → 走批量（一次上传）
- **快手**（任何非抖音）→ **走单条抽屉** `backfill.md`

## 步骤

1. 别名管理页 → 点「**批量回填发文**」
2. 弹窗内先点「**下载批量模版**」（xlsx）
3. 按模板列填写（别名 / 发文日期 / 发文链接 / 抖音号）
4. 点或拖拽文件到上传区上传
5. 点「提交」

## 页面锚点（原文）

```
弹窗标题：「批量上传发文-番茄小说」
提示：「请先 下载批量模版 ，填写后上传」
上传区：「点击或拖拽文件到此处上传」
约束：「文件不超过2万行，文件格式需要为xlsx」
按钮：「取消」/「提交」
```

## 注意

- 需要**下载模板 → 填 xlsx → 上传**三步文件操作（`browser_download` / 本地填表 / `browser_upload`）；
  单个别名只回 1 条时，**单条抽屉比批量更快**，别为了"用上批量"而绕远路。
- 「1 条链接即生效」的规矩同样适用（见 `backfill.md`）—— 别为了填满表格而逐集生成行。
