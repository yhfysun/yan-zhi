# backfill — 回填发文（结算前提）

> 别名管理行「查看」→ 抽屉「推广计划」→ 底部「**回填发文**」

## ★★★ 最重要的规矩：**1 条链接即生效，不要每集都提交**

官方口径（2026-10 页面原文核实）：**一个别名回填 1 条作品链接即生效**。
同一本书发多平台 / 连载多集，**不需要**每条都回填。

| 场景 | 该怎么做 |
|------|----------|
| 新别名首次推广 | **回填 1 条**（最早/最主要的那个作品链接）→ 结算窗口即开启 |
| 想延长结算窗口 | 再挑 1 条**最新**作品回填 → 截止日推到「最新发文日期 + 28 天」 |
| 每集都有一集视频 | **不必逐集提交** —— 逐条提交只烧步数，不增加收益 |

> ⚠️ 实拍教训（2026-10-16）：子智能体为"三集各回填一次"逐条开抽屉、逐条提交，
> 3 次提交把 token 池打满、任务在最后一步中断。**先问一句"一条够了吗"，答案通常是不够才怪。**

**但**：**新别名 7 天内不回填会失效**（过期别名不再计拉新）→ 首次回填要**及时**，别拖。

## 入口路径（原文）

```
别名管理页 promotion-list?tab_type=2
 → 行内「查看」
 → 抽屉「推广计划」
 → 底部「回填发文」
 → 表单：基础信息 / 温馨提示 / 抖音发文 / 其他平台发文
```

## 抽屉结构与锚点（2026-10 实抓）

```
div.arco-drawer
└─ form.arco-form.arco-form-vertical
   ├─ ① 基础信息   div.base-info-IVRg8K
   │     行：div.description-item-row-zpCXsM
   │        label → div.description-item-label-o1mK37(.description-item-label--wide-mPwFSl)
   │        value → div.description-item-value-YTsHRC
   │     字段：书名 / 别名 / 任务类型 / 发文类型（均只读带出）
   ├─ 温馨提示   div.highlight-tip-YL7hSS > div.title-tip-YadPjA
   │     「新别名7天内不回填会失效，请一定要及时回填提交；」
   │     「回填链接必须与「发文类型」匹配，否则会影响收益结算。」
   ├─ ② 抖音发文    label 内含 span.get-dyuid-guide-txt-cXDVTQ「如何获取抖音号?」
   │     字段：选择发文日期 + 输入抖音发文链接（占位文案含「https://开头」）
   ├─ ③ 其他平台发文   ← ★ 快手走这里
   │     字段：选择发文日期 + 输入发文链接
   │     ⚠️ **不区分平台**：没有下拉 / tab / 单选，页面上全文无「快手」字样
   │     →「其他平台发文」就是**通用兜底入口**，快手链接直接填
   └─ 按钮：添加发文 / 删除 / 取消 / 提交
```

- 定位一律用 **「文本 + `[class*=前缀]`」**；hash 后缀（`base-info-IVRg8K`）会随构建漂。
- 「发文类型」是**只读展示**（如 `图文` / `解压TTS`），**不是选择项** ——
  它是书籍自身的类型，回填时只需保证链接与它匹配（图文类别回图文链接）。

## 步骤

1. 打开别名管理页 → 找到目标别名行 → 点「查看」开抽屉
2. 抽屉底部点「回填发文」进入表单
3. 按平台选分组：抖音 → ②；**快手 → ③「其他平台发文」**
4. 点「添加发文」生成一行
5. 填**发文日期**（⚠️ 见下）与**发文链接**
6. 点「提交」
7. 核验：别名列表该行 `发文详情` 的 `已填写（N条）` **+1**

## ⚠️ 两个必踩的坑（2026-10-16 实拍）

1. **日期选择器必须"真选"**：arco DatePicker 只 route 文本**不会提交到 React/Vue 表单状态**，
   点「提交」时校验会把日期重置为空、报「发文日期必填」。
   → 正确做法：点开面板 → **点具体日格**（或键入后按 Enter）让面板回填值，再提交。
2. **空行会阻塞整张表单提交**：抽屉里会有一个默认空的「抖音发文」行，
   它的必填校验一直报错 → 提交永远失败。
   → 提交前**先把不用的空行「删除」**，只留真正要提交的那一行。

## ⚠️ 抽屉不存草稿

**刷新 / 重新 navigate 同一 URL = 已填内容全部清空**。
中断后要接手时：**先只读**确认抽屉还开着、已填了什么，再决定"补交"还是"重填"，**绝不刷新**。

## 作品链接形态（填哪个链接）

| 平台 | 链接形态 |
|------|----------|
| 抖音 | `https://www.iesdouyin.com/share/video/<aweme_id>/`（从公开页 `www.douyin.com/video/<id>` 取 id 拼，或作品管理页「分享 → 复制链接」） |
| 快手 | `https://www.kuaishou.com/short-video/<id>`（作品管理卡片里的作品 id，见 `../../../kuaishou/works/list-works.md`） |

⚠️ 填的是**短视频作品链接**，不是小说链接。
⚠️ 「发文类型」是只读展示（如 `图文` / `解压TTS`），**回填链接必须与它匹配**，否则影响结算。

## Browser 操作

```text
1) browser_navigate  url=https://kol.fanqieopen.com/page/promotion-list?tab_type=2
2) browser_get_page_content → 定位目标别名行的「查看」→ browser_click
3) browser_click 「回填发文」
4) browser_click 「添加发文」（其他平台发文分组下）
5) 日期：点开 picker → 点日格提交值；链接：browser_type 到「输入发文链接」
6) 删除多余的空行（抖音发文那行）
7) browser_click 「提交」→ browser_get_page_content 核验 已填写（N条）
```
