# create-alias — 批量创建别名

> 别名管理页工具条「批量创建别名」

## 步骤

1. 别名管理页 → 点工具条「**批量创建别名**」
2. 弹窗内书目信息已带出（只读）
3. 在别名输入区填关键词（**一行一个 / 逗号分隔**；3-5 字，与书题材强相关，如「狐王痴狂」）
4. 点「确定」
5. 回列表，**轮询该行状态到「生效中」**才可进下一步（发文必须挂生效中别名）

## 页面锚点

```
div.arco-modal（遮罩 div.arco-mask）
├─ .arco-modal-header  标题「批量创建别名」
├─ .arco-modal-body
│  ├─ 书目信息（已带出，只读展示）
│  └─ 别名输入区：textarea.arco-textarea 或 input.arco-input
└─ .arco-modal-footer  button「确定」/「取消」
```

## 输出

新别名行；判据 `别名状态 = 生效中` 且 `书籍状态 = 可用`。
