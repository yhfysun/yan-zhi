## 何时用

- 看某个别名/书籍的授权与状态（发文前提）
- **回填发文**（结算前提，见 backfill.md）
- 批量创建别名 / 批量回填发文 / 批量导出

## 展示

表格，列为：

```
关键词 | 书本信息 | 体裁 | 发文类型 | 别名状态 | 书籍状态 | 发文详情 | 创建时间 | 有效期 | 结算截止日 | 操作
```

行样例（原文）：

```
骨债阴阳 【借邪骨，我以鬼仙破阴阳】 id: 7458089212022099006 网文 解压TTS 生效中 可用 已填写（3条） \
2026-10-08 10:59:09 2026-10-08 ～ 2027-04-06 2026-11-12 剩余28天  查看 删除
```

- **发文前提**：`别名状态 = 生效中` 且 `书籍状态 = 可用`。
- `发文详情` 的 `已填写（N条）` 是**回填是否生效的判据**（N 应随每次成功提交 +1）。
- `结算截止日` 随最新发文日期滚动（见 backfill.md 的结算窗口）。
