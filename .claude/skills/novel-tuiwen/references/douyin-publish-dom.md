# 抖音创作者平台 · 发布页 / 合集 DOM 速查（creator.douyin.com）

> 对应 SKILL「流程」第 6 步发布 + 「📺 抖音合集」节。
> ⚠️ 抖音发布页为 React 私有组件，类名无语义（常是 css-xxxx hash）且**改版频繁**；
> 定位以「**文本 + placeholder + aria/语义属性**」为主，类名只做兜底。
> ⚠️ 本文为操作路径 + 定位策略（2026-10 整理）；**每次落地先 get_dom 实抓复核**，抓法见文末。

## 0. 为什么「合集操作实现不了」——先排查这四层（2026-10-11 联网核实）

> 实名 ≠ 全部条件。合集开通需同时满足：**实名认证 + 绑定中国大陆手机号 + 账号状态正常（无违规）**。

1. **实名是否「二级实名」**：只绑身份证但未完成**人脸核验**视为未认证（App：设置→账号与安全→实名认证，确认状态为"已认证"且含人脸核验）。
2. **手机号**：必须绑定**中国大陆运营商**手机号且可收短信（虚拟号/境外号/停机都过不了权限校验）。
3. **合集权限是单独开关，可能需要主动申请**：creator.douyin.com → 内容管理 → **合集管理** ——
   - 显示「自定义创建合集」按钮 = 权限已开通，直接建（名称≤20字 + 简介 + 1:1 封面 1080×1080 ≤5MB，勾选公开作品，≥3 个为佳）→ 保存并创建 → 审核 1–3 小时生效；
   - 显示「暂未开通合集权限」→ 点右侧「**立即申请**」触发申请流程（填账号类型个人/机构、主营内容方向 12 品类**单选不可选"其他"**、近7日发布主题关键词）→ 人工审核；
   - 页面空白/无入口 → 账号权限或灰度未放开。
4. **反向激活路径（两条）**：
   - **单条视频播放量 ≥10万** → 其详情页会动态出现合集关联入口，可绕过常规权限判断；
   - App 端粉丝 ≥1万 → 创作者服务中心「合集管理」直接建。
   - 另：网页端**成功创建一次合集后**，后续管理权限自动解锁（首次创建即激活）。

→ 排查顺序：合集管理页看有没有「自定义创建合集」→ 没有「立即申请」→ 申请也不给就走高播放量反向激活或 App 万粉 → 都不行如实报告。
⚠️ 发布页「添加到合集」入口只在权限开通后才显示；账号有违规/低质记录也会隐藏入口。

## 1. 发布页（/creator-micro/content/upload）

```
上传页关键锚点（文本/placeholder 匹配）
├─ 上传入口：大块拖拽区（文本「点击上传」/「拖拽文件到这里」）或 button 上传
│   → 用 browser_upload（filechooser 模式：clickSelector 点上传按钮自动投递本地文件）
├─ 标题/文案编辑器：div[contenteditable=true] 或 .notranslate（placeholder「填写作品标题…」）
│   → 受控 contenteditable：focus 后 document.execCommand('insertText', false, 文案)
├─ 话题：文案里输入 # 触发下拉（li 文本匹配）
├─ 「发布设置」区
│   ├─ 谁可以看 / 定时发布 / 合集 …
│   └─ 「添加到合集」/「选择合集」入口（有权限才显示）
│       ├─ 首次点：弹「创建新合集」→ 合集名输入框（≤20字）+ 确定按钮
│       └─ 已有合集：下拉/弹层勾选已有合集（li/checkbox 文本匹配）
└─ 底部：button「发布」                                  ← confirm_user 确认后才点
```

- 发布成功判据：跳转/出现「发布成功」提示 → 到「内容管理」确认视频在列表。
- 🚫 标题文案：带别名关键词+话题（如 #狐王痴狂 #番茄小说），**禁书名**。

## 1.1 发布按钮被悬浮层遮挡的处理（2026-10-12）

> 实测：抖音发布页底部「发布」按钮常被悬浮提示条 / 权限气泡 / 上传进度遮罩盖住，导致
> 点不到或点了不生效。下方是已落地的自动化应对，无需人工干预。

- **click 已遮挡感知 + 自动关闭**（桌面端 `main.cjs`）：点「发布」时若检测到按钮中心被其它元素盖住，
  会先尝试自动关闭遮挡层（点其关闭控件 `× / 关闭 / 取消`；找不到则退 `Esc`）再对真实按钮派发点击，
  并返回 `occluded:true` + `covering` 信息。**不再依赖脆弱的坐标点击绕过**。
- **agent 配方（2026-10-12 补，seed 内）**：
  1. 点「发布」前用 `get_page_content` 看附近有无悬浮层；若 `browser_click` 返回 `occluded:true` 或点下去没反应 →
     按 `Esc` / 点关闭按钮 / `browser_wait_for 2000` 等其自动消失后重试。
  2. 点「发布」后用 `get_page_content` **轮询**「发布成功 / 已提交 / 等待审核」文案 + 内容管理列表出现新视频作为成功判据；
     **严禁再次 navigate 回上传页**（会重置流程、清空已填标题——之前反复的根因）。
  3. 坐标点击（x/y）仅当 index/selector 都失效且已确认目标坐标时作最后兜底，且点后必须读状态复核。

## 2. 合集入口（有权限时）

- 发布页「添加到合集」：首次弹「创建新合集」（名称 ≤20 字，建议用别名/书名主题）；
  之后同系列直接勾选 → 主页显示「第N集」，同合集视频按发布时间自动累加集数。
- 合集名规范：≤20 字；别叫「我的作品集」这类泛名。

## 3. 兜底路径（发布页无合集入口 / 想回溯归集）

```
creator.douyin.com → 内容管理 → 合集管理
├─ 「自定义创建合集」：名称(≤20字) + 简介 + 1:1 封面 1080×1080
└─ 进合集 → 「添加作品」→ 勾选历史视频（单次 ≤50）→ 加入合集
   （可把已发布的第1章、第2章一起归入）
```

- 这是**无门槛/低门槛**的回溯路径，发布页入口消失时一律走这里。

## 4. get_dom 复核手法

```
browser_action { action:'get_dom', maxNodes:3000, depth:25 }   ← 发布页整页（搜「合集」文本）
browser_action { action:'get_dom', maxNodes:1500, depth:15,
                 selector:'[contenteditable]' }                ← 标题编辑器
```

- 类名无语义 + 改版频繁 → **每次发布前先实抓一次**，用「文本/placeholder」定位；
  点不动时 x/y 坐标兜底（同番茄书详情的做法）。
- 「合集」字样整页搜不到 + 实名已做 → 截图报告用户，别编造入口位置。
