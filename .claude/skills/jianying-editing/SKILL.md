# 剪映剪辑 · 详细参考

> 本文件是 `skill_jianying_editing` 正文里「详见」指向的那份参考。
> **流程看正文，能力表、迁移边界、排查看这里。**

## When to use

- 用户说「用剪映剪 / 在剪映里剪 / 导出到剪映 / 我习惯用剪映」
- 要判断这台机器到底装没装剪映、草稿存哪
- 导出后用户说「剪映里没看到 / 字幕没了 / 转场没了 / 时间对不上」
- 想确认某个效果能不能带进剪映（调色、蒙版、关键帧、曲线变速…）

---

## 一、两种剪辑模式的分工（先讲清，别混）

| 模式 | 入口 | 谁渲染 | 适合 |
|---|---|---|---|
| 应用内剪辑 | `clip_project` + 剪辑工作台 | 本应用 ffmpeg | 要一步出成片、批量/自动化、语义可控 |
| 剪映剪辑 | `clip_jianying` | 用户在剪映里导出 | 用户要实时预览、手动微调、用剪映特效库 |

**同一份工程可以两边都用**：应用内工程不会被导出动作改变；剪映里导出的成片也可以再当素材带回应用内。

开工确认时把「剪辑方式」问出来：用户没提就默认应用内；提到剪映再走下面流程。

## 二、clip_jianying 工具

| op | 参数 | 说明 |
|---|---|---|
| `detect` | — | 检测剪映安装（exe/版本）+ 草稿根目录 + 最近草稿；**先调它** |
| `export` | `{ name?, draftRoot?, open? }` | 把当前会话工程导出成剪映草稿；同名自动加序号，不覆盖 |
| `find_export` | `{ sinceMinutes?, nameHint?, limit? }` | 剪映里导出成片后，按时间/名字找回 mp4 路径 |
| `list` | `{ draftRoot?, limit? }` | 列草稿目录里已有草稿（名称/时长/是否加密） |
| `open` | — | 启动**检测到**的剪映（不接受自定义 exe；不能打开指定草稿，见 §5） |

`export` 返回：`draftDir`、`draftName`、`files`、`stats`（段/字幕/音频/时长）、`warnings`（未迁移项）、`opened`。

**草稿命名**：默认取工程名；Windows 非法字符会被替换；重名加 `(2)`、`(3)`。

## 三、迁移能力表（能带什么）

| 工程能力 | 剪映草稿 | 说明 |
|---|---|---|
| 多段素材顺序 | ✅ | 主视频轨首尾相接 |
| 裁剪 trimStart/trimEnd | ✅ | 写入 source_timerange |
| 恒定变速 speed | ✅ | 用平均倍速；总时长与应用内一致 |
| 音量 volume | ✅ | 段音量 |
| 旋转 rotate / 镜像 flip | ✅ | clip.rotation / clip.flip |
| 字幕内容与时间 | ✅ | 相对成片时间轴，微秒整数 |
| 字幕字号/颜色/描边/位置/安全区 | ✅（近似） | 字号按 1920 基准换算；安全区=上抬位置 |
| 字幕底板 backColor | ✅ | 剪映文字背景 |
| BGM | ✅ | 整片一条音频轨，音量保留 |
| 分段配音 audioFile | ✅ | 与原声替换语义一致（原声静音） |
| 画中画 overlays | ✅ | 每条叠加一条视频轨，缩放/九宫格锚点近似 |
| 调色预设 colorPreset | ✅（近似） | 映射剪映**免费**滤镜/特效；无免费对应项会进 warnings |
| 结构特效 fx | ✅（近似） | 映射剪映视频特效；fxParams 用剪映默认参数 |
| 蒙版形状 mask.shape | ✅（近似） | 剪映只有 线性/镜面/圆形/矩形/爱心/星形；其余近似 |
| 色键 mask.key | ✅ | 剪映色度抠图（chromas） |
| 转场 transition | ✅（近似） | 映射剪映转场，挂在**前一段**上 |
| 关键帧 keyframes | 🟡 | 缩放/位移/透明度写入；缓动按线性 |
| 图片推拉 kenburns | ✅ | 转成缩放关键帧（1↔1.12） |
| 淡入淡出 fadeIn/fadeOut | ✅ | 剪映入场/出场动画（渐显/渐隐） |
| 倒放 reverse | 🟡 | 写入 reverse 字段；版本差异可能不生效，需打开确认 |
| 字幕动画 | ✅（近似） | 映射剪映文字入场动画（fade/pop/zoom/slide/typewriter/karaoke/flicker/flychar） |
| 手动调节 adjust | ❌ | 剪映草稿没有亮度/对比/色温等价字段 |
| 画面裁剪 crop | ✅ | 写入素材 crop 四角 |
| 曲线变速 speedCurve | 🟡 降级 | 按**平均倍速**导出（保总时长，失去曲线） |
| 整片音效链 audioFx | ❌ | 免费资源里没有降噪/响度等价项 |
| BGM 自动闪避 duck | ❌ | 剪映里做音量关键帧 |

> 导出后必须把 `warnings` **逐项转告用户**。效果是「资源映射」不是逐像素复刻：观感为近似，参数可能用剪映默认值；首次打开个别特效可能短暂显示“加载中/加载失败”（剪映按需下载）。

## 四、剪映安装与草稿目录（Windows）

**可执行文件常见位置**
- `%LOCALAPPDATA%\JianyingPro\Apps\<版本>\JianyingPro.exe`（升级器安装的实际布局）
- `%LOCALAPPDATA%\JianyingPro\JianyingPro.exe`
- `%LOCALAPPDATA%\Programs\JianyingPro\JianyingPro.exe`
- `C:\Program Files\JianyingPro\JianyingPro.exe`（及 x86）
- 兜底：卸载注册表的 `InstallLocation` / `DisplayIcon`

**草稿根目录常见位置**（用户可在剪映「全局设置 → 草稿位置」改）
- `%LOCALAPPDATA%\JianyingPro\User Data\Projects\com.lveditor.draft`
- `%USERPROFILE%\Documents\JianyingPro Drafts`
- `%LOCALAPPDATA%\JianyingPro\User Data\Projects`（部分版本）

**显式指定草稿目录**：`clip_jianying { op:'export', draftRoot:'...' }`，或设环境变量 `JIANYING_DRAFT_ROOT`。
找不到目录时不要说"导出成功"：让用户先打开一次剪映（首次启动会建目录），或按「全局设置 → 草稿位置」把路径给过来。
**启动剪映只接受自动检测到的可执行文件**（安全边界：不能变成任意进程启动器）；自定义安装检测不到时，请用户自己从桌面/开始菜单打开。

## 五、版本知识与诚实边界

- 新建草稿兼容剪映 5.9 / 10.8 / 11.x；**剪映向下兼容旧格式，旧版打不开更新格式**。
- 新版剪映（7+，版本号 10.x/11.x）**保存后**的草稿可能不是明文 JSON → 我们只做「新建草稿」，不读取/改写用户已有草稿。`list` 会标 `encrypted`。
- 剪映 6+ **没有可用的命令行打开指定草稿**：`open` 只能启动应用；让用户点草稿列表最上面那条（按修改时间排序）。
- 剪映 7+ 隐藏了 UIAutomation 控件 → **控件级自动导出只支持 ≤6.8**；7+ 的导出只能靠**截图识别 + 鼠标键盘**（「电脑使用」插件，见 §10）。
- 字体未缓存时，字幕要第二次打开草稿才正确显示（剪映行为，提前说明）。

## 六、标准 SOP（完整闭环）

```text
1) clip_jianying op=detect                      ← 本机装没装、草稿目录在哪
2) clip_project op=get                          ← 有工程就复用，没有先 create + add_clip 建骨架
   （用户要的素材/字幕/BGM 先按应用内的方式排好，导出才完整）
3) clip_jianying op=export { name?, open:true } ← 生成草稿并启动剪映
4) 用户在剪映里继续剪/预览（应用内工程不受影响）
5) 导出成片：§10（「电脑使用」插件驱动 UI）→ clip_jianying op=find_export 找回 mp4
6) 上传平台：§11（发布队列 + 发布执行员）
```

**不要在剪映模式下 op=render**：用户要自己剪，应用内渲染是多余的一步。
**不要为了"能迁移"擅自降级应用内工程**：导出只读工程，不修改。

## 七、失败排查

| 现象 | 原因 | 处置 |
|---|---|---|
| detect 说没装，但用户说装了 | 安装目录被自定义 | 让用户自己打开剪映；草稿导出仍可用 `draftRoot` 指定路径 |
| 有剪映但找不到草稿目录 | 首次启动未建 / 改过草稿位置 | 先打开一次剪映；或 `draftRoot` 指定全局设置里的路径 |
| 导出报“找不到草稿目录” | 同上 | 同上；检查路径权限 |
| 剪映里看不到新草稿 | 剪映在运行且列表未刷新 | 重启剪映 / 切到草稿箱刷新；确认目录是同一个 |
| 提示符/文字变大变小 | 字号按 1920 基准换算，剪映画布不同 | 在剪映里统一调字号 |
| 字幕整体偏早/偏晚 | 转场/变速映射为剪映近似语义 | 到剪映里微调字幕；有曲线变速时尤其明显 |
| 字幕样式不对 | 只迁移了内容/字号/颜色/描边/位置 | 字体与动画在剪映里重设 |
| 剪映提示草稿版本不兼容 | 剪映版本过旧 | 升级剪映；旧版打不开新格式 |
| 草稿加密读不出 | 新版剪映保存后的格式 | 只新建，不读旧草稿；需要复用请让用户在剪映里另存模板 |

## 八、导出成片（Windows，「电脑使用」插件）

> 剪映 7+ 隐藏了 UIAutomation 控件，**没有可靠的命令行导出**；只能像人一样看屏幕、点鼠标。
> 前提：插件管理里启用「电脑使用」。没启用就如实说明，让用户手动导出。

```text
1) computer_open_app（或 clip_jianying op=open）→ computer_list_windows { processName:"JianyingPro" }
   → computer_activate_window
2) computer_screenshot → image_analyze 找草稿卡片（名字=草稿名，通常在草稿箱第一行）
   → computer_mouse_click 点它；找不到就 computer_scroll 或切回首页
3) 等编辑页加载完 → screenshot → image_analyze 找右上角「导出」→ 点击
4) 导出弹窗：确认分辨率/帧率/文件名（默认即可）→ 点「导出」
5) 轮询 screenshot 等「导出成功」弹窗（最长 15 分钟）→ 点关闭/完成
6) clip_jianying op=find_export { nameHint: 草稿名, sinceMinutes: 30 } → 拿到 mp4 路径
```

- 每一步都先截图识别再点，**禁止盲点坐标**；同一元素连续失败两次就停下说明。
- 导出期间不要抢鼠标键盘；用户在用电脑时先问一句。
- 导出失败/找不到文件：给「失败步骤 + 一条处置」，不要谎报成功。

## 九、上传各大平台

成片路径拿到后走现有发布链路（不要自己摸平台页面）：

```text
1) 问清平台（抖音/快手/小红书/B站/视频号…）与标题/正文/标签/合集
2) publish_enqueue { platform, title, content, mediaPaths:[mp4], tags?, collection? }  ← 逐平台入队
   （默认进入「待确认」；用户在发布面板确认后才执行）
3) 用户明确说「直接发」→ 可直接 call_agent 发布执行员；否则等确认后再委派：
   call_agent { agentId:"a_builtin_publish_agent",
   input:"平台 / 媒体绝对路径 / 标题 / 正文 / 标签 / 合集 / 发布后取回链接" }
4) 执行员回执成功（带作品链接）→ publish_mark_published { id, note:链接 }
   失败 → 如实汇报，禁止标记已发布
```

- 抖音/快手有 `browser_run_recipe` 实测配方（douyin-publish-video 等），执行员会优先用。
- 登录/扫码/验证码由执行员 `ask_user` 请用户自己完成，**不代填账号密码**。
- 平台规则（极限词/敏感词）由 `publish_enqueue` 校验；被退回就改文案，不硬发。

## 十、交付口径

给：**草稿名、草稿目录、时长、视频段/图片数、字幕条数、音频条数、未迁移项清单、剪映是否已启动**。
不要贴 draft_content.json、不要贴整段工具调用记录。
失败时给**失败步骤 + 一条最可能的处置**（版本 / 路径 / 权限）。

## 十一、做不到（照实说）

- 在没有「电脑使用」插件的环境自动导出（有插件时走截图识别+鼠标键盘；控件级自动化只支持剪映 ≤6.8）
- 替用户登录平台/过验证码（上传发布需用户本人完成扫码/验证码）
- 读取/改写剪映已有草稿（新版可能加密）
- 保证剪映里的效果与应用内**逐像素一致**（剪映资源是平台滤镜/特效，只能近似映射）
- 迁移手动调节 / 曲线变速 / 整片音效链 / BGM 闪避
- 保证倒放一定生效（写入 reverse 字段，版本差异需打开确认）
