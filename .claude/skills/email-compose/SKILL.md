# 邮件撰写（email-compose）

撰写各类邮件：商务沟通、通知、邀请、回复、催办、致歉。可选语气（正式/委婉/直接）与语言（中/英），含主题行、正文、署名。

## 何时触发

- 用户说"写邮件""帮我回邮件""写通知""写邀请函""写商务邮件""催办邮件"等
- 用户给了邮件大意，要润色成正式邮件
- 用户要中英文邮件

## 标准流程

1. **确认类型**：通知 / 邀请 / 回复 / 催办 / 致歉 / 推介
2. **确认语气与语言**：正式 / 委婉 / 直接；中文 / 英文
3. **收集要素**：收件人、发件人、关键信息、期望动作、截止时间
4. **生成**：主题行 + 称呼 + 正文 + 行动号召 + 署名

## 语气对照

| 语气 | 特征 | 适用 |
|------|------|------|
| 正式 | 敬语、完整句、不缩写 | 对外/上级/初次 |
| 委婉 | 商量口吻、缓冲词（烦请/劳驾） | 请求/催办 |
| 直接 | 短句、要点式 | 内部/熟络/紧急 |

## 模板

### 通知
```
主题：【通知】XX 系统将于 8 月 30 日 22:00 停机维护

各位同事：

为升级数据库，XX 系统将于 2026-08-30 22:00 至 23:00 停机维护，
期间无法访问。请提前保存工作，避免在此期间操作。

如有疑问，请联系运维组（ops@example.com）。

XX 运维组
2026-08-29
```

### 邀请
```
主题：【邀请】XX 产品发布会 · 9 月 5 日 14:00

XX 先生/女士：

诚邀您出席 XX 产品发布会，届时将发布新一代 XX 产品并安排演示交流。

时间：2026-09-05 14:00-16:00
地点：XX 会议中心 3 楼
议程：14:00 发布 · 15:00 演示 · 15:30 交流

请于 9 月 3 日前回复是否出席。期待您的光临。

XX 团队
```

### 回复（委婉）
```
主题：Re: 关于 XX 合作事宜

XX 您好：

感谢您的提议，我们对 XX 方案很感兴趣。经内部评估，有几个点需进一步确认：
1. ...
2. ...

能否本周内安排一次电话沟通，以便对齐细节？

顺祝商祺，
XX
```

### 催办
```
主题：【催办】XX 合同请于本周内回签

XX 您好：

上周发送的 XX 合同（附件）尚未收到回签，因项目排期较紧，
烦请于本周五前签回，以便我们启动后续流程。

如需修改条款请随时告知。

XX
```

### 英文（正式）
```
Subject: Follow-up on XX Proposal

Dear Mr. XX,

Thank you for your interest in our proposal. We have reviewed the terms and
would like to schedule a call this week to align on the details below:
1. ...
2. ...

Please let us know a convenient time.

Best regards,
XX
```

## 注意事项

- 主题行要具体，别用"你好""通知"等无信息主题；加【类型】前缀便于检索
- 一封邮件一个主旨，多件事拆多封或用编号要点
- 行动号召明确：要对方做什么、什么时候之前
- 称呼与署名匹配正式程度；对外用"尊敬的/顺祝商祺"，内部可简
- 催办先感谢再提事项，避免命令语气
- 英文注意称谓（Dear Mr./Ms.）、落款（Best regards/Sincerely）
- 涉及时间一律写全日期，避免"下周""月底"歧义
- 附件在正文提及，别只挂附件不说明
